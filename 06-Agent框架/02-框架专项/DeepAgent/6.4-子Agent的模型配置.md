# 6.4 子 Agent 的模型配置

不同子 Agent 可以用不同的模型——根据任务特点选择最合适的。

---

## 配置

```python
agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",  # 主 Agent 用 Claude
    subagents=[
        {
            "name": "contract-reviewer",
            "description": "审核法律文档",
            "system_prompt": "你是法律专家...",
            "model": "google_genai:gemini-3.5-flash",  # 大上下文窗口
        },
        {
            "name": "data-analyst",
            "description": "分析数据",
            "system_prompt": "你是数据分析师...",
            "model": "openai:gpt-5.5",  # 擅长数值分析
        },
        {
            "name": "coder",
            "description": "编程",
            "system_prompt": "你是程序员...",
            "model": "ollama:north-mini-code-1.0",  # 本地模型，免费
        },
    ],
)
```

---

## 选择策略

| 任务类型 | 推荐模型 |
|---------|---------|
| 长文档处理 | Gemini（大上下文窗口） |
| 数值分析 | GPT-5.5 |
| 编程 | 代码专用模型 |
| 简单任务 | 小模型（省钱） |
