# 5.3 MemorySaver：内存中的 Checkpointer

`MemorySaver` 是 LangGraph 内置的最简单的 Checkpointer——它把所有 checkpoint 保存在**内存**中。

这一节我们详细学习 MemorySaver 的用法和适用场景。

---

## MemorySaver 的特点

### 优点

1. **零配置**：不需要数据库、不需要文件
2. **快速**：内存读写速度极快
3. **简单**：适合学习和快速原型开发

### 缺点

1. **不持久化**：程序退出后，所有 checkpoint 丢失
2. **内存占用**：checkpoint 越多，内存占用越大
3. **不适合生产**：无法跨进程、跨服务器共享状态

---

## 基本用法

### 创建 MemorySaver

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
```

就这么简单！不需要任何配置。

### 绑定到 Graph

```python
from langgraph.graph import StateGraph, MessagesState, START, END

graph = StateGraph(MessagesState)
# ... 添加节点 ...

app = graph.compile(checkpointer=checkpointer)
```

### 使用

```python
# 第一次调用
result = app.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": "1"}}
)

# 第二次调用：会记住第一次的消息
result = app.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": "1"}}
)
```

---

## 完整示例：一个有记忆的计数器

```python
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver
from typing import TypedDict

# 定义 State
class CounterState(TypedDict):
    count: int

# 定义节点
def increment(state: CounterState):
    return {"count": state["count"] + 1}

# 构建图
graph = StateGraph(CounterState)
graph.add_node("increment", increment)
graph.add_edge(START, "increment")
graph.add_edge("increment", END)

# 添加 checkpointer
checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)

# 测试
thread_id = "counter_1"

# 第 1 次调用
result = app.invoke(
    {"count": 0},
    config={"configurable": {"thread_id": thread_id}}
)
print(f"第 1 次：count = {result['count']}")  # 1

# 第 2 次调用：从上次的状态继续
result = app.invoke(
    {"count": 0},  # 这个值会被忽略，使用 checkpoint 里的值
    config={"configurable": {"thread_id": thread_id}}
)
print(f"第 2 次：count = {result['count']}")  # 2

# 第 3 次调用
result = app.invoke(
    {"count": 0},
    config={"configurable": {"thread_id": thread_id}}
)
print(f"第 3 次：count = {result['count']}")  # 3
```

输出：

```
第 1 次：count = 1
第 2 次：count = 2
第 3 次：count = 3
```

**注意**：第 2、3 次调用时，虽然传入的是 `{"count": 0}`，但实际使用的是 checkpoint 里保存的值。

## MemorySaver 的内部结构

MemorySaver 在内存中维护一个字典：

```python
{
    "thread_1": {
        "checkpoint_1": {...},
        "checkpoint_2": {...},
        "checkpoint_3": {...}
    },
    "thread_2": {
        "checkpoint_1": {...},
        "checkpoint_2": {...}
    }
}
```

每个 `thread_id` 有一个 checkpoint 列表。

---

## 查看 MemorySaver 的内容

### 方法 1：通过 get_state

```python
state = app.get_state(config={"configurable": {"thread_id": "thread_1"}})
print(state.values)
```

### 方法 2：通过 get_state_history

```python
history = list(app.get_state_history(
    config={"configurable": {"thread_id": "thread_1"}}
))

for i, state in enumerate(history):
    print(f"Checkpoint {i}:")
    print(f"  值: {state.values}")
    print(f"  时间: {state.metadata.get('ts')}")
```

### 方法 3：直接访问 MemorySaver 内部（不推荐）

```python
# MemorySaver 内部用 storage 存储
print(checkpointer.storage)
```

checkpointer = MemorySaver()

### 运行时

```python
app.invoke(input, config={"configurable": {"thread_id": "1"}})
# MemorySaver 自动保存 checkpoint
```

### 程序退出

```python
# 程序退出后，MemorySaver 里的所有数据丢失
```

---

## 多个 Graph 共享同一个 MemorySaver

```python
checkpointer = MemorySaver()

# Graph 1
app1 = graph1.compile(checkpointer=checkpointer)

# Graph 2
app2 = graph2.compile(checkpointer=checkpointer)

# app1 和 app2 共享同一个 checkpointer
# 但 thread_id 不同，所以状态不会互相干扰
app1.invoke(input, config={"configurable": {"thread_id": "1"}})
app2.invoke(input, config={"configurable": {"thread_id": "2"}})
```

## MemorySaver 的限制

### 1. 内存占用

每个 checkpoint 都会占用内存。如果对话很长、checkpoint 很多，内存会很大。

**示例**：

```python
# 假设每个 checkpoint 占用 1KB
# 1000 个对话 × 每个对话 100 个 checkpoint = 100MB
```

**解决方案**：
- 定期清理旧的 checkpoint
- 使用持久化的 Checkpointer（如 SqliteSaver）

### 2. 不持久化

程序重启后，所有状态丢失。

**示例**：

```python
# 第一次运行
app.invoke(input, config={"configurable": {"thread_id": "1"}})

# 程序退出、重启

# 第二次运行
app.invoke(input, config={"configurable": {"thread_id": "1"}})
# ⚠️ checkpoint 丢失，从头开始
```

### 3. 不能跨进程

如果你有多个进程（比如多个服务器、多个 worker），它们无法共享 MemorySaver。

---

## 何时使用 MemorySaver？

### ✅ 适合的场景

1. **学习和实验**
   ```python
   # 快速验证 Checkpointer 的行为
   checkpointer = MemorySaver()
   ```

2. **单元测试**
   ```python
   def test_agent():
       checkpointer = MemorySaver()
       app = graph.compile(checkpointer=checkpointer)
       # 测试...
   ```

3. **快速原型开发**
   ```python
   # 快速搭建一个 Demo，不需要配置数据库
   checkpointer = MemorySaver()
   ```

4. **短期会话（几分钟内完成）**
   ```python
   # 用户一次性完成一个任务，不需要持久化
   ```

### ❌ 不适合的场景

1. **生产环境**
   - 程序重启会丢失所有状态

2. **长期对话**
   - 几天、几周的对话，用户期望状态被保存

3. **多进程、分布式系统**
   - 无法跨进程共享状态

4. **大量用户**
   - 内存占用过大

---

## 从 MemorySaver 迁移到持久化 Checkpointer

开发阶段用 MemorySaver，生产环境用持久化 Checkpointer：

### 开发阶段

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)
```

### 生产环境

```python
from langgraph.checkpoint.sqlite import SqliteSaver

checkpointer = SqliteSaver.from_conn_string("checkpoints.db")
app = graph.compile(checkpointer=checkpointer)
```

**只需要改 1 行代码**！其他代码完全不变。

## 实战技巧

### 技巧 1：为不同环境选择 Checkpointer

```python
import os
from langgraph.checkpoint.memory import MemorySaver
from langgraph.checkpoint.sqlite import SqliteSaver

# 根据环境变量选择
if os.getenv("ENV") == "production":
    checkpointer = SqliteSaver.from_conn_string("checkpoints.db")
else:
    checkpointer = MemorySaver()

app = graph.compile(checkpointer=checkpointer)
```

### 技巧 2：在测试中使用独立的 MemorySaver

```python
def test_agent():
    # 每个测试用独立的 checkpointer，避免互相干扰
    checkpointer = MemorySaver()
    app = graph.compile(checkpointer=checkpointer)
    
    result = app.invoke(input, config={"configurable": {"thread_id": "test"}})
    assert result["messages"][-1].content == "期望的回复"
```

### 技巧 3：清理旧的 checkpoint

```python
def clean_old_checkpoints(app, thread_id, keep_latest=10):
    history = list(app.get_state_history(
        config={"configurable": {"thread_id": thread_id}}
    ))
    
    if len(history) > keep_latest:
        # MemorySaver 不支持直接删除，但可以创建新的 checkpointer
        print(f"线程 {thread_id} 有 {len(history)} 个 checkpoint，建议清理")
```
