# 9.3 Sandbox 沙箱环境

生产环境中，Agent 执行代码需要在沙箱中——防止意外破坏。

---

## 沙箱类型

### LangSmith Sandbox

```python
from deepagents.backends.langsmith import LangSmithSandbox
from langsmith.sandbox import SandboxClient

client = SandboxClient()
sandbox = client.create_sandbox()

agent = create_deep_agent(
    model="gpt-5.5",
    backend=LangSmithSandbox(sandbox=sandbox),
)
```

### Gondolin（Kami Code 使用）

Kami Code 使用 Gondolin 扩展——将工具路由到本地 Linux micro-VM 进行容器化隔离。

---

## 沙箱的作用

- **安全隔离**：Agent 的代码执行不会影响宿主系统
- **资源限制**：限制 CPU、内存、网络
- **临时性**：每次执行完自动清理
