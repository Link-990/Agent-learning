# 第五章：Session 管理深入

Pi 的 Session 是树状结构——支持分支、回溯、fork。

---

## 本章学习路线

- **5.1** SessionManager 四种模式
- **5.2** 树状历史记录
- **5.3** Fork / Branch / Switch
- **5.4** Session 发布与分享

---

## 5.1 SessionManager 四种模式

```typescript
SessionManager.inMemory()           // 内存（不持久化）
SessionManager.create(cwd)          // 新建持久化会话
SessionManager.continueRecent(cwd)  // 继续最近会话
SessionManager.open(path)           // 打开指定文件
```

## 5.2 树状历史

每个 entry 有 `parentId`，形成树结构。支持从任意节点分支。

## 5.3 Fork / Branch / Switch

```typescript
const runtime = await createAgentSessionRuntime(...);
await runtime.newSession();                    // 新会话
await runtime.switchSession("/path/to.jsonl"); // 切换
await runtime.fork("entry-id");               // 从某节点分支
```

## 5.4 Session 发布与分享

Session 可以导出为 HTML 或上传到 GitHub Gist 分享。
