# 2.5 运行你的第一个 Pi Agent

---

## CLI 模式

```bash
# 安装
npm install -g @earendil-works/pi-coding-agent

# 启动
pi

# 交互
> 帮我写一个 hello world
```

## SDK 模式

```typescript
import { createAgentSession } from "@earendil-works/pi-coding-agent";

async function main() {
  const { session } = await createAgentSession();

  // 订阅流式输出
  session.subscribe((event) => {
    if (event.type === "message_update" && 
        event.assistantMessageEvent.type === "text_delta") {
      process.stdout.write(event.assistantMessageEvent.delta);
    }
  });

  // 发送消息
  await session.prompt("写一个 Python 快速排序");
  
  console.log("\n完成！");
}

main();
```

## JSON 模式

```bash
# 非交互式，输出 JSON
echo '{"prompt": "hello"}' | pi --json
```

## RPC 模式

```bash
# 通过 stdin/stdout 的 RPC 协议
pi --rpc
```

---

## 小结

Pi 的四种运行模式：
1. **CLI**：交互式终端
2. **SDK**：编程嵌入
3. **JSON**：非交互式输出
4. **RPC**：协议通信
