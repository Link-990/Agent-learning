# 8.1 Skills 系统

Skills 是可复用的行为模块——Agent 可以按需加载。

---

## 用法

```python
agent = create_deep_agent(
    model="gpt-5.5",
    skills=["/skills/personal/", "/skills/coding/"],
)
```

Skills 文件存储在文件系统中，Agent 启动时自动加载。

---

## Skills vs Memory

| | Skills | Memory |
|---|---|---|
| 加载方式 | 按需加载 | 始终加载 |
| 用途 | 特定行为模块 | 持久化上下文 |
| 更新方式 | Agent 可修改 | Agent 可修改 |

---

## 权限控制

Skills 写入可以要求审批：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    skills=["/skills/"],
    permissions=[
        FilesystemPermission(
            operations=["write"],
            paths=["/skills/**"],
            mode="interrupt",
        ),
    ],
    checkpointer=MemorySaver(),
)
```
