# 3.3 搜索工具：glob、grep

---

## glob：按文件名搜索

```
Agent: glob(pattern="**/*.py")
返回: ["src/main.py", "src/utils.py", "tests/test_main.py"]
```

## grep：按内容搜索

```
Agent: grep(pattern="import langgraph", path="src/")
返回: [
    {"file": "src/agent.py", "line": 1, "content": "import langgraph"},
    {"file": "src/tools.py", "line": 3, "content": "from langgraph.graph import ..."},
]
```

---

## 使用场景

- 查找项目中的特定文件
- 搜索代码中的特定函数或变量
- 查找配置文件中的特定设置
