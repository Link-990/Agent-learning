# 第六章：模型管理

Pi 支持 15+ LLM Provider，提供灵活的模型管理。

---

## 本章学习路线

- **6.1** ModelRuntime 详解
- **6.2** 多 Provider 支持
- **6.3** Thinking Level
- **6.4** 模型切换与 scopedModels
- **6.5** 自定义 Provider

---

## 6.1 ModelRuntime

```typescript
const modelRuntime = await ModelRuntime.create();
const available = await modelRuntime.getAvailable();
```

## 6.2 多 Provider

```typescript
getModel("anthropic", "claude-opus-4-5")
getModel("openai", "gpt-5.5")
getModel("google", "gemini-3.5-flash")
getModel("ollama", "llama3")
```

## 6.3 Thinking Level

```typescript
thinkingLevel: "off" | "minimal" | "low" | "medium" | "high" | "xhigh" | "max"
```

## 6.4 scopedModels

可以在会话中切换模型（Ctrl+P）：

```typescript
scopedModels: [
  { model: opus, thinkingLevel: "high" },
  { model: haiku, thinkingLevel: "off" },
]
```

## 6.5 自定义 Provider

通过 `models.json` 添加自定义模型配置。
