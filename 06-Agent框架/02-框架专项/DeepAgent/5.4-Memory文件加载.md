# 5.4 Memory 文件加载

Memory 是 Deep Agents 的持久化上下文——Agent 启动时自动加载。

---

## 用法

```python
agent = create_deep_agent(
    model="gpt-5.5",
    backend=FilesystemBackend(root_dir="./project"),
    memory=[
        "./AGENTS.md",        # 项目指南
        "./CODING_STYLE.md",  # 编码规范
    ],
)
```

---

## AGENTS.md 示例

```markdown
# 项目指南

## 技术栈
- Python 3.11+
- FastAPI
- PostgreSQL

## 编码规范
- 遵循 PEP 8
- 函数必须有 docstring
- 测试覆盖率 > 80%

## 目录结构
- src/：源代码
- tests/：测试
- docs/：文档
```

---

## Memory vs system_prompt

| | system_prompt | Memory |
|---|---|---|
| 加载方式 | 代码中硬编码 | 从文件加载 |
| 持久化 | ❌ | ✅（文件在磁盘上） |
| 可修改 | 需要改代码 | 改文件即可 |
| 适合 | 通用指令 | 项目特定指令 |

---

## Memory 可以被 Agent 更新

Agent 可以用 `write_file` 修改 Memory 文件：

```
Agent: write_file(path="./AGENTS.md", content="更新后的指南...")
```

下次启动时，Agent 会读取更新后的内容。
