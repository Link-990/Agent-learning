# 3.3 注册自定义工具

Extension 最常见的用途——给 Agent 添加新工具。

---

## 示例

```typescript
import type { PiExtension } from "@earendil-works/pi-coding-agent";
import { Type } from "typebox";

const extension: PiExtension = {
  name: "git-tools",
  
  setup(pi) {
    pi.registerTool({
      name: "git_log",
      label: "Git Log",
      description: "Show recent git commits",
      parameters: Type.Object({
        count: Type.Optional(Type.Number({ description: "Number of commits" })),
      }),
      execute: async (_id, params) => {
        const count = params.count || 5;
        const { execSync } = await import("child_process");
        const log = execSync(`git log --oneline -${count}`).toString();
        return {
          content: [{ type: "text", text: log }],
          details: {},
        };
      },
    });
  },
};

export default extension;
```

## Agent 使用工具

```
> 最近的 3 个 commit 是什么？
Agent: [调用 git_log(count=3)]
Agent: 最近的 3 个 commit：
1. abc1234 修复 bug
2. def5678 添加功能
3. ghi9012 更新文档
```
