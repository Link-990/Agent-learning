# 5.2 自动上下文压缩

Deep Agents 内置了自动上下文压缩机制。

---

## 工作原理

```
对话很长（比如 50 条消息）
    ↓
自动触发压缩
    ↓
用 LLM 对旧消息生成摘要
    ↓
摘要替换旧消息
    ↓
保留最近的消息原文
```

---

## 效果

```
压缩前：
- 50 条消息 × 500 tokens = 25,000 tokens

压缩后：
- 摘要 500 tokens + 最近 10 条 × 500 tokens = 5,500 tokens

节省：78%
```

---

## 配置

压缩是自动的，但可以通过 Middleware 自定义：

```python
from langchain.agents.middleware import SummarizationMiddleware

agent = create_deep_agent(
    model="gpt-5.5",
    middleware=[
        SummarizationMiddleware(
            model="gpt-4o-mini",
            max_messages=20,  # 超过 20 条时压缩
        )
    ],
)
```
