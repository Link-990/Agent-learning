# 1.4 包架构总览

Pi 是一个 monorepo，包含 5 个核心包。

---

## 包结构

```
@earendil-works/pi
├── pi-ai            # 统一多 Provider LLM API
├── pi-agent-core    # Agent 运行时 + 工具调用 + 状态管理
├── pi-coding-agent  # 交互式 CLI Agent（主入口）
├── pi-tui           # 终端 UI 库（差分渲染）
└── pi-telemetry     # 可观测性合约
```

---

## 各包职责

### pi-ai

统一的 LLM API 层——屏蔽 OpenAI、Anthropic、Google 等 Provider 的差异。

```typescript
import { getModel } from "@earendil-works/pi-ai";

const model = getModel("anthropic", "claude-opus-4-5");
const response = await model.generate(messages);
```

### pi-agent-core

Agent 的核心运行时——Agent 循环、工具调用、状态管理。

```typescript
import { Agent } from "@earendil-works/pi-agent-core";

const agent = new Agent(options);
await agent.run(messages);
```

### pi-coding-agent

交互式 CLI——这是大多数用户直接接触的包。

```typescript
import { createAgentSession } from "@earendil-works/pi-coding-agent";

const { session } = await createAgentSession();
await session.prompt("帮我写代码");
```

### pi-tui

终端 UI 库——差分渲染，高效更新终端界面。

### pi-telemetry

可观测性合约——供应商中立的追踪标准。
