# 9.2 自定义 Middleware

Deep Agents 继承 LangChain 的 Middleware 系统，同时增加了 `before_agent` / `after_agent` 钩子。

---

## 用法

```python
from langchain.agents.middleware import AgentMiddleware

class SyncMiddleware(AgentMiddleware):
    """在 Agent 执行前后同步文件"""
    
    async def abefore_agent(self, state, runtime):
        """Agent 执行前：从 Store 同步文件到沙箱"""
        user_id = runtime.context.user_id
        # 同步逻辑...
    
    async def aafter_agent(self, state, runtime):
        """Agent 执行后：从沙箱同步文件回 Store"""
        user_id = runtime.context.user_id
        # 同步逻辑...

agent = create_deep_agent(
    model="gpt-5.5",
    middleware=[SyncMiddleware()],
)
```

## Kami Code 的 DeferredToolMiddleware

Kami Code 用自定义 Middleware 实现了工具延迟加载——在 LLM 调用前过滤工具列表。这正是 LangChain Middleware 系统的典型应用。
