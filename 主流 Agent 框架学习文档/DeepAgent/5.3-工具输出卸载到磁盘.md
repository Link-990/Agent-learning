# 5.3 工具输出卸载到磁盘

当工具返回大量数据时，Deep Agents 自动把数据保存到文件，在上下文中只留一个引用。

---

## 工作原理

```
工具返回：10,000 字符的数据
    ↓
Deep Agents 自动保存到文件：/tmp/tool_output_123.txt
    ↓
上下文中只留引用："结果已保存到 /tmp/tool_output_123.txt"
    ↓
Agent 需要时，用 read_file 读取
```

---

## 效果

```
不卸载：
- 工具输出 10,000 字符 ≈ 2,500 tokens
- 10 次工具调用 = 25,000 tokens

卸载后：
- 每次只在上下文中留 50 tokens 的引用
- 10 次工具调用 = 500 tokens

节省：98%
```

---

## 提示 Agent 使用

在 system_prompt 中提示 Agent 把大数据保存到文件：

```python
system_prompt = """当收集大量数据时：
1. 把原始数据保存到 /data/raw_results.txt
2. 只保留分析摘要在上下文中
"""
```
