# 3.4 add_node() 与 add_edge()——组装工作流

学会了定义 State，现在我们来学习如何用 `add_node()` 和 `add_edge()` 把节点"组装"成一个完整的工作流。

这一节会通过大量实例，让你彻底掌握节点和边的组装技巧。

---

## 回顾：基本语法

### add_node()

```python
graph.add_node(name: str, func: Callable)
```

- `name`：节点名（字符串）
- `func`：节点函数

### add_edge()

```python
graph.add_edge(from_node: str, to_node: str)
```

- `from_node`：起点节点
- `to_node`：终点节点

---

## 模式 1：线性流程

最简单的流程：A → B → C → D

```python
from langgraph.graph import StateGraph, START, END
from typing import TypedDict

class State(TypedDict):
    value: int

def add_10(state):
    return {"value": state["value"] + 10}

def multiply_2(state):
    return {"value": state["value"] * 2}

def subtract_5(state):
    return {"value": state["value"] - 5}

graph = StateGraph(State)
graph.add_node("add", add_10)
graph.add_node("multiply", multiply_2)
graph.add_node("subtract", subtract_5)

# 线性连接
graph.add_edge(START, "add")
graph.add_edge("add", "multiply")
graph.add_edge("multiply", "subtract")
graph.add_edge("subtract", END)

app = graph.compile()
result = app.invoke({"value": 0})
print(result)  # {"value": 15}
# 0 + 10 = 10 → 10 * 2 = 20 → 20 - 5 = 15
```

**流程图**：

```
START → add → multiply → subtract → END
```

## 模式 2：分支（条件路由）

执行完 A，根据情况去 B 或 C。

```python
from langgraph.graph import StateGraph, START, END
from typing import TypedDict

class State(TypedDict):
    value: int
    path: str

def check_value(state):
    if state["value"] > 10:
        return {"path": "large"}
    else:
        return {"path": "small"}

def handle_large(state):
    return {"value": state["value"] * 2}

def handle_small(state):
    return {"value": state["value"] + 100}

def router(state):
    return state["path"]

graph = StateGraph(State)
graph.add_node("check", check_value)
graph.add_node("large", handle_large)
graph.add_node("small", handle_small)

graph.add_edge(START, "check")
graph.add_conditional_edges(
    "check",
    router,
    {
        "large": "large",
        "small": "small"
    }
)
graph.add_edge("large", END)
graph.add_edge("small", END)

app = graph.compile()

# 测试：value = 5（走 small 分支）
result = app.invoke({"value": 5, "path": ""})
print(result)  # {"value": 105, "path": "small"}

# 测试：value = 15（走 large 分支）
result = app.invoke({"value": 15, "path": ""})
print(result)  # {"value": 30, "path": "large"}
```

**流程图**：

```
START → check → router
              ├─ large → END
              └─ small → END
```

## 模式 3：循环（节点回到自己）

Agent 反复调用工具，直到不再需要工具。

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

def call_llm(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

def should_continue(state):
    last_message = state["messages"][-1]
    # 如果 LLM 返回了工具调用，继续循环
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"
    else:
        return "end"

def call_tools(state):
    # 这里模拟工具调用
    return {"messages": [{"role": "tool", "content": "工具返回结果"}]}

graph = StateGraph(MessagesState)
graph.add_node("llm", call_llm)
graph.add_node("tools", call_tools)

graph.add_edge(START, "llm")
graph.add_conditional_edges(
    "llm",
    should_continue,
    {
        "tools": "tools",
        "end": END
    }
)
graph.add_edge("tools", "llm")  # 工具 → LLM，形成循环

app = graph.compile()
```

**流程图**：

```
START → llm ⇄ tools
         ↓
        END
```

LLM 和 tools 之间形成循环，直到 LLM 不再需要工具。

## 模式 4：并行执行

从 A 出来，同时执行 B 和 C。

```python
from langgraph.graph import StateGraph, START, END
from typing import TypedDict
import time

class State(TypedDict):
    result_b: str
    result_c: str

def task_b(state):
    time.sleep(1)  # 模拟耗时操作
    return {"result_b": "B 完成"}

def task_c(state):
    time.sleep(1)
    return {"result_c": "C 完成"}

def merge(state):
    # 汇总结果
    return {"result": f"{state['result_b']} + {state['result_c']}"}

graph = StateGraph(State)
graph.add_node("b", task_b)
graph.add_node("c", task_c)
graph.add_node("merge", merge)

# 并行：START 同时连到 b 和 c
graph.add_edge(START, "b")
graph.add_edge(START, "c")

# 汇总：b 和 c 都连到 merge
graph.add_edge("b", "merge")
graph.add_edge("c", "merge")
graph.add_edge("merge", END)

app = graph.compile()
result = app.invoke({"result_b": "", "result_c": ""})
print(result)
```

**流程图**：

```
      ┌→ b ┐
START         → merge → END
      └→ c ┘
```

b 和 c 并行执行，都完成后，才执行 merge。

## 模式 5：多层条件路由

复杂的决策树。

```python
def router_1(state):
    if state["type"] == "A":
        return "node_a"
    else:
        return "router_2"

def router_2(state):
    if state["sub_type"] == "B1":
        return "node_b1"
    else:
        return "node_b2"

graph = StateGraph(State)
graph.add_node("node_a", node_a_func)
graph.add_node("router_2_node", lambda s: {})  # 空节点
graph.add_node("node_b1", node_b1_func)
graph.add_node("node_b2", node_b2_func)

graph.add_edge(START, "decision")
graph.add_conditional_edges(
    "decision",
    router_1,
    {
        "node_a": "node_a",
        "router_2": "router_2_node"
    }
)
graph.add_conditional_edges(
    "router_2_node",
    router_2,
    {
        "node_b1": "node_b1",
        "node_b2": "node_b2"
    }
)
graph.add_edge("node_a", END)
graph.add_edge("node_b1", END)
graph.add_edge("node_b2", END)
```

**流程图**：

```
START → decision
         ├─ A → node_a → END
         └─ not A → router_2
                      ├─ B1 → node_b1 → END
                      └─ B2 → node_b2 → END
```

## 模式 6：错误处理

执行出错时，跳到错误处理节点。

```python
from langgraph.graph import StateGraph, START, END
from typing import TypedDict

class State(TypedDict):
    value: int
    error: str

def risky_operation(state):
    try:
        result = 100 / state["value"]
        return {"value": result}
    except ZeroDivisionError:
        return {"error": "除零错误"}

def router(state):
    if state.get("error"):
        return "error_handler"
    else:
        return "success"

def error_handler(state):
    print(f"处理错误：{state['error']}")
    return {}

def success_handler(state):
    print(f"成功：{state['value']}")
    return {}

graph = StateGraph(State)
graph.add_node("risky", risky_operation)
graph.add_node("error_handler", error_handler)
graph.add_node("success", success_handler)

graph.add_edge(START, "risky")
graph.add_conditional_edges(
    "risky",
    router,
    {
        "error_handler": "error_handler",
        "success": "success"
    }
)
graph.add_edge("error_handler", END)
graph.add_edge("success", END)

app = graph.compile()

# 测试正常情况
app.invoke({"value": 10, "error": ""})  # 输出：成功：10.0

# 测试错误情况
app.invoke({"value": 0, "error": ""})   # 输出：处理错误：除零错误
```

## 实用技巧

### 技巧 1：用变量管理节点名

避免字符串拼错：

```python
NODE_LLM = "llm"
NODE_TOOLS = "tools"

graph.add_node(NODE_LLM, call_llm)
graph.add_node(NODE_TOOLS, call_tools)
graph.add_edge(START, NODE_LLM)
graph.add_edge(NODE_LLM, NODE_TOOLS)
```

### 技巧 2：批量添加节点

```python
nodes = {
    "node_a": func_a,
    "node_b": func_b,
    "node_c": func_c
}

for name, func in nodes.items():
    graph.add_node(name, func)
```

### 技巧 3：用列表定义线性流程

```python
pipeline = ["node_a", "node_b", "node_c"]

for i in range(len(pipeline) - 1):
    graph.add_edge(pipeline[i], pipeline[i + 1])
```

### 技巧 4：检查图的完整性

编译前，打印图结构：

```python
print(graph.nodes)  # 查看所有节点
print(graph.edges)  # 查看所有边
```

## 常见错误

### 错误 1：忘记连到 END

```python
graph.add_node("last_node", func)
graph.add_edge(START, "last_node")
# 忘了：graph.add_edge("last_node", END)

app = graph.compile()  # 报错！
```

**解决**：确保每个"叶子节点"都连到 END。

### 错误 2：条件路由的路径缺失

```python
def router(state):
    return state["path"]  # 可能返回 "A", "B", "C"

graph.add_conditional_edges(
    "decision",
    router,
    {
        "A": "node_a",
        "B": "node_b"
        # 缺少 "C" 的路径！
    }
)
```

**运行时报错**：`Path 'C' not found in path_map`

**解决**：确保 router 返回的所有可能值，都在 path_map 里。

### 错误 3：循环没有出口

```python
graph.add_edge("A", "B")
graph.add_edge("B", "A")  # 死循环！
```

**运行时会无限执行**。

**解决**：确保循环有出口（条件路由到 END）。

---

## 小结

组装工作流的核心：
1. **add_node()**：添加节点
2. **add_edge()**：连接节点

常见模式：
- 线性流程：A → B → C
- 分支：A → 判断 → B 或 C
- 循环：A ⇄ B
- 并行：A → B + C → D
- 错误处理：正常流 vs 错误流

掌握这些模式，你就能设计出任意复杂的 Agent 工作流。
