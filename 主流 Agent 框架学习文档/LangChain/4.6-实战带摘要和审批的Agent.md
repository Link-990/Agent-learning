# 4.6 实战：构建带摘要和审批的 Agent

这一节我们综合前面的知识，构建一个完整的带 Middleware 的 Agent。

---

## 需求

一个客服 Agent，具备：
1. **长对话自动摘要**（SummarizationMiddleware）
2. **危险操作人工审批**（HumanInTheLoopMiddleware）
3. **日志记录**（自定义 LoggingMiddleware）
4. **成本追踪**（自定义 CostTrackerMiddleware）

---

## 完整代码

```python
from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain.agents.middleware import (
    AgentMiddleware,
    SummarizationMiddleware,
    HumanInTheLoopMiddleware,
)
from langchain_core.tools import tool
from langchain_core.messages import AIMessage

load_dotenv()

# ========== 自定义 Middleware ==========
class LoggingMiddleware(AgentMiddleware):
    def wrap_model_call(self, request, handler):
        print(f"\n{'='*50}")
        print(f"📝 LLM 调用：{len(request.messages)} 条消息")
        response = handler(request)
        print(f"✅ LLM 返回完成")
        print(f"{'='*50}\n")
        return response

class CostTrackerMiddleware(AgentMiddleware):
    def __init__(self):
        self.total_tokens = 0
    
    def wrap_model_call(self, request, handler):
        response = handler(request)
        usage = getattr(response.message, "usage_metadata", {})
        tokens = usage.get("input_tokens", 0) + usage.get("output_tokens", 0)
        self.total_tokens += tokens
        print(f"💰 Token 消耗：{tokens}，累计：{self.total_tokens}")
        return response

# ========== 工具 ==========
@tool
def answer_question(question: str) -> str:
    """回答用户的常见问题"""
    faqs = {
        "退款": "请联系客服，提供订单号即可申请退款",
        "物流": "一般 3-5 个工作日送达",
    }
    for key, answer in faqs.items():
        if key in question:
            return answer
    return "抱歉，我不确定这个问题。请联系人工客服。"

@tool
def process_refund(order_id: str) -> str:
    """处理退款（危险操作，需要审批）"""
    return f"✅ 订单 {order_id} 的退款已处理"

@tool
def send_notification(message: str) -> str:
    """发送通知"""
    return f"✅ 通知已发送：{message}"

# ========== 创建 Agent ==========
agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[answer_question, process_refund, send_notification],
    system_prompt="""你是一个电商客服助手。
    
你可以：
- 回答常见问题
- 处理退款（需要确认）
- 发送通知

用中文回答。
""",
    middleware=[
        LoggingMiddleware(),
        SummarizationMiddleware(
            model="openai:gpt-4o-mini",
            max_messages=20,
        ),
        HumanInTheLoopMiddleware(
            tool_names=["process_refund"],  # 退款需要人工审批
        ),
        CostTrackerMiddleware(),
    ]
)

# ========== 测试 ==========
if __name__ == "__main__":
    # 普通问答（不需要审批）
    print("=== 测试 1：普通问答 ===")
    result = agent.invoke(
        {"messages": [{"role": "user", "content": "怎么退款？"}]}
    )
    print(f"AI: {result['messages'][-1].content}\n")
    
    # 退款操作（需要审批）
    print("=== 测试 2：退款操作（需要审批）===")
    result = agent.invoke(
        {"messages": [{"role": "user", "content": "帮我退款，订单号 1001"}]}
    )
    # 这里会暂停等待审批
```

## 小结

通过 Middleware，我们给 Agent 添加了：
- ✅ 日志记录
- ✅ 长对话摘要
- ✅ 人工审批
- ✅ 成本追踪

每个功能都是独立的 Middleware，互不干扰，可插拔。
