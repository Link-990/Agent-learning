# 2.2 多 Provider 支持

LangChain 支持十几个 LLM Provider。这一节我们看看都有哪些，以及如何切换。

---

## 支持的 Provider 列表

| Provider | Provider 字符串 | 安装命令 | 模型示例 |
|----------|---------------|---------|---------|
| OpenAI | `openai:` | `pip install langchain-openai` | `gpt-5.5`, `gpt-4o-mini` |
| Anthropic | `anthropic:` | `pip install langchain-anthropic` | `claude-sonnet-4-6`, `claude-opus-4-5` |
| Google | `google_genai:` | `pip install langchain-google-genai` | `gemini-3.5-flash`, `gemini-2.5-pro` |
| Ollama | `ollama:` | `pip install langchain-ollama` | `llama3`, `north-mini-code-1.0` |
| OpenRouter | `openrouter:` | `pip install langchain-openrouter` | `anthropic/claude-sonnet-4-6` |
| Fireworks | `fireworks:` | `pip install langchain-fireworks` | `accounts/fireworks/models/qwen3p5-397b-a17b` |
| Baseten | `baseten:` | `pip install langchain-baseten` | `zai-org/GLM-5.2` |
| Azure OpenAI | 通过 `ChatOpenAI(base_url=...)` | `pip install langchain-openai` | `gpt-5.4-mini` |
| AWS Bedrock | `bedrock_converse:` | `pip install langchain-aws` | `us.anthropic.claude-sonnet-4-6` |
| HuggingFace | `huggingface:` | `pip install langchain-huggingface` | `microsoft/Phi-3-mini-4k-instruct` |

---

## 切换 Provider

### 方式 1：改 Provider 字符串

```python
from langchain.agents import create_agent

# 用 OpenAI
agent = create_agent(model="openai:gpt-5.5", tools=[])

# 换成 Anthropic
agent = create_agent(model="anthropic:claude-sonnet-4-6", tools=[])

# 换成本地 Ollama
agent = create_agent(model="ollama:llama3", tools=[])
```

### 方式 2：用 init_chat_model()

```python
from langchain.chat_models import init_chat_model

# 统一接口
llm = init_chat_model("openai:gpt-5.5")
llm = init_chat_model("anthropic:claude-sonnet-4-6")
llm = init_chat_model("google_genai:gemini-3.5-flash")
```

---

## API Key 配置

每个 Provider 需要对应的 API Key：

```bash
# .env 文件
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=AI...
FIREWORKS_API_KEY=...
OPENROUTER_API_KEY=...
```

---

## Kami Code 中的多 Provider 支持

Kami Code 通过 `deepagents` 框架支持多 Provider：

```python
# 在 create_deep_agent 中指定 Provider
agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    ...
)
```

底层的 `ModelRuntime` 负责管理不同 Provider 的认证和调用。

---

## 小结

- LangChain 支持十几个 Provider
- 用 `provider:model` 字符串格式切换
- 每个 Provider 需要对应的 API Key
- `init_chat_model()` 提供统一接口
