# 9.1 Memory Namespace 配置

多用户场景下，不同用户的记忆需要隔离。

---

## 按用户隔离

```python
from deepagents import create_deep_agent
from deepagents.backends import CompositeBackend, StoreBackend, StateBackend

agent = create_deep_agent(
    model="gpt-5.5",
    backend=CompositeBackend(
        default=StateBackend(),
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: ("memories", rt.context.user_id),
            ),
        },
    ),
)
```

---

## 按组织隔离

```python
routes={
    "/memories/": StoreBackend(
        namespace=lambda rt: ("memories", rt.context.org_id),
    ),
}
```

## 按 Agent 隔离

```python
routes={
    "/memories/": StoreBackend(
        namespace=lambda rt: (rt.server_info.assistant_id,),
    ),
}
```
