# 5.5 Context Schema 与 ToolRuntime

与 LangChain 的 ToolRuntime 机制相同——为工具注入运行时上下文。

---

## 用法

```python
from dataclasses import dataclass
from deepagents import create_deep_agent
from langchain.tools import tool, ToolRuntime

@dataclass
class Context:
    user_id: str
    session_id: str

@tool
def get_user_data(query: str, runtime: ToolRuntime[Context]) -> str:
    """获取用户数据"""
    user_id = runtime.context.user_id
    return f"用户 {user_id} 的数据：{query}"

agent = create_deep_agent(
    model="gpt-5.5",
    tools=[get_user_data],
    context_schema=Context,
)

# 调用时传入上下文
result = agent.invoke(
    {"messages": [{"role": "user", "content": "查看我的数据"}]},
    context=Context(user_id="user-123", session_id="abc"),
)
```

---

## 子 Agent 自动继承上下文

上下文会自动传递给子 Agent：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    tools=[get_user_data],
    context_schema=Context,
    subagents=[
        {"name": "researcher", "description": "...", "system_prompt": "..."},
    ],
)

# 上下文自动传给 researcher 子 Agent
result = agent.invoke(
    {"messages": [{"role": "user", "content": "查看我的数据"}]},
    context=Context(user_id="user-123", session_id="abc"),
)
```
