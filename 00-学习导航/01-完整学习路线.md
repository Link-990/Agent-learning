# 完整学习路线

## 第一阶段：基础与模型

从 [01-基础与模型](../01-基础与模型/README.md) 开始。先掌握 Python 对象、并发、内存和 I/O，再理解 Transformer、Attention、生成过程和 KV Cache。目标不是背 API，而是能说清一次输入如何被处理、一次任务如何占用执行资源。

## 第二阶段：Agent 核心原理

进入 [02-Agent核心原理](../02-Agent核心原理/README.md)。重点是 LLM、Agent、Workflow 的控制权差异，Agent Loop、推理范式、记忆、上下文和 Multi-Agent。每一节都要区分“模型提出意图”和“运行时真正执行”。

## 第三阶段：Agent Runtime

进入 [03-Agent-Runtime](../03-Agent-Runtime/README.md)，按 00–11 课顺序学习。课程从同步函数开始，逐步增加线程、事件循环、队列、状态机、Agent 决策、Tool、MCP、Checkpoint、人工审批和可观测性，最后完成研究助理 Capstone。

## 第四阶段：RAG 与工具

先读 [04-RAG与知识库](../04-RAG与知识库/README.md)，理解数据接入、分块、Embedding、召回、Rerank、版本和权限；再读 [05-工具、协议与能力封装](../05-工具、协议与能力封装/README.md)，把 Function Calling、MCP、Skills 和平台事件放到 Runtime 边界里理解。

## 第五阶段：框架与生产化

进入 [06-Agent框架](../06-Agent框架/README.md)，重点看不同框架怎样实现状态、工具、编排、持久化和人机协同。然后进入 [07-企业级工程化](../07-企业级工程化/README.md)，学习身份、权限、安全、成本、可观测性、灰度和恢复。

## 第六阶段：综合输出

用 [08-场景实战](../08-场景实战/README.md) 练习把业务问题拆成 Agent、Workflow、RAG 和 Tool；用 [09-系统设计](../09-系统设计/README.md) 练习架构推导；最后用 [10-项目深挖与模拟面试](../10-项目深挖与模拟面试/README.md) 练习 30 秒、2 分钟和 5 分钟回答。

## 可选分支

基础与模型之后，可以进入 [90-模型训练与对齐](../90-模型训练与对齐/README.md)，学习 SFT、PEFT、RLHF、PPO、DPO 和 GRPO。它与 Agent 应用主线相互关联，但不是应用开发的必修前置。
