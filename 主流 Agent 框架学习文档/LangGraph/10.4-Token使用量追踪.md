# 10.4 Token 使用量追踪

在生产环境中，追踪 Token 使用量非常重要——它直接关系到成本和性能。Kami Code 展示了如何从 LangGraph 的流式输出中提取 Token 使用信息。

---

## Token 使用量在哪里？

Token 使用量信息在 LLM 返回的消息对象中：

```python
# AIMessage 对象
AIMessage(
    content="回复内容",
    usage_metadata={
        "input_tokens": 150,
        "output_tokens": 80,
        "total_tokens": 230,
        "input_token_details": {
            "cache_read": 100  # 缓存命中的 tokens
        }
    }
)
```

---

## 提取代码解读

```python
def usage_from_message(message, *, model: str):
    """从消息对象中提取 Token 使用量"""
    usage_metadata = getattr(message, "usage_metadata", None)
    
    if not usage_metadata:
        return None
    
    return UsageMetrics(
        model=model,
        input_tokens=usage_metadata.get("input_tokens", 0),
        output_tokens=usage_metadata.get("output_tokens", 0),
        cache_read_tokens=usage_metadata.get("input_token_details", {}).get("cache_read", 0),
    )

def usage_from_stream_chunk(chunk, *, model: str):
    """从流式 chunk 中提取 Token 使用量"""
    message = _stream_message(chunk)
    role = _message_role(message)
    
    # 只从 assistant 消息中提取
    if role == "assistant":
        return usage_from_message(message, model=model)
    
    # 或者从 model 节点的 unknown 消息中提取
    if role == "unknown" and _stream_node(chunk) == "model":
        return usage_from_message(message, model=model)
    
    return None
```

## 累计统计

```python
class UsageAccumulator:
    """Token 使用量累计器"""
    
    def __init__(self, model: str):
        self.model = model
        self.total_input = 0
        self.total_output = 0
        self.total_cache_read = 0
    
    def observe(self, usage: UsageMetrics | None):
        """累加一次调用的使用量"""
        if usage is None:
            return
        
        self.total_input += usage.input_tokens
        self.total_output += usage.output_tokens
        self.total_cache_read += usage.cache_read_tokens
    
    def summary(self) -> dict:
        """返回汇总"""
        return {
            "model": self.model,
            "total_input_tokens": self.total_input,
            "total_output_tokens": self.total_output,
            "total_cache_read_tokens": self.total_cache_read,
            "total_tokens": self.total_input + self.total_output,
        }
```

---

## 完整流程

```python
# 在适配器中使用
def stream_events(self, payload):
    usage_accumulator = UsageAccumulator(model=self.model_profile.name)
    
    for chunk in self._agent.stream(payload, stream_mode="messages"):
        # 1. 提取 Token 使用量
        usage = usage_from_stream_chunk(chunk, model=self.model_profile.name)
        usage_accumulator.observe(usage)
        
        # 2. 转换为事件
        yield from self._message_stream_chunk_to_events(chunk)
    
    # 3. 输出汇总
    print(f"Token 使用量: {usage_accumulator.summary()}")
```

---

## 小结

Token 追踪的要点：
1. Token 信息在 `AIMessage.usage_metadata` 中
2. 只有 `model` 节点的 assistant 消息有 Token 信息
3. 用 `UsageAccumulator` 累计多次调用的使用量
4. 关注 `input_tokens`、`output_tokens`、`cache_read_tokens`
