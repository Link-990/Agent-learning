# 1.1 Pi Agent 是什么？

## 一句话理解

> **Pi 是一个极简的 AI Coding Agent 框架——提供交互式 CLI、SDK、RPC 三种运行模式，通过 Extension 系统实现高度可扩展。**

---

## Pi 的两种身份

### 1. Coding Agent CLI（终端编程助手）

类似 Claude Code、Cursor——在终端中与 AI 对话，让 AI 帮你写代码、改文件、跑命令。

```bash
pi  # 启动交互式 CLI
> 帮我写一个排序算法
```

### 2. SDK（可编程的 Agent 框架）

把 Pi 嵌入到你自己的应用中：

```typescript
import { createAgentSession } from "@earendil-works/pi-coding-agent";

const { session } = await createAgentSession();
await session.prompt("帮我写代码");
```

---

## Pi 的核心特点

1. **极简核心**：刻意不内置 MCP、子 Agent、权限弹窗——通过 Extension 自行构建
2. **TypeScript 原生**：Extension 用 TypeScript 编写，深度集成
3. **树状历史**：对话以树结构存储，支持分支、回溯
4. **自修改**：Pi 可以在运行时修改自身代码
5. **多 Provider**：支持 15+ LLM 提供商

---

## Pi 不是什么

- ❌ 不是一个 Agent 编排框架（那是 LangGraph 的事）
- ❌ 不是一个 Python 框架（Pi 是纯 TypeScript）
- ❌ 不是一个"开箱即用的产品"（Pi 更像一个"框架"，需要你自己扩展）
