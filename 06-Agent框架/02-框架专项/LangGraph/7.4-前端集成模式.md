# 7.4 前端集成模式

在实际应用中，Agent 通常是后端服务，前端（Web、App）需要实时展示 Agent 的执行过程。

这一节我们学习如何把 LangGraph 的流式输出集成到前端。

---

## 架构概览

```
前端（Web/App）
    ↕ WebSocket / SSE
后端（LangGraph Agent）
    ↕
LLM / Tools
```

前端通过 **WebSocket** 或 **Server-Sent Events (SSE)** 与后端通信，实时接收流式事件。

---

## 模式 1：WebSocket 集成

### 后端（FastAPI + WebSocket）

```python
from fastapi import FastAPI, WebSocket
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_openai import ChatOpenAI

app = FastAPI()

# ... 定义 Agent ...

@app.websocket("/chat")
async def chat(websocket: WebSocket):
    await websocket.accept()
    
    while True:
        # 接收用户消息
        user_message = await websocket.receive_text()
        
        # 流式执行 Agent
        for event in agent.stream_events(
            {"messages": [{"role": "user", "content": user_message}]},
            version="v2"
        ):
            event_type = event["event"]
            
            if event_type == "on_chat_model_stream":
                content = event["data"]["chunk"].content
                if content:
                    # 发送 token 到前端
                    await websocket.send_json({
                        "type": "token",
                        "content": content
                    })
            
            elif event_type == "on_tool_start":
                await websocket.send_json({
                    "type": "tool_call",
                    "name": event["name"],
                    "input": event["data"]["input"]
                })
            
            elif event_type == "on_tool_end":
                await websocket.send_json({
                    "type": "tool_result",
                    "output": event["data"]["output"]
                })
        
        # 发送完成信号
        await websocket.send_json({"type": "done"})
```

### 前端（JavaScript）

```javascript
const ws = new WebSocket("ws://localhost:8000/chat");

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    
    if (data.type === "token") {
        // 实时显示 LLM 输出
        document.getElementById("response").innerText += data.content;
    }
    
    else if (data.type === "tool_call") {
        // 显示工具调用
        console.log(`调用工具：${data.name}`);
    }
    
    else if (data.type === "tool_result") {
        // 显示工具结果
        console.log(`工具结果：${data.output}`);
    }
    
    else if (data.type === "done") {
        console.log("执行完成");
    }
};

// 发送消息
ws.send("你好");
```

## 模式 2：SSE（Server-Sent Events）集成

### 后端（FastAPI + SSE）

```python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import json

app = FastAPI()

@app.get("/chat")
async def chat(message: str):
    async def generate():
        for event in agent.stream_events(
            {"messages": [{"role": "user", "content": message}]},
            version="v2"
        ):
            event_type = event["event"]
            
            if event_type == "on_chat_model_stream":
                content = event["data"]["chunk"].content
                if content:
                    data = json.dumps({"type": "token", "content": content})
                    yield f"data: {data}\n\n"
            
            elif event_type == "on_tool_start":
                data = json.dumps({
                    "type": "tool_call",
                    "name": event["name"]
                })
                yield f"data: {data}\n\n"
        
        yield "data: {\"type\": \"done\"}\n\n"
    
    return StreamingResponse(generate(), media_type="text/event-stream")
```

### 前端（JavaScript）

```javascript
const source = new EventSource("/chat?message=你好");

source.onmessage = (event) => {
    const data = JSON.parse(event.data);
    
    if (data.type === "token") {
        document.getElementById("response").innerText += data.content;
    }
    
    else if (data.type === "done") {
        source.close();
    }
};
```

## 模式 3：LangServe 集成

LangChain 提供了 **LangServe**，专门用于部署 LangGraph Agent。

### 安装

```bash
pip install langserve
```

### 部署 Agent

```python
from fastapi import FastAPI
from langserve import add_routes

app = FastAPI()

# 添加 LangGraph 路由
add_routes(app, agent, path="/agent")

# 现在可以通过以下 URL 访问：
# POST /agent/invoke - 同步调用
# POST /agent/stream - 流式调用
# POST /agent/stream_events - 事件流
```

### 前端调用

```javascript
// 流式调用
const response = await fetch("/agent/stream_events", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({
        input: {"messages": [{"role": "user", "content": "你好"}]}
    })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
    const {done, value} = await reader.read();
    if (done) break;
    
    const text = decoder.decode(value);
    const events = text.split("\n").filter(line => line.trim());
    
    for (const event of events) {
        const data = JSON.parse(event);
        if (data.event === "on_chat_model_stream") {
            console.log(data.data.chunk.content);
        }
    }
}
```

## 小结

前端集成模式：

1. **WebSocket**：双向通信，适合实时对话
2. **SSE**：单向推送，适合流式输出
3. **LangServe**：开箱即用的部署方案

前端设计要点：
- 实时显示 LLM 输出（打字机效果）
- 显示工具调用进度
- 显示整体执行进度
