# 7.1 interrupt_on 配置

`interrupt_on` 指定哪些工具调用前需要人工审批。

---

## 用法

```python
from langgraph.checkpoint.memory import MemorySaver

agent = create_deep_agent(
    model="gpt-5.5",
    interrupt_on={
        "write_file": True,   # 写文件前审批
        "edit_file": True,    # 编辑文件前审批
        "delete": True,       # 删除文件前审批
        "execute": True,      # 执行命令前审批
        "read_file": False,   # 读文件不审批
        "ls": False,          # 列目录不审批
    },
    checkpointer=MemorySaver(),  # 必须有 checkpointer
)
```

---

## 审批流程

```
Agent 想调用 write_file
    ↓
[暂停] 等待人工审批
    ↓
人类审批
    ├─ approve → 继续执行
    ├─ edit → 修改参数后执行
    └─ reject → 取消
```
