# 3.6 实战：写一个 Extension

综合前面的知识，写一个完整的 Extension。

---

## 功能

一个"代码分析" Extension：
- 工具：`analyze_code` — 分析代码复杂度
- 命令：`/stats` — 显示项目统计
- 事件：记录所有工具调用

---

## 完整代码

```typescript
// ~/.pi/agent/extensions/code-analyzer.ts
import type { PiExtension } from "@earendil-works/pi-coding-agent";
import { Type } from "typebox";
import { execSync } from "child_process";
import fs from "fs";

const extension: PiExtension = {
  name: "code-analyzer",
  
  setup(pi) {
    // 1. 注册工具
    pi.registerTool({
      name: "analyze_code",
      label: "Code Analyzer",
      description: "Analyze code complexity and quality",
      parameters: Type.Object({
        filePath: Type.String({ description: "File to analyze" }),
      }),
      execute: async (_id, params) => {
        try {
          const content = fs.readFileSync(params.filePath, "utf-8");
          const lines = content.split("\n").length;
          const functions = (content.match(/function|def |=>/g) || []).length;
          const complexity = Math.floor(lines / Math.max(functions, 1));
          
          return {
            content: [{
              type: "text",
              text: `分析结果：\n- 总行数：${lines}\n- 函数数：${functions}\n- 平均函数长度：${complexity} 行`,
            }],
            details: { lines, functions, complexity },
          };
        } catch (e) {
          return {
            content: [{ type: "text", text: `错误：${e}` }],
            details: {},
          };
        }
      },
    });
    
    // 2. 注册命令
    pi.registerCommand({
      name: "stats",
      description: "Show project statistics",
      execute: async () => {
        const files = execSync("find . -name '*.ts' -o -name '*.js' | wc -l").toString().trim();
        const loc = execSync("find . -name '*.ts' -o -name '*.js' | xargs wc -l | tail -1").toString().trim();
        console.log(`项目统计：\n- 文件数：${files}\n- 代码行数：${loc}`);
      },
    });
    
    // 3. 监听事件
    pi.on("tool_call", (event) => {
      const log = `[${new Date().toISOString()}] ${event.toolName}\n`;
      fs.appendFileSync("tool_calls.log", log);
    });
  },
};

export default extension;
```

## 使用

```
> 分析一下 src/main.ts 的代码质量
Agent: [调用 analyze_code(filePath="src/main.ts")]
Agent: 分析结果：
- 总行数：150
- 函数数：8
- 平均函数长度：18 行

> /stats
项目统计：
- 文件数：42
- 代码行数：3,500
```
