# 8.3 Swarm / Handoff 模式：Agent 之间自主交接

与 Supervisor 模式不同，Swarm 模式没有中心化的"领导"——Agent 之间可以**自主交接**，根据情况把任务转给最合适的 Agent。

---

## 架构

```
Agent A ⇄ Agent B ⇄ Agent C
```

没有中心节点，Agent 之间直接通信。

---

## 与 Supervisor 的区别

| 特性 | Supervisor | Swarm |
|------|-----------|-------|
| 控制方式 | 中心化 | 去中心化 |
| 决策者 | Supervisor | 当前执行的 Agent |
| 灵活性 | 较低 | 较高 |
| 复杂度 | 简单 | 复杂 |

---

## 实现：Handoff 工具

在 LangGraph 中，Swarm 模式通常通过"交接工具"实现——每个 Agent 有一个 `transfer_to_agent` 工具，可以把对话转给其他 Agent。

### 完整示例

```python
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langgraph.graph import StateGraph, MessagesState, START, END
from typing import TypedDict
from langchain_core.messages import BaseMessage

class SwarmState(TypedDict):
    messages: list[BaseMessage]
    current_agent: str  # 当前负责的 Agent

# ========== 定义交接工具 ==========
@tool
def transfer_to_billing():
    """转交给账单处理 Agent"""
    return "transferred_to_billing"

@tool
def transfer_to_tech_support():
    """转交给技术支持 Agent"""
    return "transferred_to_tech_support"

@tool
def transfer_to_complaints():
    """转交给投诉处理 Agent"""
    return "transferred_to_complaints"

# ========== 定义 Agent ==========
billing_llm = ChatOpenAI(model="gpt-4o-mini")

def billing_agent_node(state: SwarmState):
    """账单处理 Agent"""
    tools = [transfer_to_tech_support, transfer_to_complaints]
    llm_with_tools = billing_llm.bind_tools(tools)
    
    response = llm_with_tools.invoke([
        {"role": "system", "content": "你是账单处理专家。如果问题不属于你的领域，使用转交工具。"},
        *state["messages"]
    ])
    
    return {"messages": [response]}

tech_llm = ChatOpenAI(model="gpt-4o-mini")

def tech_support_agent_node(state: SwarmState):
    """技术支持 Agent"""
    tools = [transfer_to_billing, transfer_to_complaints]
    llm_with_tools = tech_llm.bind_tools(tools)
    
    response = llm_with_tools.invoke([
        {"role": "system", "content": "你是技术支持专家。如果问题不属于你的领域，使用转交工具。"},
        *state["messages"]
    ])
    
    return {"messages": [response]}

complaints_llm = ChatOpenAI(model="gpt-4o-mini")

def complaints_agent_node(state: SwarmState):
    """投诉处理 Agent"""
    tools = [transfer_to_billing, transfer_to_tech_support]
    llm_with_tools = complaints_llm.bind_tools(tools)
    
    response = llm_with_tools.invoke([
        {"role": "system", "content": "你是投诉处理专家。如果问题不属于你的领域，使用转交工具。"},
        *state["messages"]
    ])
    
    return {"messages": [response]}

# ========== 路由逻辑 ==========
def route_after_agent(state: SwarmState):
    """根据 Agent 的输出，决定下一步"""
    last_message = state["messages"][-1]
    
    # 如果有工具调用（交接请求）
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        tool_name = last_message.tool_calls[0]["name"]
        
        if "billing" in tool_name:
            return "billing"
        elif "tech" in tool_name:
            return "tech_support"
        elif "complaint" in tool_name:
            return "complaints"
    
    # 如果没有工具调用，结束
    return "end"

# ========== 构建图 ==========
graph = StateGraph(SwarmState)

graph.add_node("billing", billing_agent_node)
graph.add_node("tech_support", tech_support_agent_node)
graph.add_node("complaints", complaints_agent_node)

# 默认从 billing 开始
graph.add_edge(START, "billing")

# 每个 Agent 之后，根据交接请求路由
graph.add_conditional_edges("billing", route_after_agent, {
    "billing": "billing",
    "tech_support": "tech_support",
    "complaints": "complaints",
    "end": END
})

graph.add_conditional_edges("tech_support", route_after_agent, {
    "billing": "billing",
    "tech_support": "tech_support",
    "complaints": "complaints",
    "end": END
})

graph.add_conditional_edges("complaints", route_after_agent, {
    "billing": "billing",
    "tech_support": "tech_support",
    "complaints": "complaints",
    "end": END
})

app = graph.compile()
```

---

## Swarm 模式的优缺点

### 优点

- ✅ 去中心化，更灵活
- ✅ Agent 可以自主决策
- ✅ 适合对话型应用

### 缺点

- ❌ 难以追踪整体流程
- ❌ 可能出现循环交接
- ❌ 调试困难

---

## 小结

Swarm 模式：
- Agent 之间自主交接
- 通过交接工具实现
- 适合对话型应用
- 需要防止循环交接
