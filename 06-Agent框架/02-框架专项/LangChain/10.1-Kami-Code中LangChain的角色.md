# 10.1 Kami Code 中 LangChain 的角色

## 核心发现

Kami Code **不直接使用 LangChain 的 `create_agent()`**。它的核心 Agent 框架是 `deepagents`（基于 LangGraph）。

LangChain 在 Kami Code 中扮演的是**"协议适配层"**——而不是核心框架。

---

## 具体用途

| LangChain 特性 | 使用位置 | 用途 |
|---|---|---|
| `StructuredTool` | `registry.py` | 将内部 ToolSpec 转为 LangChain 标准工具 |
| `AgentMiddleware` | `tool_search_middleware.py` | 实现延迟加载工具过滤 |
| `convert_to_openai_tool` | 测试文件 | 验证工具 Schema |
| `usage_metadata` | `usage.py` | 读取 Token 用量 |
| 消息类型识别 | `message_stream.py` | 兼容 AIMessage/HumanMessage |

---

## 设计哲学

Kami Code 的理念是：**用 LangChain 的协议标准，但不被 LangChain 框架锁定**。

- LangChain 的导入是可选的（try/except ImportError）
- 不强制绑定 LangChain 版本
- 核心逻辑与 LangChain 解耦
