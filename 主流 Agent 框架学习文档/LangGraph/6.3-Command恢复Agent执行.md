# 6.3 Command(resume=...)：恢复 Agent 执行

当 Agent 因为 `interrupt()` 暂停后，需要用 `Command(resume=...)` 来恢复执行。

这一节我们详细学习 `Command` 的各种用法。

---

## 基本用法

### 导入

```python
from langgraph.types import Command
```

### 恢复执行

```python
# 恢复，传入人类输入的值
workflow.invoke(Command(resume=True), config={"thread_id": "1"})
```

---

## Command 的结构

`Command` 是一个特殊的对象，包含：

```python
Command(
    resume=...  # 人类输入的值，会作为 interrupt() 的返回值
)
```

### resume 的值

`resume` 可以是**任意 Python 对象**：

```python
# 布尔值
Command(resume=True)
Command(resume=False)

# 字符串
Command(resume="approved")
Command(resume="Alice")

# 数字
Command(resume=42)
Command(resume=3.14)

# 列表
Command(resume=[1, 2, 3])

# 字典
Command(resume={"approved": True, "comment": "looks good"})

# None
Command(resume=None)
```

## 完整流程示例

### 1. 定义工作流

```python
from langgraph.func import entrypoint, interrupt
from langgraph.checkpoint.memory import MemorySaver
from langgraph.types import Command

@entrypoint(checkpointer=MemorySaver())
def workflow(task: str):
    plan = f"执行：{task}"
    
    # 暂停
    approved = interrupt({"plan": plan})
    
    if approved:
        return f"✅ {plan}"
    else:
        return f"❌ {plan}"
```

### 2. 第一次调用（暂停）

```python
thread_id = "test_1"

# 调用工作流，会在 interrupt 处暂停
try:
    workflow("建设新大楼", config={"thread_id": thread_id})
except Exception as e:
    print(f"工作流已暂停")
```

### 3. 恢复执行（批准）

```python
# 恢复，传入 True
result = workflow.invoke(Command(resume=True), config={"thread_id": thread_id})
print(result)
# 输出：✅ 执行：建设新大楼
```

### 4. 或者：恢复执行（拒绝）

```python
thread_id_2 = "test_2"

# 暂停
workflow("购买奢侈品", config={"thread_id": thread_id_2})

# 恢复，传入 False
result = workflow.invoke(Command(resume=False), config={"thread_id": thread_id_2})
print(result)
# 输出：❌ 执行：购买奢侈品
```

## 多个 interrupt 的恢复

如果工作流有多个 `interrupt`，每次 `Command(resume=...)` 只恢复**当前暂停的 interrupt**。

### 示例

```python
@entrypoint(checkpointer=MemorySaver())
def multi_step():
    # 第一个 interrupt
    step1 = interrupt({"step": 1, "message": "第一步"})
    print(f"步骤 1 完成：{step1}")
    
    # 第二个 interrupt
    step2 = interrupt({"step": 2, "message": "第二步"})
    print(f"步骤 2 完成：{step2}")
    
    # 第三个 interrupt
    step3 = interrupt({"step": 3, "message": "第三步"})
    print(f"步骤 3 完成：{step3}")
    
    return "全部完成"

thread_id = "multi_1"

# 第一次调用：在第一个 interrupt 暂停
multi_step(config={"thread_id": thread_id})
# 输出：（无，因为暂停了）

# 恢复第一个 interrupt
multi_step.invoke(Command(resume="A"), config={"thread_id": thread_id})
# 输出：步骤 1 完成：A
# 然后在第二个 interrupt 暂停

# 恢复第二个 interrupt
multi_step.invoke(Command(resume="B"), config={"thread_id": thread_id})
# 输出：步骤 2 完成：B
# 然后在第三个 interrupt 暂停

# 恢复第三个 interrupt
result = multi_step.invoke(Command(resume="C"), config={"thread_id": thread_id})
# 输出：步骤 3 完成：C
# 然后返回最终结果
print(result)
# 输出：全部完成
```

## 检查暂停状态

### 获取当前状态

```python
state = app.get_state(config={"thread_id": thread_id})
print(state.next)  # 下一步要执行的节点
print(state.values)  # 当前状态值
```

### 检查是否有 interrupt

```python
# 如果 state.next 不为空，说明有暂停
if state.next:
    print("工作流已暂停，等待人工输入")
else:
    print("工作流已完成或运行中")
```

---

## 查看暂停的原因

### 获取 interrupt 的 payload

```python
state = app.get_state(config={"thread_id": thread_id})

# interrupt 的 payload 在 state 里
if state.values.get("__interrupt__"):
    payload = state.values["__interrupt__"]
    print(f"暂停原因：{payload}")
```

## 实战：带审批的工作流

```python
from langgraph.func import entrypoint, interrupt
from langgraph.checkpoint.memory import MemorySaver
from langgraph.types import Command

@entrypoint(checkpointer=MemorySaver())
def expense_approval(amount: float, description: str):
    """费用审批工作流"""
    # 生成申请
    request = {
        "amount": amount,
        "description": description
    }
    
    # 暂停，等待审批
    approval = interrupt({
        "type": "expense_approval",
        "request": request,
        "message": f"请审批费用申请：{description}，金额 {amount} 元"
    })
    
    # 解析审批结果
    if isinstance(approval, dict):
        approved = approval.get("approved", False)
        comment = approval.get("comment", "")
    else:
        approved = approval
        comment = ""
    
    if approved:
        return {
            "status": "approved",
            "request": request,
            "comment": comment
        }
    else:
        return {
            "status": "rejected",
            "request": request,
            "comment": comment
        }

# 测试
thread_id = "expense_1"

# 暂停
expense_approval(5000, "团队建设活动", config={"thread_id": thread_id})

# 审批（批准 + 评论）
result = expense_approval.invoke(
    Command(resume={
        "approved": True,
        "comment": "金额合理，批准"
    }),
    config={"thread_id": thread_id}
)

print(f"状态：{result['status']}")
print(f"评论：{result['comment']}")
```

## 超时处理

如果人类长时间没有响应 `interrupt`，可以设置超时：

### 方法 1：检查暂停状态

```python
import time

# 记录暂停时间
pause_time = time.time()

# 定期检查
while True:
    state = app.get_state(config={"thread_id": thread_id})
    
    if not state.next:
        # 工作流已完成
        break
    
    # 检查是否超时（比如 24 小时）
    if time.time() - pause_time > 24 * 3600:
        print("审批超时，自动拒绝")
        app.invoke(Command(resume=False), config={"thread_id": thread_id})
        break
    
    time.sleep(60)  # 每分钟检查一次
```

### 方法 2：外部系统通知

实际应用中，应该用外部系统（如邮件、短信、推送）通知人类：

```python
@entrypoint(checkpointer=MemorySaver())
def workflow():
    # 发送通知
    send_notification("请审批任务")
    
    # 暂停
    approved = interrupt({"message": "请审批"})
    
    return approved

# 实际应用中，应该有一个后台任务：
# 1. 监听暂停的工作流
# 2. 发送通知给人类
# 3. 等待人类响应
```

## 错误处理

### 错误 1：没有暂停就恢复

```python
# 如果工作流没有在 interrupt 处暂停
# 直接调用 Command(resume=...) 会报错
workflow.invoke(Command(resume=True), config={"thread_id": "1"})
# 报错：No interrupt found
```

### 错误 2：thread_id 不匹配

```python
# 工作流用 thread_id="1" 暂停
workflow(config={"thread_id": "1"})

# 恢复时用 thread_id="2"
workflow.invoke(Command(resume=True), config={"thread_id": "2"})
# 报错：找不到对应的 checkpoint
```

---

## 小结

`Command(resume=...)` 的用法：

**基本用法**：
```python
workflow.invoke(Command(resume=value), config={"thread_id": "..."})
```

**resume 的值**：
- 任意 Python 对象
- 通常用字典（包含多个字段）

**多个 interrupt**：
- 每次 `Command` 只恢复当前暂停的 interrupt
- 按顺序逐个恢复

**检查状态**：
- `app.get_state()` 获取当前状态
- `state.next` 判断是否有暂停

**最佳实践**：
- 用字典传递复杂的审批信息
- 设置超时处理
- 用外部系统通知人类
