# 7.3 消息流、Token 流、中断事件

在使用 `stream_events()` 时，你会遇到不同类型的事件。这一节我们详细讲解最常用的几种事件类型。

---

## 事件类型总览

| 事件类型 | 触发时机 | 常用场景 |
|---------|---------|---------|
| `on_chain_start` | 节点开始执行 | 显示"正在执行..." |
| `on_chain_end` | 节点执行完成 | 显示"执行完成" |
| `on_chat_model_stream` | LLM 生成 token | 实时显示 LLM 输出 |
| `on_tool_start` | 工具开始调用 | 显示"正在调用工具..." |
| `on_tool_end` | 工具调用完成 | 显示工具结果 |

---

## on_chat_model_stream：LLM 的 Token 流

这是最常用的事件——实时获取 LLM 生成的每个 token。

### 基本用法

```python
for event in app.stream_events(input, version="v2"):
    if event["event"] == "on_chat_model_stream":
        chunk = event["data"]["chunk"]
        content = chunk.content
        
        if content:
            print(content, end="", flush=True)
```

### 完整示例

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", streaming=True)

def chat(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

graph = StateGraph(MessagesState)
graph.add_node("chat", chat)
graph.add_edge(START, "chat")
graph.add_edge("chat", END)

app = graph.compile()

# 流式显示
print("AI: ", end="")
for event in app.stream_events(
    {"messages": [{"role": "user", "content": "用一句话解释什么是 AI"}]},
    version="v2"
):
    if event["event"] == "on_chat_model_stream":
        content = event["data"]["chunk"].content
        if content:
            print(content, end="", flush=True)

print()
```

## on_tool_start / on_tool_end：工具调用

### 基本用法

```python
for event in app.stream_events(input, version="v2"):
    if event["event"] == "on_tool_start":
        tool_name = event["name"]
        tool_input = event["data"]["input"]
        print(f"🔧 调用工具：{tool_name}，输入：{tool_input}")
    
    elif event["event"] == "on_tool_end":
        tool_output = event["data"]["output"]
        print(f"✅ 工具结果：{tool_output}")
```

### 完整示例

```python
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索工具"""
    import time
    time.sleep(1)  # 模拟耗时
    return f"搜索结果：{query}"

@tool
def calculator(expression: str) -> str:
    """计算器工具"""
    return str(eval(expression))

# 在 ReAct Agent 中使用
for event in agent.stream_events(
    {"messages": [{"role": "user", "content": "搜索 Python 教程，然后计算 1+1"}]},
    version="v2"
):
    event_type = event["event"]
    
    if event_type == "on_chat_model_stream":
        content = event["data"]["chunk"].content
        if content:
            print(content, end="", flush=True)
    
    elif event_type == "on_tool_start":
        print(f"\n🔧 调用工具：{event['name']}")
    
    elif event_type == "on_tool_end":
        print(f"✅ 结果：{event['data']['output']}")
```

## on_chain_start / on_chain_end：节点执行

### 基本用法

```python
for event in app.stream_events(input, version="v2"):
    if event["event"] == "on_chain_start":
        node_name = event["name"]
        print(f"▶️ 开始执行：{node_name}")
    
    elif event["event"] == "on_chain_end":
        node_name = event["name"]
        print(f"✅ 执行完成：{node_name}")
```

---

## 综合示例：完整的流式日志

```python
def stream_with_logs(app, input):
    """带完整日志的流式执行"""
    
    for event in app.stream_events(input, version="v2"):
        event_type = event["event"]
        
        # 节点开始
        if event_type == "on_chain_start":
            print(f"\n{'='*50}")
            print(f"▶️ 节点开始：{event['name']}")
            print(f"{'='*50}")
        
        # LLM token
        elif event_type == "on_chat_model_stream":
            content = event["data"]["chunk"].content
            if content:
                print(content, end="", flush=True)
        
        # 工具开始
        elif event_type == "on_tool_start":
            print(f"\n🔧 调用工具：{event['name']}")
            print(f"   输入：{event['data']['input']}")
        
        # 工具完成
        elif event_type == "on_tool_end":
            print(f"✅ 工具结果：{event['data']['output']}")
        
        # 节点完成
        elif event_type == "on_chain_end":
            print(f"\n✅ 节点完成：{event['name']}")

# 使用
stream_with_logs(agent, {"messages": [{"role": "user", "content": "搜索 AI 新闻"}]})
```

## 处理中断事件

如果工作流中有 `interrupt`，流式输出会包含中断事件。

```python
for event in app.stream_events(input, version="v2"):
    if event["event"] == "on_chain_end":
        # 检查是否有中断
        if hasattr(event["data"], "output"):
            output = event["data"]["output"]
            if "__interrupt__" in output:
                print("⏸️ 工作流已暂停，等待人工输入")
```

---

## 小结

常用事件类型：

| 事件 | 用途 |
|------|------|
| `on_chat_model_stream` | 实时显示 LLM 输出 |
| `on_tool_start` / `on_tool_end` | 显示工具调用 |
| `on_chain_start` / `on_chain_end` | 显示节点执行 |

最佳实践：
- 用 `on_chat_model_stream` 实现"打字机"效果
- 用工具事件显示工具调用进度
- 用节点事件显示整体流程
