# 1.5 安装与环境准备

动手时间！这一节我们把 LangChain 的开发环境搭起来。

---

## 前置要求

- Python 3.9+
- 已安装 LangGraph（前置知识）
- 至少一个 LLM Provider 的 API Key

---

## 安装 LangChain

```bash
pip install langchain
```

这会安装 LangChain 核心包。

---

## 安装 LLM Provider

根据你的需要，安装对应的 Provider 包：

```bash
# OpenAI
pip install langchain-openai

# Anthropic (Claude)
pip install langchain-anthropic

# Google (Gemini)
pip install langchain-google-genai

# Ollama (本地模型)
pip install langchain-ollama

# 其他 Provider
pip install langchain-fireworks
pip install langchain-baseten
```

---

## 安装辅助工具

```bash
# 环境变量管理
pip install python-dotenv

# LangSmith（可观测性，可选）
pip install langsmith
```

---

## 配置 API Key

创建 `.env` 文件：

```bash
OPENAI_API_KEY=你的OpenAI_KEY
ANTHROPIC_API_KEY=你的Anthropic_KEY
GOOGLE_API_KEY=你的Google_KEY

# LangSmith（可选）
LANGSMITH_API_KEY=你的LangSmith_KEY
LANGSMITH_TRACING=true
```

---

## 验证安装

```python
from dotenv import load_dotenv
load_dotenv()

from langchain.agents import create_agent

def hello():
    """打个招呼"""
    return "Hello from LangChain!"

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[hello],
    system_prompt="你是一个友好的助手"
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]}
)
print(result["messages"][-1].content)
```

如果看到 AI 的回复，说明安装成功！

## 常见问题

### Q: 报 `ImportError: cannot import name 'create_agent'`

**原因**：版本太旧，`create_agent` 是 v1.0+ 才有的。

**解决**：

```bash
pip install --upgrade langchain
```

### Q: 报 `AuthenticationError`

**原因**：API Key 没有正确配置。

**解决**：
1. 检查 `.env` 文件中的 Key
2. 确保调用了 `load_dotenv()`
3. 确保在同一个终端会话中运行
