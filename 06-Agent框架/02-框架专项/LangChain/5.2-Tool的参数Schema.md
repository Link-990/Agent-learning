# 5.2 Tool 的参数 Schema

工具的参数 Schema 决定了 LLM 如何传递参数。Schema 越清晰，LLM 调用越准确。

---

## 方式 1：类型标注（简单参数）

```python
@tool
def add(a: int, b: int) -> int:
    """两个数相加"""
    return a + b

# Schema 自动生成：
# {"type": "object", "properties": {"a": {"type": "integer"}, "b": {"type": "integer"}}}
```

---

## 方式 2：Pydantic BaseModel（复杂参数）

```python
from pydantic import BaseModel, Field

class SearchInput(BaseModel):
    query: str = Field(description="搜索关键词")
    max_results: int = Field(default=10, description="最大结果数", ge=1, le=100)
    language: str = Field(default="zh", description="结果语言")

@tool
def search(input: SearchInput) -> str:
    """搜索信息"""
    return f"搜索：{input.query}，最多 {input.max_results} 条结果"
```

---

## 方式 3：StructuredTool（最大灵活性）

```python
from langchain_core.tools import StructuredTool

tool = StructuredTool.from_function(
    func=my_function,
    name="my_tool",
    description="工具描述",
    args_schema=SearchInput,
    metadata={"source": "api", "version": "v2"}
)
```

---

## 参数 Schema 最佳实践

### 1. 每个参数都要有描述

```python
class Input(BaseModel):
    city: str = Field(description="城市名称，如：北京、上海")
```

### 2. 用枚举限制选项

```python
from enum import Enum

class Unit(str, Enum):
    CELSIUS = "celsius"
    FAHRENHEIT = "fahrenheit"

class Input(BaseModel):
    unit: Unit = Field(description="温度单位")
```

### 3. 设置默认值

```python
class Input(BaseModel):
    max_results: int = Field(default=10, description="最大结果数")
```

### 4. 添加约束

```python
class Input(BaseModel):
    age: int = Field(description="年龄", ge=0, le=150)
    name: str = Field(description="姓名", min_length=1, max_length=50)
```

---

## 小结

参数 Schema 的三种方式：
1. **类型标注**：简单参数
2. **Pydantic BaseModel**：复杂参数
3. **StructuredTool**：最大灵活性

最佳实践：每个参数要有描述、用枚举限制选项、设置默认值和约束。
