# 3.5 Agent 的 invoke 与 stream

`create_agent()` 返回的对象支持多种调用方式。

---

## invoke()：同步调用

```python
result = agent.invoke({"messages": [{"role": "user", "content": "你好"}]})
print(result["messages"][-1].content)
```

特点：等待 Agent 完全执行完毕后返回结果。

---

## stream()：流式调用

```python
for event in agent.stream({"messages": [{"role": "user", "content": "你好"}]}):
    print(event)
```

特点：每个节点执行完后立即返回，不用等全部完成。

输出示例：

```
{"model": {"messages": [AIMessage(content="你好！")]}}
```

---

## stream_events()：事件流

```python
for event in agent.stream_events(
    {"messages": [{"role": "user", "content": "你好"}]},
    version="v3"
):
    if event["event"] == "on_chat_model_stream":
        content = event["data"]["chunk"].content
        if content:
            print(content, end="", flush=True)
```

特点：Token 级别的流式输出，实时显示 LLM 生成的文字。

---

## 异步调用

```python
# 异步 invoke
result = await agent.ainvoke({"messages": [...]})

# 异步 stream
async for event in agent.astream({"messages": [...]}):
    print(event)
```

---

## 带 config 的调用

```python
result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={
        "configurable": {
            "thread_id": "session_123"  # 会话 ID
        }
    }
)
```

---

## 小结

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| `invoke()` | 同步，等全部完成 | 简单调用 |
| `stream()` | 节点级流式 | 显示执行进度 |
| `stream_events()` | Token 级流式 | 实时显示 LLM 输出 |
| `ainvoke()` | 异步 invoke | 异步应用 |
| `astream()` | 异步 stream | 异步应用 |
