# 2.4 Tool：工具的定义与绑定

工具是 Agent 与外部世界交互的桥梁。这一节我们学习如何定义工具，以及如何把工具绑定给 LLM。

---

## 定义工具：@tool 装饰器

最简单的方式是用 `@tool` 装饰器：

```python
from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取城市的天气信息"""
    return f"{city}今天晴天，25°C"

@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    return str(eval(expression))

@tool
def search(query: str) -> str:
    """搜索互联网"""
    return f"搜索结果：{query}"
```

### 关键点

1. **函数名**就是工具名（`get_weather`、`calculate`、`search`）
2. **docstring**（第一行注释）就是工具描述——LLM 靠它理解工具是干什么的
3. **参数类型标注**会被自动提取为 JSON Schema——LLM 靠它知道该传什么参数

---

## 绑定工具到 LLM

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")
tools = [get_weather, calculate, search]

# 绑定工具
llm_with_tools = llm.bind_tools(tools)
```

`bind_tools()` 会把工具的定义（名字、描述、参数 Schema）发送给 LLM，让 LLM 知道有哪些工具可用。

---

## 工具调用的流程

```
1. 用户：北京天气怎么样？
    ↓
2. LLM 看到有 get_weather 工具
   → 决定调用它
   → 返回 tool_calls: [{"name": "get_weather", "args": {"city": "北京"}}]
    ↓
3. 你的代码执行工具
   → get_weather(city="北京") → "晴天，25°C"
    ↓
4. 把工具结果喂给 LLM
   → ToolMessage(content="晴天，25°C", tool_call_id="...")
    ↓
5. LLM 生成最终回复
   → "北京今天晴天，25°C。"
```

---

## 手动执行工具调用

```python
# 1. LLM 决定调用工具
response = llm_with_tools.invoke([
    HumanMessage(content="北京天气怎么样？")
])

# 2. 检查是否有工具调用
if response.tool_calls:
    for tool_call in response.tool_calls:
        tool_name = tool_call["name"]
        tool_args = tool_call["args"]
        
        # 3. 执行工具
        tool_map = {t.name: t for t in tools}
        result = tool_map[tool_name].invoke(tool_args)
        
        # 4. 构造工具消息
        tool_msg = ToolMessage(
            content=result,
            tool_call_id=tool_call["id"]
        )
        
        # 5. 把结果喂给 LLM
        final = llm_with_tools.invoke([
            HumanMessage(content="北京天气怎么样？"),
            response,
            tool_msg
        ])
        print(final.content)
```

当然，你不需要手动写这些——`create_agent()` 会自动处理整个循环。

## 自定义工具名和描述

```python
@tool(name="天气查询", description="查询指定城市的实时天气信息")
def get_weather(city: str) -> str:
    return f"{city}今天晴天，25°C"
```

## Kami Code 中的工具定义

Kami Code 使用 `StructuredTool` 来定义工具：

```python
from langchain_core.tools import StructuredTool

tool = StructuredTool.from_function(
    func=my_function,
    name="tool_name",
    description="工具描述",
    args_schema=MyInputSchema,  # Pydantic 模型
    metadata={"source": "internal", "is_read_only": True}
)
```

这种方式更灵活——可以附加 `metadata`（如 `defer_loading`、`search_hint`），用于 Middleware 过滤。

---

## 小结

- 用 `@tool` 装饰器定义工具
- docstring = 工具描述，参数类型 = 参数 Schema
- 用 `llm.bind_tools(tools)` 绑定工具
- `create_agent()` 自动处理工具调用循环
- Kami Code 用 `StructuredTool` 附加 metadata
