# 4.5 CompositeBackend：复合路由

CompositeBackend 让你根据文件路径，路由到不同的 Backend。

---

## 用法

```python
from deepagents import create_deep_agent
from deepagents.backends import (
    CompositeBackend,
    StateBackend,
    StoreBackend,
    FilesystemBackend,
)

agent = create_deep_agent(
    model="gpt-5.5",
    backend=CompositeBackend(
        default=StateBackend(),  # 默认用内存
        routes={
            "/memories/": StoreBackend(
                namespace=lambda rt: ("memories", rt.context.user_id),
            ),
            "/skills/": StoreBackend(
                namespace=lambda rt: ("skills", rt.context.user_id),
            ),
            "/project/": FilesystemBackend(root_dir="./project"),
        },
    ),
)
```

---

## 路由规则

```
/memories/xxx → StoreBackend（持久化记忆）
/skills/xxx   → StoreBackend（持久化技能）
/project/xxx  → FilesystemBackend（本地磁盘）
其他          → StateBackend（内存）
```

---

## 适用场景

- 记忆和技能需要持久化
- 项目文件在本地磁盘
- 临时文件在内存
