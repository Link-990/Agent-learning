# 7.3 FilesystemPermission：文件级权限控制

`FilesystemPermission` 让你精确控制哪些路径的哪些操作需要审批。

---

## 用法

```python
from deepagents import FilesystemPermission, create_deep_agent
from langgraph.checkpoint.memory import MemorySaver

agent = create_deep_agent(
    model="gpt-5.5",
    permissions=[
        FilesystemPermission(
            operations=["write"],           # 写操作
            paths=["/skills/**"],           # /skills/ 下所有文件
            mode="interrupt",               # 需要审批
        ),
        FilesystemPermission(
            operations=["write", "delete"],
            paths=["/important/**"],
            mode="interrupt",
        ),
    ],
    checkpointer=MemorySaver(),
)
```

---

## 权限规则

| operations | paths | mode | 含义 |
|-----------|-------|------|------|
| `["write"]` | `["/skills/**"]` | `"interrupt"` | 写 /skills/ 下文件需审批 |
| `["read"]` | `["/public/**"]` | `"allow"` | 读 /public/ 下文件放行 |
| `["write", "delete"]` | `["/**"]` | `"interrupt"` | 所有写/删除都需审批 |
