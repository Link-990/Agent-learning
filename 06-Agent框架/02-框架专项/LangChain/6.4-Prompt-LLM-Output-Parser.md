# 6.4 Prompt + LLM + Output Parser

这是 LCEL 最经典的组合——**Prompt → LLM → Parser**。

---

## 完整示例

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# 1. Prompt
prompt = ChatPromptTemplate.from_template(
    "你是一个翻译助手。把以下内容从{source_lang}翻译成{target_lang}：\n{text}"
)

# 2. LLM
model = ChatOpenAI(model="gpt-4o-mini")

# 3. Parser
parser = StrOutputParser()

# 4. 组合
chain = prompt | model | parser

# 5. 调用
result = chain.invoke({
    "source_lang": "英文",
    "target_lang": "中文",
    "text": "Hello, how are you?"
})
print(result)  # "你好，你怎么样？"
```

---

## 其他 Parser

```python
# JSON Parser
from langchain_core.output_parsers import JsonOutputParser

parser = JsonOutputParser()
chain = prompt | model | parser

# 要求 LLM 返回 JSON
prompt = ChatPromptTemplate.from_template(
    "返回 JSON 格式的翻译结果：\n{text}\n{format_instructions}"
)
```

---

## 小结

经典 LCEL 链：`Prompt → LLM → Parser`

- `ChatPromptTemplate`：构造 Prompt
- `ChatModel`：调用 LLM
- `StrOutputParser`：提取字符串
- `JsonOutputParser`：提取 JSON
