# 9.4 性能优化

优化 Agent 的性能——减少延迟、降低成本。

---

## 1. 使用小模型做路由

```python
agent = create_agent(
    model="openai:gpt-5.5",  # 大模型做最终回答
    tools=all_tools,
    middleware=[
        LLMToolSelectorMiddleware(
            model="openai:gpt-4o-mini",  # 小模型选择工具
            max_tools=5,
        )
    ]
)
```

## 2. 缓存

```python
# 使用缓存 LLM
from langchain.globals import set_llm_cache
from langchain_community.cache import InMemoryCache

set_llm_cache(InMemoryCache())
```

## 3. 限制工具数量

工具越多，LLM 的决策时间越长。用 Middleware 过滤不相关的工具。

## 4. 流式输出

用 `stream_events()` 代替 `invoke()`，让用户实时看到进展，感知延迟更低。

---

## 小结

性能优化策略：
- 小模型路由
- 缓存
- 限制工具数量
- 流式输出
