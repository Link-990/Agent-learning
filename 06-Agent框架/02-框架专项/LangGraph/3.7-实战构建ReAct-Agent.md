# 3.7 实战：构建一个带工具调用的 ReAct Agent

前面学了这么多理论，现在我们动手写一个完整的、能实际使用的 Agent——**ReAct Agent**。

这个 Agent 能：
- 理解用户的问题
- 决定是否需要调用工具
- 调用工具获取信息
- 根据工具返回的结果生成最终答案

---

## 什么是 ReAct？

**ReAct = Reasoning（推理） + Acting（行动）**

这是一种经典的 Agent 模式，流程如下：

```
1. 用户提问
2. LLM 推理：我需要什么信息？需要什么工具？
3. 如果需要工具 → 调用工具 → 把结果喂给 LLM → 回到步骤 2
4. 如果不需要工具 → 生成最终答案
```

---

## 我们要实现的功能

一个简单的"知识助手"Agent：

- **工具 1**：搜索工具（模拟）
- **工具 2**：计算器工具
- **工具 3**：获取当前时间

用户可以问：
- "今天天气怎么样？"（需要搜索）
- "123 * 456 等于多少？"（需要计算器）
- "现在几点了？"（需要时间工具）
- "你好"（不需要工具）

## 第一步：定义工具

```python
from langchain_core.tools import tool
from datetime import datetime

@tool
def search(query: str) -> str:
    """
    搜索工具：用于搜索互联网信息
    
    Args:
        query: 搜索关键词
    """
    # 这里是模拟搜索，实际项目可以接入真实的搜索 API
    fake_results = {
        "天气": "今天晴天，气温 25°C",
        "python": "Python 是一种高级编程语言",
        "langgraph": "LangGraph 是一个用于构建 Agent 的框架"
    }
    
    for key, value in fake_results.items():
        if key in query.lower():
            return value
    
    return f"未找到关于 '{query}' 的信息"

@tool
def calculator(expression: str) -> str:
    """
    计算器工具：计算数学表达式
    
    Args:
        expression: 数学表达式，例如 "123 * 456"
    """
    try:
        result = eval(expression)
        return str(result)
    except Exception as e:
        return f"计算错误：{str(e)}"

@tool
def get_current_time() -> str:
    """
    获取当前时间
    """
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
```

---

## 第二步：绑定工具到 LLM

```python
from langchain_openai import ChatOpenAI

# 初始化 LLM
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 把工具列表传给 LLM
tools = [search, calculator, get_current_time]
llm_with_tools = llm.bind_tools(tools)
```

`bind_tools()` 会把工具的定义（名字、描述、参数）发送给 LLM，让 LLM 知道有哪些工具可用。

---

## 第三步：定义节点

### 节点 1：调用 LLM

```python
from langgraph.graph import MessagesState

def call_llm(state: MessagesState):
    """
    调用 LLM，让它决定下一步做什么
    """
    messages = state["messages"]
    response = llm_with_tools.invoke(messages)
    return {"messages": [response]}
```

### 节点 2：调用工具

```python
from langchain_core.messages import ToolMessage

def call_tools(state: MessagesState):
    """
    执行 LLM 请求的工具调用
    """
    last_message = state["messages"][-1]
    tool_calls = last_message.tool_calls
    
    # 创建一个工具名到工具函数的映射
    tool_map = {tool.name: tool for tool in tools}
    
    results = []
    for tool_call in tool_calls:
        tool_name = tool_call["name"]
        tool_args = tool_call["args"]
        
        # 执行工具
        tool_func = tool_map[tool_name]
        result = tool_func.invoke(tool_args)
        
        # 构造工具返回消息
        results.append(
            ToolMessage(
                content=result,
                tool_call_id=tool_call["id"]
            )
        )
    
    return {"messages": results}
```

---

## 第四步：定义路由逻辑

```python
from langgraph.graph import END

def should_continue(state: MessagesState):
    """
    判断：LLM 是否需要调用工具？
    """
    last_message = state["messages"][-1]
    
    # 如果 LLM 返回了工具调用，就去执行工具
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"
    
    # 否则就结束
    return "end"
```

---

## 第五步：构建图

```python
from langgraph.graph import StateGraph, START

# 创建图
graph = StateGraph(MessagesState)

# 添加节点
graph.add_node("llm", call_llm)
graph.add_node("tools", call_tools)

# 添加边
graph.add_edge(START, "llm")

# 条件路由：LLM 之后去哪？
graph.add_conditional_edges(
    "llm",
    should_continue,
    {
        "tools": "tools",
        "end": END
    }
)

# 工具执行完，回到 LLM
graph.add_edge("tools", "llm")

# 编译
app = graph.compile()
```

**流程图**：

```
START → llm → 判断
           ↓     ↑
         tools ──┘
           ↓
          END
```

## 完整代码

把上面的代码整合到一起：

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langchain_core.messages import ToolMessage
from langgraph.graph import StateGraph, MessagesState, START, END
from datetime import datetime

load_dotenv()

# ========== 定义工具 ==========
@tool
def search(query: str) -> str:
    """搜索工具：用于搜索互联网信息"""
    fake_results = {
        "天气": "今天晴天，气温 25°C",
        "python": "Python 是一种高级编程语言",
        "langgraph": "LangGraph 是一个用于构建 Agent 的框架"
    }
    for key, value in fake_results.items():
        if key in query.lower():
            return value
    return f"未找到关于 '{query}' 的信息"

@tool
def calculator(expression: str) -> str:
    """计算器工具：计算数学表达式"""
    try:
        result = eval(expression)
        return str(result)
    except Exception as e:
        return f"计算错误：{str(e)}"

@tool
def get_current_time() -> str:
    """获取当前时间"""
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

# ========== 绑定工具到 LLM ==========
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
tools = [search, calculator, get_current_time]
llm_with_tools = llm.bind_tools(tools)

# ========== 定义节点 ==========
def call_llm(state: MessagesState):
    response = llm_with_tools.invoke(state["messages"])
    return {"messages": [response]}

def call_tools(state: MessagesState):
    last_message = state["messages"][-1]
    tool_calls = last_message.tool_calls
    tool_map = {tool.name: tool for tool in tools}
    
    results = []
    for tool_call in tool_calls:
        tool_func = tool_map[tool_call["name"]]
        result = tool_func.invoke(tool_call["args"])
        results.append(ToolMessage(content=result, tool_call_id=tool_call["id"]))
    
    return {"messages": results}

def should_continue(state: MessagesState):
    last_message = state["messages"][-1]
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"
    return "end"

# ========== 构建图 ==========
graph = StateGraph(MessagesState)
graph.add_node("llm", call_llm)
graph.add_node("tools", call_tools)

graph.add_edge(START, "llm")
graph.add_conditional_edges("llm", should_continue, {"tools": "tools", "end": END})
graph.add_edge("tools", "llm")

app = graph.compile()

# ========== 测试 ==========
if __name__ == "__main__":
    queries = [
        "今天天气怎么样？",
        "123 乘以 456 等于多少？",
        "现在几点了？",
        "你好"
    ]
    
    for query in queries:
        print(f"\n用户: {query}")
        result = app.invoke({"messages": [{"role": "user", "content": query}]})
        print(f"AI: {result['messages'][-1].content}")
```

## 扩展思路

基于这个 ReAct Agent，你可以：

1. **添加更多工具**：
   - 数据库查询工具
   - API 调用工具（真实的搜索、天气 API）
   - 文件操作工具

2. **添加记忆**：
   - 用 Checkpointer 持久化对话历史
   - 多轮对话时保持上下文

3. **添加人工审批**：
   - 在执行某些工具前，先让用户确认
   - 用 `interrupt_before=["tools"]`

4. **优化错误处理**：
   - 工具调用失败时，给 LLM 反馈错误信息
   - 让 LLM 重试或换个工具

---

## 小结

这一节我们从零构建了一个完整的 ReAct Agent，包含：

1. **工具定义**：用 `@tool` 装饰器
2. **绑定工具**：`llm.bind_tools(tools)`
3. **LLM 节点**：调用 LLM，让它决定是否需要工具
4. **工具节点**：执行 LLM 请求的工具调用
5. **路由逻辑**：判断是否需要继续调用工具
6. **图构建**：用 StateGraph 组装节点和边

这个 Agent 虽然简单，但它已经具备了"自主决策"的能力——它会根据用户的问题，自己决定是否需要工具、需要哪个工具。

掌握了这个模式，你就能构建各种实用的 Agent 应用。
