# 7.2 stream() 与 stream_events()

LangGraph 提供两种流式 API，适用于不同场景。

---

## stream()：节点级别的流式输出

### 基本用法

```python
for event in app.stream(input):
    # event 是一个字典：{节点名: 节点输出}
    node_name = list(event.keys())[0]
    node_output = event[node_name]
    print(f"节点 {node_name} 输出：{node_output}")
```

### 完整示例

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

def node_a(state):
    return {"messages": [{"role": "assistant", "content": "节点 A 执行完成"}]}

def node_b(state):
    return {"messages": [{"role": "assistant", "content": "节点 B 执行完成"}]}

graph = StateGraph(MessagesState)
graph.add_node("a", node_a)
graph.add_node("b", node_b)
graph.add_edge(START, "a")
graph.add_edge("a", "b")
graph.add_edge("b", END)

app = graph.compile()

# 流式执行
for event in app.stream({"messages": []}):
    node_name = list(event.keys())[0]
    print(f"执行节点：{node_name}")
    print(f"输出：{event[node_name]}")
    print("---")
```

输出：

```
执行节点：a
输出：{'messages': [{'role': 'assistant', 'content': '节点 A 执行完成'}]}
---
执行节点：b
输出：{'messages': [{'role': 'assistant', 'content': '节点 B 执行完成'}]}
---
```

---

## stream() 的模式

`stream()` 支持不同的模式：

### 模式 1：values（默认）

返回每个节点执行后的**完整状态值**。

```python
for event in app.stream(input, stream_mode="values"):
    # event 是完整的 State
    print(event)
```

### 模式 2：updates

返回每个节点的**输出更新**（而不是完整状态）。

```python
for event in app.stream(input, stream_mode="updates"):
    # event 是 {节点名: 节点输出}
    print(event)
```

### 模式 3：debug

返回详细的调试信息。

```python
for event in app.stream(input, stream_mode="debug"):
    # event 包含详细的执行信息
    print(event["type"])
    print(event["payload"])
```

---

## stream_events()：事件级别的流式输出

`stream_events()` 提供更细粒度的事件流。

### 基本用法

```python
for event in app.stream_events(input, version="v2"):
    event_type = event["event"]
    data = event["data"]
    print(f"事件：{event_type}，数据：{data}")
```

### 事件类型

| 事件类型 | 说明 |
|---------|------|
| `on_chain_start` | 节点开始执行 |
| `on_chain_end` | 节点执行完成 |
| `on_chat_model_stream` | LLM 生成的 token |
| `on_tool_start` | 工具开始执行 |
| `on_tool_end` | 工具执行完成 |

### 完整示例

```python
for event in app.stream_events(
    {"messages": [{"role": "user", "content": "你好"}]},
    version="v2"
):
    event_type = event["event"]
    
    if event_type == "on_chat_model_stream":
        # LLM 生成的每个 token
        content = event["data"]["chunk"].content
        if content:
            print(content, end="", flush=True)
    
    elif event_type == "on_tool_start":
        print(f"\n调用工具：{event['name']}")
    
    elif event_type == "on_chain_end":
        print(f"\n节点完成：{event['name']}")
```

---

## stream() vs stream_events()

| 特性 | stream() | stream_events() |
|------|---------|-----------------|
| 粒度 | 节点级别 | 事件级别 |
| 内容 | 节点输出 | LLM token、工具调用等 |
| 适用场景 | 查看每个节点的执行 | 实时显示 LLM 输出 |
| 性能 | 快 | 稍慢（更多事件） |
| API 版本 | 默认 | 需要指定 version |

---

## 实战：实时显示 LLM 输出

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

def chat(state):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

graph = StateGraph(MessagesState)
graph.add_node("chat", chat)
graph.add_edge(START, "chat")
graph.add_edge("chat", END)

app = graph.compile()

# 流式显示 LLM 输出
print("AI: ", end="")
for event in app.stream_events(
    {"messages": [{"role": "user", "content": "写一首关于编程的诗"}]},
    version="v2"
):
    if event["event"] == "on_chat_model_stream":
        content = event["data"]["chunk"].content
        if content:
            print(content, end="", flush=True)

print()  # 换行
```

输出：

```
AI: 代码如诗行，
逻辑似乐章，
指尖舞键盘，
创造无边界。
...
```

---

## 小结

**stream()**：
- 节点级别的流式输出
- 适合查看每个节点的执行
- 模式：values、updates、debug

**stream_events()**：
- 事件级别的细粒度流式输出
- 适合实时显示 LLM 输出
- 事件类型：on_chat_model_stream、on_tool_start 等
