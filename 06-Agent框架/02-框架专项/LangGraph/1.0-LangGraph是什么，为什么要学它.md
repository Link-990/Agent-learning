# 第一章：LangGraph 是什么，为什么要学它

欢迎来到 LangGraph 的学习之旅。在这一章，我们不会马上跳进代码，而是先搞清楚三个问题：

1. **LangGraph 到底是什么？**
2. **为什么我们需要它？**
3. **它在整个 AI Agent 开发生态中处于什么位置？**

把这三个问题想明白了，后面的学习会轻松很多。

## 为什么要先读这一章？

很多人学框架喜欢直接上手敲代码，结果写着写着就迷失了——不知道为什么要这么写，不知道什么时候该用什么功能。

这一章就是给你打底的。读完之后，你会对 LangGraph 有一个清晰的"心智模型"，知道它是干什么的，适合解决什么问题，不适合解决什么问题。
