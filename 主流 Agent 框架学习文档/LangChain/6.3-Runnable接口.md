# 6.3 Runnable 接口

所有能参与 LCEL 链的组件，都必须实现 **Runnable 接口**。

---

## Runnable 接口定义

```python
class Runnable:
    def invoke(self, input) -> output: ...
    def stream(self, input) -> Iterator[output]: ...
    def batch(self, inputs) -> list[output]: ...
    async def ainvoke(self, input) -> output: ...
    async def astream(self, input) -> AsyncIterator[output]: ...
```

LangChain 的大部分组件都实现了这个接口：
- `ChatModel`（LLM）
- `PromptTemplate`
- `OutputParser`
- `Tool`
- `Retriever`

---

## 自定义 Runnable

```python
from langchain_core.runnables import RunnableLambda

def my_function(input: dict) -> str:
    return input["text"].upper()

runnable = RunnableLambda(my_function)

chain = prompt | model | runnable | parser
```

---

## RunnableLambda

把普通函数变成 Runnable：

```python
from langchain_core.runnables import RunnableLambda

chain = prompt | model | RunnableLambda(lambda x: x.content.upper())
```

---

## 小结

- Runnable 是 LCEL 的基础接口
- 所有 LangChain 组件都实现了 Runnable
- 用 `RunnableLambda` 把函数变成 Runnable
