# 按岗位学习

## Agent 应用工程

基础与模型 → Agent 核心原理 → Agent Runtime → RAG 与知识库 → 工具与协议 → 企业级工程化 → 一个场景实战。

重点准备：Agent Loop、Function Calling、RAG 评测、权限、幂等、Checkpoint、Trace 和失败复盘。

## RAG 工程

基础与模型 → RAG 与知识库 → 工具与协议 → 企业级工程化 → 系统设计。

重点准备：分块、Embedding、混合检索、Rerank、引用溯源、增量同步、ACL、幻觉治理和指标口径。

## Runtime / 平台工程

基础与模型 → Agent 核心原理 → Agent Runtime → Agent 框架 → 企业级工程化 → 系统设计。

重点准备：调度、队列、租约、状态机、事件、持久化、重试、幂等、限流、沙箱、恢复和可观测性。

## 框架 / Coding Agent

Agent 核心原理 → Agent Runtime → Agent 框架。先读框架共性，再选择 LangGraph、LangChain、Deep Agents、Pi Agent 或 Harness 专项，不要四套框架同时从头学。

## 训练与对齐

基础与模型 → 模型训练与对齐。重点准备 SFT 与 PEFT 的适用边界，以及 RLHF、PPO、DPO、GRPO 的数据、目标和稳定性差异。

## 面试最后冲刺

选择一个真实或练习项目，依次完成：架构图、数据流、技术选型、一个失败案例、指标口径和示范回答。回答时始终说明目标、边界、证据、取舍和复盘。
