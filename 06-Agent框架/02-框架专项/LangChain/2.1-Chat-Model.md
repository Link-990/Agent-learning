# 2.1 Chat Model：如何调用 LLM

调用 LLM 是 LangChain 最基础的能力。这一节我们学习如何调用各种 LLM。

---

## 方式 1：通过 Provider 包直接调用

### OpenAI

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")
response = llm.invoke("你好")
print(response.content)
```

### Anthropic

```python
from langchain_anthropic import ChatAnthropic

llm = ChatAnthropic(model="claude-sonnet-4-6")
response = llm.invoke("你好")
print(response.content)
```

### Google

```python
from langchain_google_genai import ChatGoogleGenerativeAI

llm = ChatGoogleGenerativeAI(model="gemini-2.5-flash")
response = llm.invoke("你好")
print(response.content)
```

### Ollama（本地模型）

```python
from langchain_ollama import ChatOllama

llm = ChatOllama(model="llama3")
response = llm.invoke("你好")
print(response.content)
```

---

## 方式 2：通过 create_agent() 的 Provider 字符串

`create_agent()` 支持更简洁的 Provider 字符串格式：

```python
from langchain.agents import create_agent

# 格式："provider:model_name"
agent = create_agent(model="openai:gpt-5.5", tools=[])
agent = create_agent(model="anthropic:claude-sonnet-4-6", tools=[])
agent = create_agent(model="google_genai:gemini-3.5-flash", tools=[])
agent = create_agent(model="ollama:llama3", tools=[])
agent = create_agent(model="openrouter:anthropic/claude-sonnet-4-6", tools=[])
agent = create_agent(model="fireworks:accounts/fireworks/models/qwen3p5-397b-a17b", tools=[])
```

---

## 传入消息列表

```python
from langchain_core.messages import HumanMessage, SystemMessage

response = llm.invoke([
    SystemMessage(content="你是一个翻译助手"),
    HumanMessage(content="把'Hello'翻译成中文")
])
print(response.content)  # "你好"
```

---

## 流式输出

```python
for chunk in llm.stream("讲一个短故事"):
    print(chunk.content, end="", flush=True)
```

---

## 小结

调用 LLM 的两种方式：
1. **Provider 包**：`ChatOpenAI`、`ChatAnthropic` 等，直接调用
2. **Provider 字符串**：`"openai:gpt-5.5"` 格式，用于 `create_agent()`
