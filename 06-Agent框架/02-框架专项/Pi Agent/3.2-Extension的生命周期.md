# 3.2 Extension 的生命周期

---

## 加载时机

Pi 启动时：
1. 扫描 `~/.pi/agent/extensions/` 目录
2. 加载所有 `.ts` 文件
3. 调用每个 Extension 的 `setup()` 方法
4. 注册工具、命令、事件钩子

---

## 热重载

Pi 支持 `/reload` 命令——修改 Extension 后不用重启：

```
> /reload
Extensions reloaded successfully.
```

---

## 加载顺序

多个 Extension 按文件名排序加载。如果多个 Extension 注册同名命令，会自动分配数字后缀。
