# 9.3 错误处理与重试

Agent 执行中难免出错——LLM API 超时、工具调用失败等。

---

## 工具级错误处理

```python
@tool
def risky_tool(x: int) -> str:
    """可能出错的工具"""
    try:
        result = 100 / x
        return str(result)
    except ZeroDivisionError:
        return "错误：除数不能为零"
```

工具内部的 try/except 可以捕获错误，返回友好的错误信息给 LLM。

---

## LLM 级重试

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-4o-mini",
    max_retries=3,  # API 调用失败时重试 3 次
    request_timeout=30,  # 超时 30 秒
)
```

---

## Agent 级错误处理

```python
try:
    result = agent.invoke(input)
except Exception as e:
    print(f"Agent 执行失败：{e}")
    # 降级处理
    result = {"messages": [AIMessage(content="抱歉，暂时无法处理您的请求")]}
```
