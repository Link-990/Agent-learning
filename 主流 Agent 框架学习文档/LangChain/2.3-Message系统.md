# 2.3 Message 系统：对话消息的类型与格式

LangChain 的消息系统是 Agent 和 LLM 之间通信的基础。理解消息的类型和格式，是构建 Agent 的前提。

---

## 消息类型

LangChain 定义了 4 种核心消息类型：

| 类型 | 类名 | role | 说明 |
|------|------|------|------|
| 系统消息 | `SystemMessage` | `system` | 系统提示词，设定 Agent 行为 |
| 用户消息 | `HumanMessage` | `user` | 用户输入 |
| AI 消息 | `AIMessage` | `assistant` | LLM 的回复 |
| 工具消息 | `ToolMessage` | `tool` | 工具调用的返回结果 |

---

## 基本用法

```python
from langchain_core.messages import (
    SystemMessage,
    HumanMessage,
    AIMessage,
    ToolMessage
)

# 系统消息
sys_msg = SystemMessage(content="你是一个友好的助手")

# 用户消息
user_msg = HumanMessage(content="你好")

# AI 消息（通常由 LLM 生成）
ai_msg = AIMessage(content="你好！有什么可以帮你的？")

# 工具消息
tool_msg = ToolMessage(
    content="晴天，25°C",
    tool_call_id="call_abc123"
)
```

---

## 消息的属性

```python
msg = AIMessage(content="你好")

print(msg.type)        # "ai"
print(msg.content)     # "你好"
print(msg.id)          # 唯一 ID（可选）
print(msg.tool_calls)  # 工具调用列表（如果有）
```

---

## 字典格式

除了用类，也可以用字典格式：

```python
messages = [
    {"role": "system", "content": "你是一个助手"},
    {"role": "user", "content": "你好"},
]

response = llm.invoke(messages)
```

LangChain 会自动把字典转换成对应的消息对象。

---

## 消息列表 = 对话历史

Agent 的对话历史就是一个消息列表：

```python
messages = [
    SystemMessage(content="你是一个天气助手"),
    HumanMessage(content="北京天气怎么样？"),
    AIMessage(content="", tool_calls=[{
        "name": "get_weather",
        "args": {"city": "北京"},
        "id": "call_123"
    }]),
    ToolMessage(content="晴天，25°C", tool_call_id="call_123"),
    AIMessage(content="北京今天晴天，25°C。")
]
```

---

## Kami Code 中的消息处理

Kami Code 的消息处理是**格式无关**的——同时支持字典和 LangChain 消息对象：

```python
# 在 message_stream.py 中
def message_role(message):
    # 方式 1：通过 role/type 字段识别
    role = getattr(message, "type", None) or message.get("role", "")
    
    if role in {"ai", "aimessage", "assistant"}:
        return "assistant"
    elif role in {"human", "humanmessage", "user"}:
        return "user"
    elif role in {"tool", "toolmessage"}:
        return "tool"
```

这种设计让 Kami Code 可以兼容不同来源的消息格式。

---

## 小结

- 4 种消息类型：System、Human、AI、Tool
- 可以用类（`AIMessage`）或字典（`{"role": "assistant"}`）
- 消息列表 = 对话历史
- `tool_calls` 和 `tool_call_id` 用于工具调用
