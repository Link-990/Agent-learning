# 1.3 Pi 与其他 Coding Agent 对比

---

## 对比表

| 特性 | Pi | Claude Code | Cursor | Aider |
|------|-----|------------|--------|-------|
| 语言 | TypeScript | TypeScript | 闭源 | Python |
| 开源 | ✅ | ✅ 部分 | ❌ | ✅ |
| 扩展性 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐ |
| 内置 MCP | ❌（通过 Extension） | ✅ | ✅ | ❌ |
| 树状历史 | ✅ | ❌ | ❌ | ❌ |
| 自修改 | ✅ | ❌ | ❌ | ❌ |
| SDK | ✅ | ✅ | ❌ | ❌ |
| 模型支持 | 15+ Provider | Anthropic only | 多 Provider | 多 Provider |
| 子 Agent | ❌（通过 Extension） | ❌ | ❌ | ❌ |

---

## Pi 的独特优势

1. **树状历史**：可以分支、回溯，像 Git 一样管理对话
2. **自修改**：Agent 可以修改自身
3. **Extension 系统**：TypeScript 原生，深度定制
4. **多种运行模式**：CLI / SDK / RPC / JSON

## Pi 的不足

1. **不是开箱即用**：需要自己配置 Extension
2. **TypeScript only**：Python 用户不友好
3. **社区较小**：比 Claude Code 等新
