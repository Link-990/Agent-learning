# 8.4 层级模式与子图

层级模式是多 Agent 系统的高级架构——Supervisor 下面还有 Sub-supervisor，形成多层嵌套结构。在 LangGraph 中，这通过**子图（Subgraphs）**实现。

---

## 层级模式

```
Supervisor
  ├─ Sub-supervisor 1（研究组）
  │   ├─ Worker A（搜索）
  │   └─ Worker B（分析）
  └─ Sub-supervisor 2（内容组）
      ├─ Worker C（写作）
      └─ Worker D（审核）
```

---

## 子图：把工作流封装成可复用模块

子图就是一个"小图"，可以被嵌入到"大图"中作为一个节点。

### 定义子图

```python
from langgraph.graph import StateGraph, START, END

# 研究组子图
research_graph = StateGraph(ResearchState)
research_graph.add_node("search", search_node)
research_graph.add_node("analyze", analyze_node)
research_graph.add_edge(START, "search")
research_graph.add_edge("search", "analyze")
research_graph.add_edge("analyze", END)

# 编译子图
research_subgraph = research_graph.compile()
```

### 在主图中使用子图

```python
# 主图
main_graph = StateGraph(MainState)
main_graph.add_node("research", research_subgraph)  # 把子图作为节点
main_graph.add_node("writing", writing_node)
main_graph.add_edge(START, "research")
main_graph.add_edge("research", "writing")
main_graph.add_edge("writing", END)

main_app = main_graph.compile()
```

## 完整示例

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain_openai import ChatOpenAI
from typing import TypedDict
from langchain_core.messages import BaseMessage

# ========== 研究组子图 ==========
class ResearchState(TypedDict):
    messages: list[BaseMessage]
    research_data: str

def search_node(state: ResearchState):
    llm = ChatOpenAI(model="gpt-4o-mini")
    response = llm.invoke([
        {"role": "system", "content": "你是搜索专家，搜索资料。"},
        *state["messages"]
    ])
    return {"research_data": response.content}

def analyze_node(state: ResearchState):
    llm = ChatOpenAI(model="gpt-4o-mini")
    response = llm.invoke([
        {"role": "system", "content": f"你是分析专家。基于以下资料进行分析：\n{state['research_data']}"},
        *state["messages"]
    ])
    return {"messages": [response]}

research_graph = StateGraph(ResearchState)
research_graph.add_node("search", search_node)
research_graph.add_node("analyze", analyze_node)
research_graph.add_edge(START, "search")
research_graph.add_edge("search", "analyze")
research_graph.add_edge("analyze", END)
research_app = research_graph.compile()

# ========== 内容组子图 ==========
class ContentState(TypedDict):
    messages: list[BaseMessage]
    draft: str

def write_node(state: ContentState):
    llm = ChatOpenAI(model="gpt-4o")
    response = llm.invoke([
        {"role": "system", "content": "你是写作专家。"},
        *state["messages"]
    ])
    return {"draft": response.content}

def review_node(state: ContentState):
    llm = ChatOpenAI(model="gpt-4o-mini")
    response = llm.invoke([
        {"role": "system", "content": f"你是审核专家。审核以下文章：\n{state['draft']}"},
        *state["messages"]
    ])
    return {"messages": [response]}

content_graph = StateGraph(ContentState)
content_graph.add_node("write", write_node)
content_graph.add_node("review", review_node)
content_graph.add_edge(START, "write")
content_graph.add_edge("write", "review")
content_graph.add_edge("review", END)
content_app = content_graph.compile()

# ========== 主图 ==========
class MainState(TypedDict):
    messages: list[BaseMessage]

main_graph = StateGraph(MainState)
main_graph.add_node("research", research_app)  # 子图作为节点
main_graph.add_node("content", content_app)    # 子图作为节点
main_graph.add_edge(START, "research")
main_graph.add_edge("research", "content")
main_graph.add_edge("content", END)

main_app = main_graph.compile()

# 测试
result = main_app.invoke({
    "messages": [{"role": "user", "content": "写一篇关于 AI 的文章"}]
})
```

---

## 子图的优势

- ✅ **模块化**：每个子图独立开发、测试
- ✅ **可复用**：同一个子图可以用在多个主图中
- ✅ **清晰**：大图简洁，细节封装在子图中
- ✅ **团队协作**：不同团队负责不同子图

---

## 小结

层级模式与子图：
- 用子图封装复杂的子工作流
- 子图可以作为主图的节点
- 适合大型、复杂的 Agent 系统
