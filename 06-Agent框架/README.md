# Agent 框架

框架是前面概念的工程映射，不是学习 Agent 的起点。建议先完成 Agent Runtime，再选择一个框架深入。

## 目录

- [框架概览](01-框架概览/README.md)：选型、Harness 和通用边界。
- [框架专项](02-框架专项/README.md)：LangChain、LangGraph、Deep Agents、Pi Agent 的完整资料。

## 选择建议

- 想学习显式状态和可恢复编排：优先 LangGraph。
- 想学习模型、消息和工具的快速拼装：优先 LangChain。
- 想学习长任务、后端、上下文和子 Agent：阅读 Deep Agents。
- 想学习 TypeScript Coding Agent 的 Session、Extension 和 Hooks：阅读 Pi Agent。
