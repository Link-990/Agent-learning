# 9.2 Context Schema 与多租户

`context_schema` 让你为 Agent 注入运行时上下文——比如用户 ID、租户 ID 等。

---

## 用法

```python
from dataclasses import dataclass
from langchain.agents import create_agent
from langchain.tools import tool, ToolRuntime

@dataclass
class AppContext:
    user_id: str
    tenant_id: str

@tool
def get_user_data(runtime: ToolRuntime[AppContext]) -> str:
    """获取用户数据"""
    return f"用户 {runtime.context.user_id} 的数据"

agent = create_agent(
    model="gpt-4o-mini",
    tools=[get_user_data],
    context_schema=AppContext,
)

# 调用时传入上下文
result = agent.invoke(
    {"messages": [...]},
    context=AppContext(user_id="u123", tenant_id="t456")
)
```

---

## 多租户场景

不同租户可以有不同的数据隔离：

```python
# 租户 A 的请求
agent.invoke(input, context=AppContext(user_id="u1", tenant_id="tenant_a"))

# 租户 B 的请求
agent.invoke(input, context=AppContext(user_id="u2", tenant_id="tenant_b"))
```
