# 3.5 规划工具：write_todos

`write_todos` 让 Agent 能够制定和管理任务计划。

---

## 使用方式

Agent 调用 `write_todos` 创建任务列表：

```
write_todos(todos=[
    {"id": "1", "content": "搜索资料", "status": "pending"},
    {"id": "2", "content": "分析数据", "status": "pending"},
    {"id": "3", "content": "撰写报告", "status": "pending"},
])
```

## 更新任务状态

```
write_todos(todos=[
    {"id": "1", "content": "搜索资料", "status": "completed"},
    {"id": "2", "content": "分析数据", "status": "in_progress"},
    {"id": "3", "content": "撰写报告", "status": "pending"},
])
```

## 任务状态

| 状态 | 含义 |
|------|------|
| `pending` | 待处理 |
| `in_progress` | 进行中 |
| `completed` | 已完成 |

---

## 任务持久化

任务信息保存在 Agent 的 State 中，不会丢失。即使 Agent 重启，任务列表依然存在。

---

## 配合子 Agent

Agent 可以结合 `write_todos` 和 `task()` 实现复杂的工作流：

```
1. write_todos: 创建计划
2. task("researcher", "搜索资料"): 委派搜索任务
3. write_todos: 更新搜索任务为 completed
4. task("writer", "写报告"): 委派写作任务
5. write_todos: 所有任务 completed
```
