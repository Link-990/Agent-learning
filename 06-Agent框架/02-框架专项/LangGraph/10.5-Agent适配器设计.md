# 10.5 Agent 适配器设计

Kami Code 通过 `deepagents_adapter.py` 设计了一个优雅的**适配器层**——把 `deepagents`（基于 LangGraph）的 Agent 适配成统一的接口。

---

## 设计目标

1. **统一接口**：不管底层用什么框架，对外暴露一致的 API
2. **降级兼容**：优先用高级 API，失败时降级到低级 API
3. **可测试**：适配器可以 mock，方便测试

---

## 适配器接口

```python
class AgentAdapter:
    """Agent 适配器基类"""
    
    def invoke(self, payload: dict) -> dict:
        """同步调用"""
        raise NotImplementedError
    
    def stream(self, payload: dict) -> Iterator:
        """流式调用"""
        raise NotImplementedError
    
    def stream_events(self, payload: dict) -> Iterator[RuntimeEvent]:
        """事件流调用"""
        raise NotImplementedError
```

---

## deepagents 适配器实现

```python
class DeepAgentsAdapter(AgentAdapter):
    """deepagents 适配器"""
    
    def __init__(self, agent, model_profile):
        self._agent = agent
        self.model_profile = model_profile
    
    def stream_events(self, payload: dict) -> Iterator[RuntimeEvent]:
        """核心方法：流式事件迭代"""
        usage_accumulator = UsageAccumulator(model=self.model_profile.name)
        
        try:
            # 方式 1：messages stream mode（推荐）
            for chunk in self._agent.stream(payload, stream_mode="messages"):
                # 提取 Token 使用量
                usage_accumulator.observe(
                    usage_from_stream_chunk(chunk, model=self.model_profile.name)
                )
                
                # 转换为统一事件
                yield from self._message_stream_chunk_to_events(chunk)
                yield from self.drain_tool_events()
        
        except TypeError:
            # 方式 2：降级到 state stream mode
            usage_accumulator = UsageAccumulator(model=self.model_profile.name)
            
            for chunk in self._agent.stream(payload):
                usage_accumulator.observe(
                    usage_from_stream_chunk(chunk, model=self.model_profile.name)
                )
                
                yield from self._state_stream_chunk_to_events(chunk)
                yield from self.drain_tool_events()
        
        finally:
            # 输出 Token 使用量汇总
            yield RuntimeEvent(
                type="usage_summary",
                data=usage_accumulator.summary()
            )
```

## 消息 chunk 转事件

```python
def _message_stream_chunk_to_events(self, chunk):
    """将 LangGraph 的 message chunk 转换为统一事件"""
    message = chunk[0]
    node = _stream_node(chunk)
    
    events = []
    
    # 1. assistant 文本增量
    text = assistant_text_from_stream_chunk(chunk)
    if text:
        events.append(RuntimeEvent(type="text_delta", data={"content": text}))
    
    # 2. 工具调用开始
    if node == "tools":
        tool_calls = getattr(message, "tool_calls", [])
        if tool_calls:
            events.append(RuntimeEvent(
                type="tool_call_start",
                data={"name": tool_calls[0]["name"]}
            ))
    
    # 3. 工具调用结束
    if node == "tools" and getattr(message, "type", None) == "tool":
        events.append(RuntimeEvent(
            type="tool_call_end",
            data={"result": message.content}
        ))
    
    return events
```

---

## 降级策略

```
尝试 stream_mode="messages"
    ↓ 成功 → 使用消息级流式
    ↓ 失败（TypeError）
尝试 stream() 无参数
    ↓ 使用状态级流式
```

这种降级策略保证了**兼容性**——即使 Agent 不支持高级 API，也能正常工作。

---

## 小结

适配器设计的关键：

1. **统一接口**：`invoke` / `stream` / `stream_events`
2. **降级兼容**：优先 messages mode，降级 state mode
3. **事件转换**：把框架特定的数据格式转为统一事件
4. **Token 追踪**：在适配器层统一处理
