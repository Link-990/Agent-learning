# 3.1 StateGraph 类详解

`StateGraph` 是 LangGraph 的核心类——用它来构建图、添加节点、添加边，最后编译成可执行的 Agent。

这一节我们把 StateGraph 类的用法彻底搞清楚。

---

## StateGraph 的基本用法

### 第一步：导入

```python
from langgraph.graph import StateGraph
```

### 第二步：定义 State 类型

```python
from typing import TypedDict

class MyState(TypedDict):
    input: str
    output: str
```

### 第三步：创建 StateGraph 对象

```python
graph = StateGraph(MyState)
```

这行代码做了什么？
- 创建一个图对象
- 告诉 LangGraph："这个图的 State 类型是 MyState"
- LangGraph 会根据 MyState 进行类型检查

---

## StateGraph 的核心方法

StateGraph 提供了几个核心方法来构建图：

| 方法 | 作用 |
|------|------|
| `add_node(name, func)` | 添加一个节点 |
| `add_edge(from, to)` | 添加一条固定边 |
| `add_conditional_edges(from, router, path_map)` | 添加条件边 |
| `set_entry_point(node)` | 设置入口节点（已废弃，用 START） |
| `compile()` | 编译图，生成可执行对象 |

我们逐个讲解。

---

## add_node()：添加节点

### 语法

```python
graph.add_node(name: str, func: Callable)
```

- **name**：节点的名字（字符串），后面用这个名字来引用节点
- **func**：节点对应的函数

### 示例

```python
def my_node(state):
    return {"output": "处理结果"}

graph.add_node("my_node", my_node)
```

### 节点名字的规范

- 只能包含字母、数字、下划线、连字符
- 建议用小写 + 下划线：`call_llm`、`query_db`
- 避免用数字开头：`1_node` ❌

---

## add_edge()：添加固定边

### 语法

```python
graph.add_edge(from_node: str, to_node: str)
```

- **from_node**：起点节点的名字
- **to_node**：终点节点的名字

### 示例

```python
graph.add_edge("node_a", "node_b")
```

表示：执行完 `node_a`，接下来执行 `node_b`。

### 特殊节点：START 和 END

```python
from langgraph.graph import START, END

graph.add_edge(START, "first_node")  # 从开始到 first_node
graph.add_edge("last_node", END)     # 从 last_node 到结束
```

---

## add_conditional_edges()：添加条件边

### 语法

```python
graph.add_conditional_edges(
    source: str,
    path: Callable,
    path_map: dict
)
```

- **source**：从哪个节点出来
- **path**：路由函数，根据 State 返回一个字符串
- **path_map**：把路由函数的返回值映射到节点名

### 示例

```python
def my_router(state):
    if state["count"] > 10:
        return "branch_a"
    else:
        return "branch_b"

graph.add_conditional_edges(
    "decision_node",
    my_router,
    {
        "branch_a": "node_a",
        "branch_b": "node_b"
    }
)
```

---

## compile()：编译图

### 语法

```python
app = graph.compile(checkpointer=None, interrupt_before=None, interrupt_after=None)
```

- **checkpointer**：持久化检查点（后面章节会讲），默认不持久化
- **interrupt_before**：在哪些节点之前暂停（用于人工介入）
- **interrupt_after**：在哪些节点之后暂停

### 返回值

返回一个 `CompiledGraph` 对象，可以调用 `invoke()` 或 `stream()` 运行。

---

## 完整示例：一个三节点的图

```python
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 定义 State
class MyState(TypedDict):
    value: int

# 定义节点
def add_10(state):
    return {"value": state["value"] + 10}

def multiply_2(state):
    return {"value": state["value"] * 2}

def subtract_5(state):
    return {"value": state["value"] - 5}

# 构建图
graph = StateGraph(MyState)

# 添加节点
graph.add_node("add", add_10)
graph.add_node("multiply", multiply_2)
graph.add_node("subtract", subtract_5)

# 添加边
graph.add_edge(START, "add")
graph.add_edge("add", "multiply")
graph.add_edge("multiply", "subtract")
graph.add_edge("subtract", END)

# 编译
app = graph.compile()

# 运行
result = app.invoke({"value": 0})
print(result)  # {"value": 15}
# 过程：0 + 10 = 10 → 10 * 2 = 20 → 20 - 5 = 15
```

## 常见错误

### 错误 1：节点名字拼错

```python
graph.add_node("my_node", my_func)
graph.add_edge(START, "my_nod")  # 拼错了！
```

报错：`Node 'my_nod' not found`

**解决**：仔细检查拼写。

### 错误 2：节点没有出边

```python
graph.add_node("lonely_node", func)
graph.add_edge(START, "lonely_node")
# 忘了：graph.add_edge("lonely_node", END)

app = graph.compile()  # 报错！
```

报错：`Node 'lonely_node' has no outgoing edges`

**解决**：确保每个节点都有出边。

### 错误 3：State 类型不匹配

```python
class MyState(TypedDict):
    value: int

def bad_node(state):
    return {"value": "字符串"}  # 类型错了！

graph = StateGraph(MyState)
graph.add_node("bad", bad_node)
# ... 运行时可能报错
```

**解决**：确保节点返回的类型，与 State 定义一致。

---

## StateGraph 的高级选项

### 1. 设置并发限制

```python
graph = StateGraph(MyState, config={"max_concurrency": 5})
```

当有并行节点时，最多同时执行 5 个。

### 2. 自定义节点超时

```python
graph.add_node("slow_node", slow_func, timeout=30)  # 30 秒超时
```

（注意：这个功能在某些版本可能不可用，具体看文档）

---

## 小结

`StateGraph` 是 LangGraph 的核心类，用法总结：

1. **创建**：`graph = StateGraph(StateType)`
2. **添加节点**：`graph.add_node(name, func)`
3. **添加边**：
   - 固定边：`graph.add_edge(from, to)`
   - 条件边：`graph.add_conditional_edges(source, router, path_map)`
4. **编译**：`app = graph.compile()`
5. **运行**：`app.invoke(initial_state)`

掌握了这 5 步，你就能构建任何 LangGraph 应用。
