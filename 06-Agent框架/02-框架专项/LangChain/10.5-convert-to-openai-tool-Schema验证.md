# 10.5 convert_to_openai_tool：Schema 验证

Kami Code 在测试中用 `convert_to_openai_tool` 验证工具 Schema 的正确性。

---

## 核心代码

```python
# tests/test_plan_mode_tools.py
from langchain_core.utils.function_calling import convert_to_openai_tool

# 验证工具能正确转为 OpenAI function calling 格式
schema = convert_to_openai_tool(enter_tool, strict=True)["function"]

assert "properties" in schema["parameters"]
assert "required" in schema["parameters"]
```

---

## 作用

`convert_to_openai_tool` 把 LangChain 的工具定义转成 OpenAI 的 function calling 格式：

```python
# LangChain 工具
@tool
def search(query: str) -> str:
    """搜索"""
    ...

# 转成 OpenAI 格式
{
    "type": "function",
    "function": {
        "name": "search",
        "description": "搜索",
        "parameters": {
            "type": "object",
            "properties": {
                "query": {"type": "string"}
            },
            "required": ["query"]
        }
    }
}
```

---

## 为什么要验证？

确保工具定义能被所有 LLM Provider 正确解析——如果 Schema 格式不对，某些 Provider 可能无法调用工具。
