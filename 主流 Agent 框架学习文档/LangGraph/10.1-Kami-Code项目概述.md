# 10.1 Kami Code 项目概述

## 项目简介

**Kami Code** 是一个类似 Claude Code 的**本地 CLI 编程助手**（coding agent），项目名为 KamiAgent。

它的核心功能：
- 在终端中与 AI 对话
- AI 可以读写文件、执行命令、搜索代码
- 支持多种 LLM provider（OpenAI、Anthropic 等）
- 支持工具调用和流式输出

---

## 技术栈

```
Kami Code
├── deepagents（核心框架，基于 LangGraph）
├── LangGraph（Agent 编排引擎）
├── LangChain（LLM 调用和工具集成）
└── CLI 界面（终端交互）
```

---

## 关键发现：LangGraph 的使用方式

**Kami Code 并不直接使用 LangGraph**，而是通过 `deepagents` 框架间接使用。

```
Kami Code
    ↓ 使用
deepagents（基于 LangGraph 的上层框架）
    ↓ 使用
LangGraph（底层编排引擎）
    ↓ 使用
LangChain（LLM 和工具）
```

`deepagents` 是 LangChain 生态中的"全家桶"——它封装了 LangGraph 的图构建、节点定义、边连接等底层细节，提供了更高级的 `create_deep_agent()` API。

Kami Code 的代码专注于**消费 LangGraph 的流式输出**——解析 `(message, metadata)` 元组中的 `langgraph_node` 字段来实现消息路由和 token 统计。

## LangGraph 在 Kami Code 中的角色

虽然 Kami Code 不直接构建 LangGraph 图，但它**深度消费 LangGraph 的输出**：

| LangGraph 特性 | Kami Code 的使用方式 |
|---------------|---------------------|
| Stream (messages mode) | `agent.stream(payload, stream_mode="messages")` |
| `langgraph_node` metadata | 通过元数据区分消息来源节点 |
| 节点类型识别 | `"model"`, `"tools"`, `"input"` |
| Message format | `(AIMessageChunk, {"langgraph_node": "model"})` |

---

## 推断出的 LangGraph 图结构

根据代码分析，Kami Code 底层的 LangGraph 图是一个典型的 **ReAct 模式**：

```
[input] --用户消息--> [model] --LLM响应--> {条件路由}
    ↑                                        |
    |                                        ↓
    +--- 工具结果 ---- [tools] ────────────────┘
```

1. **input 节点**：接收用户输入
2. **model 节点**：调用 LLM 生成响应或工具调用
3. **tools 节点**：执行工具调用并返回结果
4. 条件边：LLM 输出如果是工具调用则路由到 tools，否则结束

这就是我们在第 3.7 节学的 **ReAct Agent** 模式！

## 小结

Kami Code 项目的关键信息：
- 基于 `deepagents` 框架（底层使用 LangGraph）
- 核心是消费 LangGraph 的流式输出
- 使用 ReAct 模式的 Agent 架构
- 通过 `langgraph_node` 元数据实现消息路由
