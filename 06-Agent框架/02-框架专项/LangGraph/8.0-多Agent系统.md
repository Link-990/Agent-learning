## 为什么需要多 Agent？

### 单 Agent 的局限

一个 Agent 要处理所有事情：
- 搜索信息
- 分析数据
- 生成内容
- 审核质量
- ...

**问题**：
1. **Prompt 太长**：系统提示塞满了各种指令，LLM 容易混淆
2. **能力有限**：一个 Agent 很难在所有方面都做到最好
3. **难以维护**：修改一个功能可能影响其他功能
4. **无法并行**：所有步骤串行执行，效率低

### 多 Agent 的优势

把任务拆分给不同的专业 Agent：
- **研究员 Agent**：专注搜索和分析
- **写手 Agent**：专注内容生成
- **审核员 Agent**：专注质量检查

**优势**：
1. ✅ 每个 Agent 的 Prompt 简洁清晰
2. ✅ 每个 Agent 专注一件事，效果更好
3. ✅ 模块化，易于维护和扩展
4. ✅ 可以并行执行，提高效率

## 多 Agent 的常见模式

### 1. Supervisor 模式（领导分配）

一个 Supervisor Agent 负责分配任务，Worker Agent 负责执行。

```
Supervisor → Worker A
           → Worker B
           → Worker C
```

### 2. Swarm 模式（自主交接）

Agent 之间自主交接，没有中心化的 Supervisor。

```
Agent A ⇄ Agent B ⇄ Agent C
```

### 3. 层级模式（多层嵌套）

Supervisor 下面还有 Sub-supervisor，形成多层结构。

```
Supervisor
  ├─ Sub-supervisor 1
  │   ├─ Worker A
  │   └─ Worker B
  └─ Sub-supervisor 2
      └─ Worker C
```
