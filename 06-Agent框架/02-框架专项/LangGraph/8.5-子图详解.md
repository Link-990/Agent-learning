# 8.5 子图详解

子图（Subgraph）是 LangGraph 中实现多 Agent 系统的关键技术。这一节我们深入讲解子图的使用方法和最佳实践。

---

## 子图的本质

子图就是一个**编译好的 LangGraph 应用**（CompiledGraph），它可以作为另一个图的**节点**使用。

```python
# 子图
sub_app = sub_graph.compile()

# 主图中使用
main_graph.add_node("sub", sub_app)  # 直接把编译后的子图作为节点
```

---

## 子图的 State 传递

### 方式 1：相同 State 类型

如果子图和主图使用相同的 State 类型，数据自动传递：

```python
# 主图和子图都用 MessagesState
main_graph = StateGraph(MessagesState)
sub_graph = StateGraph(MessagesState)

sub_app = sub_graph.compile()
main_graph.add_node("sub", sub_app)

# messages 会自动在子图和主图之间传递
```

### 方式 2：不同 State 类型

如果 State 类型不同，需要用**输入/输出函数**做转换：

```python
class MainState(TypedDict):
    messages: list
    user_id: str

class SubState(TypedDict):
    messages: list
    research_data: str

# 输入函数：主图 State → 子图 State
def main_to_sub(state: MainState) -> SubState:
    return {
        "messages": state["messages"],
        "research_data": ""
    }

# 输出函数：子图 State → 主图 State
def sub_to_main(result: SubState) -> dict:
    return {"messages": result["messages"]}

# 添加子图节点，带转换函数
main_graph.add_node("sub", sub_app, input=main_to_sub, output=sub_to_main)
```

---

## 子图的流式输出

子图的流式事件会自动冒泡到主图：

```python
for event in main_app.stream_events(input, version="v2"):
    # 包括子图内部的节点执行事件
    print(event)
```

---

## 嵌套子图

子图可以嵌套——子图的节点也可以是子图：

```python
# 三层嵌套
level3 = level3_graph.compile()
level2_graph.add_node("level3", level3)
level2 = level2_graph.compile()
level1_graph.add_node("level2", level2)
level1 = level1_graph.compile()
```

---

## 最佳实践

1. **每个子图职责单一**
2. **子图之间通过 State 传递数据**
3. **避免过深的嵌套（最多 3 层）**
4. **子图要独立可测试**

---

## 小结

子图的核心：
- 编译后的 LangGraph 应用可以作为节点
- State 传递：相同类型自动传递，不同类型需要转换
- 支持嵌套
- 适合模块化设计
