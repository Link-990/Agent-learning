# 10.1 Kami Code 架构概览

---

## 技术栈

```
Kami Code
├── deepagents（核心框架，基于 LangGraph）
│   ├── LangGraph（Agent 编排引擎）
│   └── LangChain（工具协议 + Middleware）
├── KamiAgent（编程助手逻辑）
│   ├── ToolRegistry（工具注册表）
│   ├── PermissionPolicy（权限策略）
│   └── Runtime（运行时管理）
└── CLI（终端界面）
```

---

## Deep Agents 在 Kami Code 中的角色

Kami Code 的核心是一个 Deep Agent：

```python
# 简化版
agent = create_deep_agent(
    model=model_profile,
    tools=tool_registry.as_structured_tool_list(),
    middleware=[DeferredToolMiddleware(activation_state)],
    system_prompt=system_prompt,
)
```

Deep Agent 提供了：
- 文件系统访问（读写代码文件）
- 工具调用循环（ReAct 模式）
- 流式输出（Token 级）
- 中间件扩展（延迟加载过滤）

---

## 底层 LangGraph 图结构

```
[input] → [model] → {条件路由}
             ↑          ↓
             └── [tools] ┘
```

标准的 ReAct 模式——model 节点调用 LLM，tools 节点执行工具。
