# 3.3 MessagesState——内置的消息状态

如果你要做一个**对话 Agent**（聊天机器人、问答助手、客服机器人），那么 `MessagesState` 是你的最佳选择。

它是 LangGraph 内置的 State 类型，专门为对话场景优化——自动处理消息列表的追加、去重、更新。

---

## MessagesState 是什么？

`MessagesState` 本质上是一个预定义的 TypedDict，长这样：

```python
from typing import TypedDict, Annotated
from langgraph.graph import add_messages

class MessagesState(TypedDict):
    messages: Annotated[list, add_messages]
```

就一个字段：`messages`，类型是"带有 `add_messages` reducer 的列表"。

---

## 为什么要用 MessagesState？

### 场景：做一个对话 Agent

对话 Agent 的核心是**维护对话历史**：

```
用户：你好
AI：你好！有什么可以帮你的吗？
用户：今天天气怎么样？
AI：今天天气晴朗，温度 25°C。
```

对话历史就是一个消息列表：

```python
messages = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！有什么可以帮你的吗？"},
    {"role": "user", "content": "今天天气怎么样？"},
    {"role": "assistant", "content": "今天天气晴朗，温度 25°C。"}
]
```

每个节点（调用 LLM、调用工具）都会产生新消息，需要追加到列表里。

**MessagesState 就是为这个场景设计的**。

---

## 如何使用 MessagesState？

### 导入

```python
from langgraph.graph import MessagesState
```

### 创建图

```python
from langgraph.graph import StateGraph

graph = StateGraph(MessagesState)
```

### 在节点里使用

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

def call_llm(state: MessagesState):
    messages = state["messages"]
    response = llm.invoke(messages)
    return {"messages": [response]}
```

### 运行

```python
app = graph.compile()

result = app.invoke({
    "messages": [{"role": "user", "content": "你好"}]
})

print(result["messages"][-1].content)
```

## add_messages 的智能行为

`add_messages` 不是简单的列表拼接，它有三个智能特性：

### 1. 自动追加消息

```python
# 当前 State
state = {"messages": [
    {"role": "user", "content": "你好"}
]}

# 节点返回
return {"messages": [
    {"role": "assistant", "content": "你好！"}
]}

# 合并后
state = {"messages": [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！"}
]}
```

### 2. 基于 ID 的去重/更新

如果消息有 `id` 字段，相同 `id` 的消息会被**更新**而不是重复追加。

```python
# 当前 State
state = {"messages": [
    {"role": "assistant", "content": "思考中...", "id": "msg_123"}
]}

# 节点返回（相同 id）
return {"messages": [
    {"role": "assistant", "content": "答案是 42", "id": "msg_123"}
]}

# 合并后（替换了，而不是追加）
state = {"messages": [
    {"role": "assistant", "content": "答案是 42", "id": "msg_123"}
]}
```

这在"流式输出"场景非常有用——可以不断更新同一条消息的内容。

### 3. 支持 LangChain 的消息对象

LangChain 有专门的消息类：`HumanMessage`、`AIMessage`、`SystemMessage` 等。

`add_messages` 兼容这些对象：

```python
from langchain_core.messages import HumanMessage, AIMessage

# 节点返回
return {"messages": [
    AIMessage(content="你好！")
]}

# 自动转换并追加
```

## 扩展 MessagesState：添加自定义字段

有时候，除了 `messages`，你还需要其他字段。可以继承 `MessagesState`：

```python
from langgraph.graph import MessagesState

class MyState(MessagesState):
    user_id: str
    session_id: str
    tool_result: str
```

这样定义的 State 包含：
- `messages`（继承自 MessagesState）
- `user_id`、`session_id`、`tool_result`（自定义字段）

### 使用

```python
graph = StateGraph(MyState)

def my_node(state: MyState):
    user_id = state["user_id"]
    messages = state["messages"]
    # ...
    return {"messages": [response], "tool_result": "结果"}
```

## 完整示例：一个简单的对话 Agent

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, MessagesState, START, END

load_dotenv()
llm = ChatOpenAI(model="gpt-4o-mini")

# 定义节点
def call_llm(state: MessagesState):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

# 构建图
graph = StateGraph(MessagesState)
graph.add_node("llm", call_llm)
graph.add_edge(START, "llm")
graph.add_edge("llm", END)

# 编译
app = graph.compile()

# 第一轮对话
result = app.invoke({
    "messages": [{"role": "user", "content": "你好"}]
})
print("AI:", result["messages"][-1].content)

# 第二轮对话（继续之前的历史）
result = app.invoke({
    "messages": result["messages"] + [
        {"role": "user", "content": "你叫什么名字？"}
    ]
})
print("AI:", result["messages"][-1].content)
```

输出：

```
AI: 你好！有什么可以帮你的吗？
AI: 我是 Claude，一个 AI 助手。很高兴认识你！
```

## MessagesState 的消息格式

### 标准格式（OpenAI 风格）

```python
{
    "role": "user" | "assistant" | "system" | "tool",
    "content": "消息内容",
    "name": "可选：发送者名字",
    "tool_calls": [...]  # 可选：工具调用
}
```

### LangChain 消息对象

```python
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage, ToolMessage

HumanMessage(content="用户输入")
AIMessage(content="AI 回复")
SystemMessage(content="系统提示")
ToolMessage(content="工具返回", tool_call_id="...")
```

两种格式可以混用，LangGraph 会自动转换。

## 常见场景

### 场景 1：添加系统提示

```python
def add_system_prompt(state: MessagesState):
    messages = state["messages"]
    if not any(msg.get("role") == "system" for msg in messages):
        # 如果还没有系统提示，添加一个
        return {"messages": [
            {"role": "system", "content": "你是一个友好的助手。"}
        ]}
    return {}
```

### 场景 2：限制对话历史长度

```python
def trim_messages(state: MessagesState):
    messages = state["messages"]
    if len(messages) > 20:
        # 只保留最近 20 条消息
        return {"messages": messages[-20:]}
    return {}
```

### 场景 3：工具调用后的消息追加

```python
def call_tool(state: MessagesState):
    # 假设 LLM 返回了工具调用
    tool_result = "查询结果：晴天，25°C"
    return {"messages": [
        {"role": "tool", "content": tool_result, "tool_call_id": "call_123"}
    ]}
```

---

## 小结

- **MessagesState**：LangGraph 内置的消息状态，专为对话 Agent 设计
- **核心字段**：`messages: Annotated[list, add_messages]`
- **智能行为**：
  - 自动追加消息
  - 基于 ID 去重/更新
  - 兼容 LangChain 消息对象
- **扩展**：可以继承 MessagesState，添加自定义字段
- **适用场景**：所有需要维护对话历史的 Agent

如果你在做对话 Agent，直接用 MessagesState 就对了——它帮你处理了 90% 的消息管理逻辑。
