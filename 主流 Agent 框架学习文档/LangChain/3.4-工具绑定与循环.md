# 3.4 工具绑定与工具调用循环

`create_agent()` 会自动处理工具绑定和调用循环。这一节我们理解它的内部工作原理。

---

## 底层原理

`create_agent()` 创建的 Agent，底层是一个 LangGraph 图：

```
START → model → 判断
           ↓       ↑
        (需要工具?) │
           ↓       │
         tools ────┘
           ↓
         END (不需要工具时)
```

1. **model 节点**：调用 LLM
2. **判断**：LLM 返回了 tool_calls 吗？
   - 是 → 去 tools 节点
   - 否 → 结束
3. **tools 节点**：执行工具调用，把结果加入消息列表
4. **回到 model 节点**：LLM 看到工具结果，继续判断

---

## 工具绑定的过程

```python
agent = create_agent(model="openai:gpt-4o-mini", tools=[tool1, tool2])
```

内部执行：

```python
# 1. 创建 LLM
llm = ChatOpenAI(model="gpt-4o-mini")

# 2. 绑定工具
llm_with_tools = llm.bind_tools([tool1, tool2])

# 3. 构建 LangGraph 图
# ... 省略
```

---

## 工具调用循环（详解）

```
用户: "北京天气怎么样？"
    ↓
[Step 1] model 节点
    LLM 看到：用户消息 + [get_weather] 工具
    LLM 决定：调用 get_weather(city="北京")
    返回：AIMessage(tool_calls=[{"name": "get_weather", "args": {"city": "北京"}}])
    ↓
[判断] 有 tool_calls → 去 tools 节点
    ↓
[Step 2] tools 节点
    执行：get_weather(city="北京") → "晴天，25°C"
    返回：ToolMessage(content="晴天，25°C", tool_call_id="call_123")
    ↓
[回到 model 节点]
    ↓
[Step 3] model 节点
    LLM 看到：用户消息 + AI 的工具调用 + 工具结果
    LLM 决定：不需要工具了，生成回复
    返回：AIMessage(content="北京今天晴天，25°C。")
    ↓
[判断] 没有 tool_calls → END
    ↓
返回给用户
```

---

## 循环终止条件

循环在以下情况终止：
1. LLM 不再返回 tool_calls（认为任务完成）
2. 达到最大迭代次数（防止无限循环）

---

## 小结

- `create_agent()` 自动绑定工具到 LLM
- 底层的 LangGraph 图处理工具调用循环
- 循环直到 LLM 不再需要工具
- 你只需要定义工具和 system_prompt
