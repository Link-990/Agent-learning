# 6.1 为什么需要子 Agent？

---

## 单 Agent 的问题

一个 Agent 做所有事：
- Prompt 太长，LLM 容易混淆
- 无法并行处理
- 不能利用"专家"知识

## 子 Agent 的解决方案

把任务分给"专家"：
- **researcher**：专注搜索
- **writer**：专注写作
- **coder**：专注编程

每个子 Agent 有独立的 system_prompt、工具、甚至不同的模型。

---

## 类比

```
单 Agent = 一个人做所有事
子 Agent = 一个团队，各司其职
```
