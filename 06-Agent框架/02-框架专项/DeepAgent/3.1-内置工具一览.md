# 3.1 内置工具一览

Deep Agents 内置了一套完整的工具，不需要手动添加。

---

## 文件系统工具

| 工具 | 功能 | 参数 |
|------|------|------|
| `ls` | 列出目录内容 | `path` |
| `read_file` | 读取文件 | `path` |
| `write_file` | 写入文件 | `path`, `content` |
| `edit_file` | 编辑文件 | `path`, `edits` |
| `delete` | 删除文件 | `path` |

## 搜索工具

| 工具 | 功能 | 参数 |
|------|------|------|
| `glob` | 搜索文件名 | `pattern` |
| `grep` | 搜索文件内容 | `pattern`, `path` |

## 执行工具

| 工具 | 功能 | 参数 |
|------|------|------|
| `execute` | 执行 Shell 命令 | `command` |
| `eval` | 执行 JavaScript | `code` |

## 规划工具

| 工具 | 功能 | 参数 |
|------|------|------|
| `write_todos` | 管理任务列表 | `todos` |

## 委派工具

| 工具 | 功能 | 参数 |
|------|------|------|
| `task` | 委派子任务 | `subagent_type`, `task` |

---

## 工具的使用方式

Agent 通过 LLM 的工具调用机制自动使用这些工具：

```
用户: 列出当前目录的文件
LLM: 调用 ls(path=".")
结果: file1.py, file2.py, README.md
LLM: 当前目录有 file1.py, file2.py, README.md
```
