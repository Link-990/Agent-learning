# 6.1 为什么需要人工介入？

在构建 AI Agent 时，你可能会想："既然 AI 能自动完成任务，为什么还要让人类介入？这不是违背了自动化的初衷吗？"

这个问题问得好。让我们先通过几个真实场景来理解人工介入的必要性。

---

## 场景 1：高风险操作

### 场景描述

你构建了一个"财务 Agent"，用户可以让它：
- 查看账户余额
- 查询交易记录
- **转账**

### 问题

如果 Agent 理解错了用户的意图：
- 用户说："给张三转 100 元"
- Agent 理解成："给张三转 10000 元"

这 100 倍的差距，可能就是灾难性的。

### 解决方案

在执行转账之前，Agent 暂停，显示将要执行的操作，让人类确认：

```
Agent: 即将执行转账：
  收款人：张三
  金额：100 元
  账户：我的工商银行储蓄账户

请确认是否执行？(y/n)
```

人类检查无误后，回复 "y"，Agent 才继续执行。

---

## 场景 2：AI 不确定

### 场景描述

你构建了一个"内容审核 Agent"，自动审核用户发布的内容。

### 问题

有些内容处于"灰色地带"：
- 可能是讽刺，也可能是真实的恶意言论
- AI 判断只有 60% 的把握

如果直接自动处理，可能误判。

### 解决方案

AI 在不确定时暂停，把内容展示给人类审核员：

```
Agent: 以下内容的审核置信度只有 60%，需要人工审核：
  内容："这个产品真是'太棒了'..."
  AI 判断：可能是讽刺，建议标记为负面
  置信度：60%

请人工判断：
  1. 确认是负面内容
  2. 确认是正面内容
  3. 需要更多信息
```

---

## 场景 3：合规要求

### 场景描述

你在金融行业工作，构建了一个"投资建议 Agent"。

### 问题

根据法规，投资建议必须经过合规部门审批才能发布给客户。

### 解决方案

Agent 生成投资建议后，暂停，发送给合规部门审批：

```
Agent: 生成投资建议，等待合规审批：
  建议：建议客户加仓 A 股票，目标价 50 元
  理由：...
  风险提示：...

状态：待审批
```

合规部门审批通过后，Agent 才把建议发送给客户。

---

## 场景 4：质量控制

### 场景描述

你构建了一个"报告生成 Agent"，自动生成销售报告。

### 问题

AI 生成的报告可能有：
- 数据错误
- 逻辑不通
- 格式不规范

### 解决方案

Agent 生成报告后，暂停，让人类审阅：

```
Agent: 报告已生成，请审阅：
  [报告内容]

操作选项：
  1. 批准发布
  2. 需要修改（请在下方输入修改意见）
  3. 重新生成
```

人类审阅后，如果选择"需要修改"，输入修改意见，Agent 根据意见重新生成。

---

## 人工介入的通用模式

从上面 4 个场景，我们可以总结出人工介入的通用模式：

### 1. Agent 执行到关键步骤

Agent 正常执行工作流，直到遇到需要人工介入的步骤。

### 2. 暂停执行

Agent 暂停，保存当前状态。

### 3. 等待人类输入

Agent 等待人类做出决策（批准、修改、拒绝等）。

### 4. 恢复执行

收到人类输入后，Agent 根据输入继续执行。

---

## LangGraph 的实现

LangGraph 通过以下机制实现人工介入：

### 1. interrupt()

在代码里显式暂停：

```python
from langgraph.func import interrupt

# 暂停，等待人类输入
decision = interrupt({"question": "是否批准？"})

# 根据人类输入继续
if decision == "approved":
    execute_action()
else:
    cancel_action()
```

### 2. Checkpointer

保存暂停时的状态，恢复时加载。

### 3. Command(resume=...)

人类输入后，用 `Command` 恢复执行：

```python
from langgraph.types import Command

# 恢复执行，传入人类的输入
app.invoke(Command(resume="approved"), config={"thread_id": "1"})
```

---

## 小结

人工介入的必要性：
- **高风险操作**：防止 AI 理解错误导致损失
- **AI 不确定**：让经验丰富的人类帮忙判断
- **合规要求**：满足法规要求
- **质量控制**：确保输出质量

LangGraph 的实现方式：
- `interrupt()`：暂停执行
- Checkpointer：保存状态
- `Command(resume=...)`：恢复执行
