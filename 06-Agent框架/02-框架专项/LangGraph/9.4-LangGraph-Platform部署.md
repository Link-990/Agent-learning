# 9.4 LangGraph Platform 部署

当你的 Agent 开发完成，需要部署到生产环境时，**LangGraph Platform** 是官方的部署方案。

---

## LangGraph Platform 是什么？

LangGraph Platform 是一个**托管的 Agent 运行时**，提供：

- **API 服务**：把 Agent 暴露为 REST API
- **持久化**：自动保存 Checkpoint 和 State
- **可扩展**：支持水平扩展
- **监控**：内置可观测性

---

## 部署方式

### 方式 1：LangGraph Cloud（托管）

最简单的部署方式——LangChain 帮你托管一切。

```bash
# 安装 CLI
pip install langgraph-cli

# 登录
langgraph login

# 部署
langgraph deploy
```

### 方式 2：LangGraph Server（自托管）

在自己的服务器上部署 LangGraph Server。

```bash
# Docker 部署
docker pull langchain/langgraph-server
docker run -p 8000:8000 langchain/langgraph-server
```

### 方式 3：LangServe（轻量级）

用 FastAPI + LangServe 快速部署。

```python
from fastapi import FastAPI
from langserve import add_routes

app = FastAPI()
add_routes(app, agent, path="/agent")

# 启动
# uvicorn app:app --host 0.0.0.0 --port 8000
```

---

## API 接口

部署后，你会得到以下 API：

| 端点 | 方法 | 说明 |
|------|------|------|
| `/agent/invoke` | POST | 同步调用 |
| `/agent/stream` | POST | 流式调用 |
| `/agent/stream_events` | POST | 事件流调用 |
| `/agent/state` | GET | 获取状态 |
| `/agent/history` | GET | 获取历史 |

---

## 与 Kami Code 的关联

Kami Code 项目使用 `deepagents`（基于 LangGraph）构建 Agent，通过 `deepagents_adapter.py` 适配器提供统一的 API 接口。它的核心就是消费 LangGraph 的流式输出——`stream_mode="messages"` 和 `langgraph_node` 元数据。

---

## 小结

LangGraph 的部署方案：
- **LangGraph Cloud**：最省心，官方托管
- **LangGraph Server**：自托管，Docker 部署
- **LangServe**：轻量级，FastAPI 集成
