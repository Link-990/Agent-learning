# 8.1 什么是 RAG？

RAG 的核心思想：**先检索，再生成**。

---

## 问题

LLM 的知识有截止日期，而且可能不知道你的私有数据。

## 解决方案

1. 把你的知识库（文档、网页等）切分成小块
2. 把每个块转成向量（Embedding）
3. 存入向量数据库
4. 用户提问时，先检索最相关的块
5. 把检索结果 + 用户问题一起发给 LLM

---

## 流程图

```
用户问题
    ↓
[检索知识库] → 找到最相关的文档块
    ↓
[构造 Prompt] = 系统提示 + 文档块 + 用户问题
    ↓
[LLM 生成回答]
    ↓
返回给用户
```

---

## RAG 的 5 个组件

1. **Document Loader**：加载文档
2. **Text Splitter**：切分文档
3. **Embedding Model**：文本转向量
4. **Vector Store**：存储向量
5. **Retriever**：检索相关文档
