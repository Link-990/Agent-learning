# 3.2 快速创建一个 Agent

我们直接动手，创建几个不同类型的 Agent。

---

## 示例 1：最简单的 Agent

```python
from dotenv import load_dotenv
from langchain.agents import create_agent

load_dotenv()

def hello(name: str) -> str:
    """向用户打招呼"""
    return f"你好，{name}！"

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[hello],
    system_prompt="你是一个友好的助手"
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "我叫 Alice，跟我打个招呼"}]}
)
print(result["messages"][-1].content)
# 输出：你好，Alice！很高兴认识你！
```

## 示例 2：天气助手

```python
from langchain.agents import create_agent
from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取城市的天气"""
    weather_data = {
        "北京": "晴天，25°C",
        "上海": "多云，22°C",
        "广州": "小雨，28°C",
    }
    return weather_data.get(city, f"未找到 {city} 的天气数据")

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[get_weather],
    system_prompt="你是一个天气助手。帮用户查询天气信息。"
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "北京和上海今天天气怎么样？"}]}
)
print(result["messages"][-1].content)
# 输出：北京今天晴天，25°C；上海多云，22°C。
```

## 示例 3：多工具 Agent

```python
from langchain.agents import create_agent
from langchain_core.tools import tool
from datetime import datetime

@tool
def get_weather(city: str) -> str:
    """获取天气"""
    return f"{city}晴天，25°C"

@tool
def get_time() -> str:
    """获取当前时间"""
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    return str(eval(expression))

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[get_weather, get_time, calculate],
    system_prompt="你是一个多功能助手"
)

# 测试不同工具
queries = [
    "北京天气怎么样？",
    "现在几点了？",
    "123 乘以 456 等于多少？",
]

for query in queries:
    result = agent.invoke({"messages": [{"role": "user", "content": query}]})
    print(f"Q: {query}")
    print(f"A: {result['messages'][-1].content}\n")
```

## 示例 5：用本地 Ollama 模型

```python
from langchain.agents import create_agent

agent = create_agent(
    model="ollama:llama3",  # 本地模型
    tools=[],
    system_prompt="你是一个友好的助手"
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]}
)
print(result["messages"][-1].content)
```

---

## 小结

创建 Agent 的三要素：
1. **model**：指定 LLM（Provider 字符串格式）
2. **tools**：工具列表
3. **system_prompt**：系统提示词

就这么简单。`create_agent()` 把复杂的底层逻辑都封装好了。
