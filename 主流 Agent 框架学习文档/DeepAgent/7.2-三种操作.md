# 7.2 approve / edit / reject 三种操作

人工审批时有三种选择。

---

## approve（批准）

直接通过，继续执行。

```python
from langgraph.types import Command
agent.invoke(Command(resume={"action": "approve"}), config={"thread_id": "1"})
```

## edit（编辑）

修改参数后继续执行。

```python
agent.invoke(Command(resume={
    "action": "edit",
    "modified_args": {"path": "/safe/path.txt", "content": "..."}
}), config={"thread_id": "1"})
```

## reject（拒绝）

取消操作。

```python
agent.invoke(Command(resume={"action": "reject"}), config={"thread_id": "1"})
```
