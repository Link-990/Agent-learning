# 4.6 自定义 Backend

如果内置 Backend 不满足需求，可以实现自定义 Backend。

---

## 实现接口

```python
from deepagents.backends import Backend

class MyBackend(Backend):
    def read_file(self, path: str) -> str:
        # 从你的存储系统读取
        ...
    
    def write_file(self, path: str, content: str) -> None:
        # 写入你的存储系统
        ...
    
    def list_dir(self, path: str) -> list[str]:
        ...
    
    def delete(self, path: str) -> None:
        ...
    
    def glob(self, pattern: str) -> list[str]:
        ...
    
    def grep(self, pattern: str, path: str) -> list[dict]:
        ...
```

---

## 使用

```python
agent = create_deep_agent(
    model="gpt-5.5",
    backend=MyBackend(),
)
```

---

## 小结

Backend 系统让你灵活选择文件存储：
- `StateBackend`：内存（开发）
- `FilesystemBackend`：磁盘（单机）
- `StoreBackend`：Store（多用户）
- `CompositeBackend`：混合路由
- 自定义 Backend：任意存储
