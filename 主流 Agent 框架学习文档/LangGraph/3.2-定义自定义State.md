# 3.2 用 TypedDict + Annotated 定义自定义 State

在 LangGraph 里，State 的定义方式直接影响了代码的可读性和可维护性。这一节，我们学习如何用 Python 的 `TypedDict` 和 `Annotated` 定义出结构清晰、类型安全的 State。

---

## 为什么要用 TypedDict？

### 方式 1：直接用 dict（不推荐）

```python
state = {"input": "", "output": "", "count": 0}
```

问题：
- 没有类型检查，容易拼错字段名
- IDE 不能自动补全
- 别人看代码时，不知道 State 里有哪些字段

### 方式 2：用 TypedDict（推荐）

```python
from typing import TypedDict

class MyState(TypedDict):
    input: str
    output: str
    count: int
```

好处：
- ✅ 类型明确，一眼看懂
- ✅ IDE 自动补全和类型检查
- ✅ 代码即文档

---

## TypedDict 的基本用法

### 定义一个 State

```python
from typing import TypedDict

class AgentState(TypedDict):
    user_input: str
    llm_response: str
    tool_result: str
    step_count: int
```

### 使用这个 State

```python
from langgraph.graph import StateGraph

graph = StateGraph(AgentState)
```

### 在节点里使用

```python
def my_node(state: AgentState) -> dict:
    # IDE 会自动提示 state 里有哪些字段
    user_input = state["user_input"]
    return {"llm_response": "处理结果"}
```

---

## 可选字段：用 `total=False`

有时候，State 里有些字段是可选的（一开始可能没有值）。

### 方式 1：全部可选

```python
class MyState(TypedDict, total=False):
    input: str
    output: str
    error: str  # 可选字段
```

### 方式 2：部分可选

```python
from typing import TypedDict, NotRequired

class MyState(TypedDict):
    input: str          # 必需字段
    output: str         # 必需字段
    error: NotRequired[str]  # 可选字段
```

（`NotRequired` 是 Python 3.11+ 的特性，如果用旧版本，用 `total=False`）

---

## Annotated：自定义字段的更新逻辑

默认情况下，LangGraph 的 State 更新是"合并"——节点返回的字段会覆盖原字段。

但有时候，你想要不同的更新逻辑：
- **追加**到列表（像 messages）
- **取最大值**
- **累加**

这时候就用 `Annotated` + `reducer` 函数。

### 基本语法

```python
from typing import Annotated

class MyState(TypedDict):
    field_name: Annotated[类型, reducer函数]
```

### reducer 函数

reducer 函数接收两个参数：
- `existing`：State 里已有的值
- `new`：节点返回的新值

返回合并后的值。

---

## 示例 1：追加到列表

```python
from typing import Annotated
from operator import add

class MyState(TypedDict):
    items: Annotated[list, add]
```

`add` 是 Python 内置的加法操作，对列表来说就是"拼接"。

```python
# 当前 State
state = {"items": [1, 2, 3]}

# 节点返回
return {"items": [4, 5]}

# 合并后
state = {"items": [1, 2, 3, 4, 5]}
```

### 对于 messages，LangGraph 提供了专用的 reducer

```python
from typing import Annotated
from langgraph.graph import add_messages

class MyState(TypedDict):
    messages: Annotated[list, add_messages]
```

`add_messages` 比 `add` 更智能：
- 会自动追加消息
- 如果消息有 `id`，相同 `id` 的消息会被更新而不是重复追加

---

## 示例 2：取最大值

```python
from typing import Annotated

def take_max(existing, new):
    return max(existing, new)

class MyState(TypedDict):
    max_score: Annotated[int, take_max]
```

```python
# 当前 State
state = {"max_score": 80}

# 节点返回
return {"max_score": 95}

# 合并后
state = {"max_score": 95}  # 取了更大的值

# 如果节点返回 60
return {"max_score": 60}

# 合并后
state = {"max_score": 80}  # 还是保持原来的值
```

---

## 示例 3：累加

```python
from typing import Annotated

def accumulate(existing, new):
    return existing + new

class MyState(TypedDict):
    total_cost: Annotated[float, accumulate]
```

```python
# 当前 State
state = {"total_cost": 10.0}

# 节点 1 返回
return {"total_cost": 5.0}

# 合并后
state = {"total_cost": 15.0}

# 节点 2 返回
return {"total_cost": 3.0}

# 合并后
state = {"total_cost": 18.0}
```

---

## 示例 4：合并字典

```python
from typing import Annotated

def merge_dicts(existing, new):
    return {**existing, **new}

class MyState(TypedDict):
    metadata: Annotated[dict, merge_dicts]
```

```python
# 当前 State
state = {"metadata": {"user": "Alice", "role": "admin"}}

# 节点返回
return {"metadata": {"timestamp": "2023-10-01"}}

# 合并后
state = {"metadata": {"user": "Alice", "role": "admin", "timestamp": "2023-10-01"}}
```

## 完整示例：一个复杂的 State

```python
from typing import TypedDict, Annotated
from langgraph.graph import add_messages

def take_max(existing, new):
    return max(existing, new)

def accumulate(existing, new):
    return existing + new

class AgentState(TypedDict):
    # 消息列表：追加
    messages: Annotated[list, add_messages]
    
    # 步骤计数：累加
    step_count: Annotated[int, accumulate]
    
    # 最大置信度：取最大值
    max_confidence: Annotated[float, take_max]
    
    # 普通字段：替换
    current_tool: str
    error: str
```

使用：

```python
from langgraph.graph import StateGraph, START, END

graph = StateGraph(AgentState)

def node_a(state):
    return {
        "messages": [{"role": "ai", "content": "Hello"}],
        "step_count": 1,
        "max_confidence": 0.8,
        "current_tool": "search"
    }

def node_b(state):
    return {
        "messages": [{"role": "ai", "content": "World"}],
        "step_count": 1,  # 会累加，变成 2
        "max_confidence": 0.6,  # 会取最大值，保持 0.8
        "current_tool": "calculator"  # 会替换
    }

graph.add_node("a", node_a)
graph.add_node("b", node_b)
graph.add_edge(START, "a")
graph.add_edge("a", "b")
graph.add_edge("b", END)

app = graph.compile()
result = app.invoke({
    "messages": [],
    "step_count": 0,
    "max_confidence": 0.0,
    "current_tool": "",
    "error": ""
})

print(result)
# {
#     "messages": [
#         {"role": "ai", "content": "Hello"},
#         {"role": "ai", "content": "World"}
#     ],
#     "step_count": 2,
#     "max_confidence": 0.8,
#     "current_tool": "calculator",
#     "error": ""
# }
```

## 常见 reducer 函数总结

| 需求 | reducer 函数 |
|------|-------------|
| 追加到列表 | `from operator import add` |
| 追加消息（智能去重） | `from langgraph.graph import add_messages` |
| 取最大值 | `lambda existing, new: max(existing, new)` |
| 取最小值 | `lambda existing, new: min(existing, new)` |
| 累加 | `lambda existing, new: existing + new` |
| 合并字典 | `lambda existing, new: {**existing, **new}` |
| 合并集合 | `lambda existing, new: existing | new` |
| 替换（默认行为） | 不需要 Annotated |

---

## 小结

- **TypedDict**：定义 State 的推荐方式，类型清晰、IDE 支持好
- **Annotated + reducer**：自定义字段的更新逻辑
  - 追加列表：`Annotated[list, add]`
  - 追加消息：`Annotated[list, add_messages]`
  - 取最大值：`Annotated[int, take_max]`
  - 累加：`Annotated[int, accumulate]`
- **默认行为**：不加 Annotated，就是直接替换

设计 State 时，思考清楚：
1. 这个字段是什么类型？
2. 更新时是替换、追加、还是其他逻辑？
3. 是必需字段还是可选字段？
