# 5.3 ToolRuntime 与上下文注入

有时候工具需要访问"运行时上下文"——比如当前用户 ID、会话 ID 等。`ToolRuntime` 让你把这些信息注入到工具中。

---

## 基本用法

```python
from dataclasses import dataclass
from langchain.tools import tool, ToolRuntime

@dataclass
class UserContext:
    user_id: str
    session_id: str

@tool
def get_account_info(runtime: ToolRuntime[UserContext]) -> str:
    """获取用户账户信息"""
    user_id = runtime.context.user_id
    return f"用户 {user_id} 的余额：1000 元"

# 创建 Agent 时传入 context_schema
agent = create_agent(
    model="gpt-4o-mini",
    tools=[get_account_info],
    context_schema=UserContext,
    system_prompt="你是财务助手"
)

# 调用时传入 context
result = agent.invoke(
    {"messages": [{"role": "user", "content": "我的余额是多少？"}]},
    context=UserContext(user_id="user_123", session_id="session_456")
)
```

---

## 关键点

1. 工具函数接收 `runtime: ToolRuntime[ContextType]` 参数
2. 通过 `runtime.context` 访问上下文
3. `create_agent()` 需要指定 `context_schema`
4. 调用时传入 `context=...`

---

## 小结

`ToolRuntime` 让你把运行时信息（用户 ID、会话 ID 等）注入到工具中，而不需要 LLM 传递这些参数。
