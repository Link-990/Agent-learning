# 6.3 task() 命令：委派任务

主 Agent 通过 `task()` 工具把任务委派给子 Agent。

---

## 使用方式

Agent 自动调用 `task()` 工具：

```
task(subagent_type="researcher", task="搜索 AI 最新进展")
```

等价于：
- 创建 researcher 子 Agent
- 把任务描述传给它
- 等待它完成
- 返回结果

---

## 完整示例

```python
agent = create_deep_agent(
    model="openai:gpt-5.5",
    system_prompt="""你是项目协调者。
    
收到任务后：
1. 用 write_todos 制定计划
2. 把搜索任务委派给 researcher
3. 把写作任务委派给 writer
4. 汇总结果
""",
    subagents=[
        {
            "name": "researcher",
            "description": "搜索资料",
            "system_prompt": "你是研究员，搜索资料后返回摘要。",
        },
        {
            "name": "writer",
            "description": "写文章",
            "system_prompt": "你是写手，根据资料撰写文章。",
        },
    ],
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "写一篇 AI 教育应用的报告"}]}
)
```

---

## 流式查看子 Agent

```python
stream = agent.stream_events(
    {"messages": [{"role": "user", "content": "写一篇报告"}]},
    version="v3",
)

for name, item in stream.interleave("messages", "subagents"):
    if name == "messages":
        print(f"[主 Agent] {item.text}")
    else:
        print(f"[{item.name}] 开始")
        for msg in item.messages:
            print(f"  {msg.text}")
        print(f"[{item.name}] 完成")
```
