# 6.1 什么是 LCEL？

LCEL = **LangChain Expression Language**——一种用管道符 `|` 连接组件的语法。

---

## 核心思想

```python
chain = component_a | component_b | component_c
result = chain.invoke(input)
```

数据从左边流入，经过每个组件处理，从右边流出。

---

## 为什么需要 LCEL？

### 没有 LCEL

```python
prompt = create_prompt(input)
llm_response = llm.invoke(prompt)
result = parser.parse(llm_response)
```

### 有 LCEL

```python
chain = prompt | llm | parser
result = chain.invoke(input)
```

更简洁，更可组合。

---

## LCEL 在 v1.0+ 中的地位

v1.0 后，LCEL 不再是核心叙事——`create_agent()` 成了主流。但 LCEL 仍然有用：
- 构建简单的处理链（翻译、摘要等）
- 组合自定义组件
- 与 LangGraph 集成
