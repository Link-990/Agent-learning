# 7.4 调试与追踪

调试 Agent 需要看到每一步的执行细节。

---

## 方法 1：stream() 打印

```python
for event in agent.stream({"messages": [...]}):
    for node_name, output in event.items():
        print(f"=== {node_name} ===")
        if "messages" in output:
            for msg in output["messages"]:
                print(f"  {msg.type}: {msg.content[:100]}")
```

## 方法 2：LangSmith

自动记录所有执行细节，可以在 Web UI 中查看。

## 方法 3：verbose 模式

```python
import langchain
langchain.debug = True
```

---

## 小结

调试方式：
- `stream()`：代码中打印
- LangSmith：Web UI 查看
- `langchain.debug`：全局 verbose
