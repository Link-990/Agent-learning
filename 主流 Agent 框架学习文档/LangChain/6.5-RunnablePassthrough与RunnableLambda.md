# 6.5 RunnablePassthrough 与 RunnableLambda

这两个组件让你在链中做更灵活的数据处理。

---

## RunnablePassthrough：原样传递

```python
from langchain_core.runnables import RunnablePassthrough

# 原样传递输入，不做任何处理
chain = RunnablePassthrough() | model | parser
```

常用于多分支场景：

```python
from langchain_core.runnables import RunnablePassthrough, RunnableParallel

chain = RunnableParallel(
    translation=RunnablePassthrough() | translator_chain,
    summary=RunnablePassthrough() | summary_chain,
)
```

---

## RunnableLambda：自定义函数

```python
from langchain_core.runnables import RunnableLambda

def preprocess(input):
    return {"text": input["text"].lower()}

chain = RunnableLambda(preprocess) | prompt | model | parser
```

---

## RunnableParallel：并行执行

```python
from langchain_core.runnables import RunnableParallel

chain = RunnableParallel(
    translation=translation_chain,
    summary=summary_chain,
)

result = chain.invoke({"text": "Hello"})
# result = {"translation": "...", "summary": "..."}
```

---

## 小结

| 组件 | 作用 |
|------|------|
| `RunnablePassthrough` | 原样传递 |
| `RunnableLambda` | 自定义函数 |
| `RunnableParallel` | 并行执行多个链 |
