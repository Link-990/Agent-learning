# 10.4 工具系统

Kami Code 有几十个工具，通过 ToolRegistry 管理。

---

## 两层工具系统

### 内部层：ToolSpec

```python
class ToolSpec:
    name: str
    description: str
    input_schema: type  # Pydantic 模型
    handler: Callable
    source: str
    is_read_only: bool
    defer_loading: bool
    # ...
```

### 适配层：StructuredTool

```python
# 转换为 LangChain StructuredTool
StructuredTool.from_function(
    func=spec.handler,
    name=spec.name,
    description=spec.description,
    args_schema=spec.input_schema,
    metadata={
        "public_name": spec.name,
        "is_read_only": spec.is_read_only,
        "defer_loading": spec.defer_loading,
    }
)
```

---

## 设计亮点

- **内部丰富**：ToolSpec 包含 source、risk_level、permission_scope 等
- **外部简洁**：StructuredTool 只暴露 LLM 需要的信息
- **metadata 桥接**：通过 metadata 传递内部信息给 Middleware
