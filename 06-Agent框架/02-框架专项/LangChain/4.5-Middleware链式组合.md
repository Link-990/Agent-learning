# 4.5 Middleware 链式组合

多个 Middleware 可以像洋葱一样一层层叠加——每个 Middleware 处理完，再交给下一个。

---

## 执行顺序

```python
agent = create_agent(
    model="gpt-4o-mini",
    tools=[],
    middleware=[
        LoggingMiddleware(),      # 第 1 层
        SafetyMiddleware(),       # 第 2 层
        CostTrackerMiddleware(),  # 第 3 层
    ]
)
```

执行顺序（类似洋葱模型）：

```
请求进入
    ↓
[LoggingMiddleware 前处理] → 打印 "LLM 调用开始"
    ↓
[SafetyMiddleware 前处理] → 检查敏感词
    ↓
[CostTrackerMiddleware 前处理]
    ↓
[LLM 调用]
    ↓
[CostTrackerMiddleware 后处理] → 记录 Token
    ↓
[SafetyMiddleware 后处理]
    ↓
[LoggingMiddleware 后处理] → 打印 "LLM 调用结束"
    ↓
返回响应
```

---

## 链式组合的示例

```python
agent = create_agent(
    model="gpt-4o-mini",
    tools=[...],
    middleware=[
        LoggingMiddleware(),           # 日志
        SummarizationMiddleware(),     # 长对话自动摘要
        CostTrackerMiddleware(),       # 成本追踪
    ]
)
```

这三个 Middleware 协同工作：
1. `LoggingMiddleware` 记录每次调用
2. `SummarizationMiddleware` 压缩长对话
3. `CostTrackerMiddleware` 追踪成本

---

## 小结

- Middleware 按列表顺序依次执行
- 每个 Middleware 可以修改 request 和 response
- 多个 Middleware 可以链式组合
- 执行顺序是"洋葱模型"——先进入的后退出
