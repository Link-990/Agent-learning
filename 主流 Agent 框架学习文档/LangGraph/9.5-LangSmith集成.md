# 9.5 LangSmith 集成与可观测性

Agent 系统越来越复杂，调试和监控变得越来越重要。**LangSmith** 是 LangChain 官方的可观测性平台，让你能追踪 Agent 的每一步执行。

---

## LangSmith 提供什么？

- **Tracing（追踪）**：记录每个节点、每次 LLM 调用的输入输出
- **Monitoring（监控）**：实时监控 Agent 的性能和错误
- **Evaluation（评估）**：自动化测试和评估 Agent 质量
- **Playground（实验）**：在线调试和测试 Agent

---

## 配置 LangSmith

### 1. 获取 API Key

去 [smith.langchain.com](https://smith.langchain.com/) 注册，创建 API Key。

### 2. 配置环境变量

```bash
# .env 文件
LANGSMITH_API_KEY=你的API_KEY
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=my-agent-project
```

### 3. 自动追踪

配置好后，LangGraph 的所有执行会**自动**发送到 LangSmith，不需要改代码。

---

## 追踪内容

每次 Agent 执行，LangSmith 会记录：

```
执行 #123
├── 节点：search
│   ├── 输入：{topic: "AI"}
│   ├── LLM 调用：gpt-4o-mini, tokens: 150/80
│   └── 输出：{results: [...]}
├── 节点：analyze
│   ├── 输入：{results: [...]}
│   ├── LLM 调用：gpt-4o-mini, tokens: 200/120
│   └── 输出：{analysis: "..."}
└── 节点：generate
    ├── 输入：{analysis: "..."}
    ├── LLM 调用：gpt-4o, tokens: 100/500
    └── 输出：{report: "..."}

总耗时：12.3s
总 tokens：1150
```

---

## 在 LangSmith 中查看

登录后，在 LangSmith Dashboard 中可以看到：

1. **执行列表**：每次 Agent 调用的概览
2. **追踪详情**：每个节点的输入/输出
3. **LLM 调用**：Prompt、Completion、Token 使用量
4. **错误日志**：哪个节点出错，错误信息是什么

---

## 与 Kami Code 的关联

Kami Code 项目在 `deepagents_adapter.py` 中处理流式事件，这些事件都可以发送到 LangSmith 进行追踪。在实际项目中，LangSmith 是调试复杂 Agent 系统的必备工具。
