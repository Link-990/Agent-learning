## 8.1 自修改 Agent

Pi 可以在运行时修改自身的 Extension 代码：

```
> 添加一个 /hello 命令
Pi: 好的，我来修改 hello-extension.ts...
    [Pi 编辑了自己的文件]
    /reload 完成！
```

这是 Pi 最独特的特性——其他 Agent 做不到。

## 8.2 Gondolin 沙箱

Gondolin 扩展把工具执行路由到本地 Linux micro-VM，实现容器化隔离。

## 8.3 Telemetry

`pi-telemetry` 包提供供应商中立的可观测性合约——标准化追踪数据格式。

## 8.4 TUI 差分渲染

`pi-tui` 包实现了终端 UI 的差分渲染——只更新变化的部分，高效流畅。

## 8.5 包管理

Extension 可以打包成 Pi packages，通过 npm 或 git 分发：

```bash
npm install pi-subagents
```
