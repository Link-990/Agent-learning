# 4.2 StateBackend：内存虚拟文件系统

StateBackend 是最简单的 Backend——文件存在 Agent 的 State 中（内存里）。

---

## 用法

```python
from deepagents import create_deep_agent
from deepagents.backends import StateBackend

agent = create_deep_agent(
    model="gpt-5.5",
    backend=StateBackend(),  # 默认就是 StateBackend
)
```

---

## 特点

- ✅ 零配置
- ✅ 快速
- ❌ 不持久化（程序退出后丢失）
- ❌ 内存占用

---

## 种子数据

可以在启动时注入文件：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    backend=StateBackend(),
    files={
        "/README.md": "# 项目说明",
        "/config.json": '{"debug": true}',
    },
)
```
