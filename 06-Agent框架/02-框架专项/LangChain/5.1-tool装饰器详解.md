# 5.1 @tool 装饰器详解

`@tool` 是定义工具最常用的方式。这一节我们看看它的所有选项。

---

## 基本用法

```python
from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取城市天气"""
    return f"{city}晴天，25°C"
```

---

## 自定义名称和描述

```python
@tool(name="天气查询", description="查询指定城市的实时天气信息")
def get_weather(city: str) -> str:
    return f"{city}晴天，25°C"
```

---

## 复杂参数

```python
from pydantic import BaseModel, Field

class WeatherInput(BaseModel):
    city: str = Field(description="城市名称")
    unit: str = Field(default="celsius", description="温度单位：celsius 或 fahrenheit")

@tool
def get_weather(input: WeatherInput) -> str:
    """获取天气"""
    return f"{input.city}: 25°{input.unit[0].upper()}"
```

---

## 异步工具

```python
@tool
async def search_async(query: str) -> str:
    """异步搜索"""
    import aiohttp
    async with aiohttp.ClientSession() as session:
        async with session.get(f"https://api.example.com/search?q={query}") as resp:
            return await resp.text()
```

---

## 小结

`@tool` 的选项：
- `name`：自定义工具名
- `description`：自定义描述
- 参数用 Pydantic BaseModel 定义复杂 Schema
- 支持异步工具
