# 第四章：上下文系统

Pi 的上下文系统让你精确控制 Agent 看到的指令和信息。

---

## 本章学习路线

- **4.1** AGENTS.md：项目指令注入
- **4.2** 上下文文件优先级
- **4.3** 虚拟文件注入
- **4.4** 系统提示覆盖
- **4.5** Skills

---

## 4.1 AGENTS.md

在项目根目录放 `AGENTS.md`，Pi 自动加载作为上下文。

```markdown
# 项目指南
- 使用 TypeScript
- 遵循 ESLint 规范
- 测试覆盖率 > 80%
```

## 4.2 优先级

```
AGENTS.override.md > AGENTS.md > AGENTS.MD > CLAUDE.md > CLAUDE.MD
```

## 4.3 虚拟文件注入

```typescript
const { session } = await createAgentSession({
  agentsFilesOverride: [
    { path: "AGENTS.md", content: "虚拟指令内容" }
  ],
});
```

## 4.4 系统提示覆盖

```typescript
const loader = new DefaultResourceLoader({
  systemPromptOverride: () => "你是一个简洁的助手。",
});
```

## 4.5 Skills

Skills 是按需加载的行为模块（不同于始终加载的 Memory）。
