# 3.6 多 Provider 模型配置

`create_agent()` 的 `model` 参数支持多种格式。

---

## 格式 1：Provider 字符串（推荐）

```python
# 格式："provider:model_name"
agent = create_agent(model="openai:gpt-5.5", tools=[])
agent = create_agent(model="anthropic:claude-sonnet-4-6", tools=[])
agent = create_agent(model="google_genai:gemini-3.5-flash", tools=[])
agent = create_agent(model="ollama:llama3", tools=[])
```

---

## 格式 2：Chat Model 对象

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)
agent = create_agent(model=llm, tools=[])
```

适合需要精细配置 LLM 参数（如 temperature、max_tokens）的场景。

---

## 格式 3：init_chat_model()

```python
from langchain.chat_models import init_chat_model

llm = init_chat_model("openai:gpt-5.5", temperature=0.7)
agent = create_agent(model=llm, tools=[])
```

`init_chat_model()` 是 LangChain 的统一模型初始化接口。

---

## Provider 字符串速查表

| Provider | 格式 | 示例 |
|----------|------|------|
| OpenAI | `openai:model` | `openai:gpt-5.5` |
| Anthropic | `anthropic:model` | `anthropic:claude-sonnet-4-6` |
| Google | `google_genai:model` | `google_genai:gemini-3.5-flash` |
| Ollama | `ollama:model` | `ollama:llama3` |
| OpenRouter | `openrouter:model` | `openrouter:anthropic/claude-sonnet-4-6` |
| Fireworks | `fireworks:model` | `fireworks:accounts/fireworks/models/qwen3p5-397b-a17b` |
| Bedrock | `bedrock_converse:model` | `bedrock_converse:us.anthropic.claude-sonnet-4-6` |
| Azure | 通过 ChatOpenAI(base_url=...) | - |

---

## 小结

- Provider 字符串是最简洁的方式
- Chat Model 对象适合精细配置
- `init_chat_model()` 是统一接口
