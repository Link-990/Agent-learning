# 10.6 最佳实践总结

从 Kami Code 学到的 Deep Agents 最佳实践。

---

## 1. 适配器模式隔离底层

Kami Code 通过 `deepagents_adapter.py` 封装了 Deep Agents 的接口。

**最佳实践**：
- 用适配器隔离底层框架
- 对外暴露统一接口
- 支持降级策略

---

## 2. 流式消息处理

通过 `langgraph_node` 元数据区分消息来源。

**最佳实践**：
- 用 `stream_mode="messages"` 获取 Token 级流式
- 用 `langgraph_node` 过滤消息
- 准备好降级到 state stream

---

## 3. 两层工具系统

内部 ToolSpec + 外部 StructuredTool。

**最佳实践**：
- 内部定义可以很丰富
- 外部暴露简洁接口
- 用 metadata 桥接

---

## 4. Middleware 做工具过滤

`DeferredToolMiddleware` 按需加载工具。

**最佳实践**：
- 工具多时用 Middleware 过滤
- 标记工具的加载策略
- 只暴露当前需要的工具

---

## 5. Token 追踪

从 `usage_metadata` 提取 Token 使用量。

**最佳实践**：
- 在每个 chunk 中追踪 Token
- 用 Accumulator 累计
- 支持多 Provider 兼容
