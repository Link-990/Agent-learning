# 2.3 defineTool：定义工具

Pi 用 `defineTool` 定义自定义工具——用 TypeBox Schema 定义参数。

---

## 基本用法

```typescript
import { Type } from "typebox";
import { defineTool } from "@earendil-works/pi-coding-agent";

const statusTool = defineTool({
  name: "status",
  label: "Status",
  description: "Get system status",
  parameters: Type.Object({}),
  execute: async () => ({
    content: [{ type: "text", text: `Uptime: ${process.uptime()}s` }],
    details: {},
  }),
});
```

---

## 带参数的工具

```typescript
const searchTool = defineTool({
  name: "search",
  label: "Search",
  description: "Search for information",
  parameters: Type.Object({
    query: Type.String({ description: "Search query" }),
    maxResults: Type.Optional(Type.Number({ description: "Max results" })),
  }),
  execute: async (_toolCallId, params) => {
    const results = await doSearch(params.query, params.maxResults);
    return {
      content: [{ type: "text", text: results }],
      details: {},
    };
  },
});
```

---

## 注册到 Session

```typescript
const { session } = await createAgentSession({
  tools: ["read", "bash"],       // 内置工具
  customTools: [statusTool, searchTool],  // 自定义工具
});
```

---

## 工具的 terminate 选项

工具可以设置 `terminate: true`，跳过后续 LLM 调用：

```typescript
const exitTool = defineTool({
  name: "exit",
  label: "Exit",
  description: "Exit the session",
  parameters: Type.Object({}),
  execute: async () => ({
    content: [{ type: "text", text: "Goodbye!" }],
    details: {},
    terminate: true,  // 终止后续 LLM 调用
  }),
});
```

---

## 工具执行模式

```typescript
// 串行：工具一个一个执行
executionMode: "sequential"

// 并行：多个工具同时执行（默认）
executionMode: "parallel"
```
