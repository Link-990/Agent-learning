# 8.7 实战：构建知识库问答系统

把 RAG 的所有组件串起来，构建一个完整的知识库问答系统。

---

## 完整代码

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain.text_splitter import RecursiveCharacterTextSplitter

load_dotenv()

# ========== 1. 准备文档 ==========
documents = [
    "LangChain 是一个用于构建 AI Agent 的框架。它提供了 LLM 调用、工具定义、Agent 创建等功能。",
    "LangGraph 是 LangChain 生态中的工作流编排框架。它用图结构来编排 Agent 的执行流程。",
    "Deep Agents 是基于 LangChain 和 LangGraph 的上层框架。它内置了规划、子 Agent、文件系统等功能。",
    "Kami Code 是一个基于 deepagents 构建的编程助手。它使用 LangGraph 的流式输出实现实时交互。",
    "RAG（检索增强生成）是一种让 LLM 基于外部知识回答问题的技术。核心是检索 + 生成。",
]

# ========== 2. 切分文档 ==========
splitter = RecursiveCharacterTextSplitter(chunk_size=200, chunk_overlap=20)
# 简化：直接用整段作为 chunk
from langchain_core.documents import Document
chunks = [Document(page_content=doc) for doc in documents]

# ========== 3. 存入向量数据库 ==========
embeddings = OpenAIEmbeddings()
vectorstore = InMemoryVectorStore(embeddings)
vectorstore.add_documents(chunks)

# ========== 4. 创建 Retriever ==========
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

# ========== 5. 构建 RAG 链 ==========
prompt = ChatPromptTemplate.from_template("""
根据以下参考资料回答问题。如果资料中没有相关信息，请说明。

参考资料：
{context}

问题：{question}
""")

model = ChatOpenAI(model="gpt-4o-mini")

rag_chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | model
    | StrOutputParser()
)

# ========== 6. 测试 ==========
if __name__ == "__main__":
    questions = [
        "LangGraph 是什么？",
        "Kami Code 使用了什么技术？",
        "什么是 RAG？",
    ]
    
    for q in questions:
        print(f"\nQ: {q}")
        answer = rag_chain.invoke(q)
        print(f"A: {answer}")
```

---

## 小结

RAG 的完整流程：
1. 加载文档
2. 切分文档
3. 向量化 + 存入向量数据库
4. 检索相关文档
5. 构造 Prompt（文档 + 问题）
6. LLM 生成回答
