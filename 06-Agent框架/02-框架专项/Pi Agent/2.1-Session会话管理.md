# 2.1 Session：会话管理

Session 是 Pi 中管理对话的核心概念。每个 Session 包含完整的对话历史和状态。

---

## Session 的四种创建方式

```typescript
import { SessionManager } from "@earendil-works/pi-coding-agent";

// 1. 内存会话（不持久化）
const { session } = await createAgentSession({
  sessionManager: SessionManager.inMemory(),
});

// 2. 新的持久化会话
const { session } = await createAgentSession({
  sessionManager: SessionManager.create(process.cwd()),
});

// 3. 继续最近的会话
const { session } = await createAgentSession({
  sessionManager: SessionManager.continueRecent(process.cwd()),
});

// 4. 打开指定的会话文件
const { session } = await createAgentSession({
  sessionManager: SessionManager.open("/path/to/session.jsonl"),
});
```

---

## Session 的核心方法

```typescript
// 发送消息
await session.prompt("帮我写代码");

// 订阅事件
session.subscribe((event) => {
  if (event.type === "message_update") {
    console.log(event.assistantMessageEvent.delta);
  }
});

// 列出所有会话
const sessions = await SessionManager.list(process.cwd());
```

---

## 树状历史

Pi 的 Session 不是线性列表，而是**树结构**——支持分支和回溯。

```
entry_1 (用户: 你好)
    ├── entry_2 (AI: 你好！)
    │   └── entry_3 (用户: 写代码)
    │       └── entry_4 (AI: 好的...)
    └── entry_5 (AI: 你好，有什么可以帮你的？)  ← 分支
```

这意味着你可以从一个点"分支"出不同的对话路径。
