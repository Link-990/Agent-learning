# 5.6 实战：构建多功能工具箱

这一节我们构建一个完整的工具箱，包含各种类型的工具。

---

## 完整代码

```python
from dotenv import load_dotenv
from langchain.agents import create_agent
from langchain_core.tools import tool
from pydantic import BaseModel, Field
from datetime import datetime
import json

load_dotenv()

# ========== 1. 简单工具 ==========
@tool
def get_time() -> str:
    """获取当前时间"""
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

# ========== 2. 带参数的工具 ==========
@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    try:
        return str(eval(expression))
    except Exception as e:
        return f"计算错误：{e}"

# ========== 3. 带 Pydantic Schema 的工具 ==========
class WeatherInput(BaseModel):
    city: str = Field(description="城市名称")
    unit: str = Field(default="celsius", description="温度单位")

@tool
def get_weather(input: WeatherInput) -> str:
    """获取城市天气"""
    return f"{input.city}: 晴天，25°{input.unit[0].upper()}"

# ========== 4. 带 metadata 的工具（StructuredTool）==========
from langchain_core.tools import StructuredTool

def search_impl(query: str) -> str:
    return f"搜索结果：{query}"

search_tool = StructuredTool.from_function(
    func=search_impl,
    name="search",
    description="搜索互联网",
    metadata={"is_read_only": True, "source": "web"}
)

# ========== 5. 组合成 Agent ==========
agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[get_time, calculate, get_weather, search_tool],
    system_prompt="你是一个多功能助手，可以使用各种工具帮助用户。"
)

# ========== 测试 ==========
if __name__ == "__main__":
    queries = [
        "现在几点了？",
        "123 * 456 + 789 = ?",
        "上海天气怎么样？",
        "搜索 Python 教程",
    ]
    
    for query in queries:
        print(f"\nQ: {query}")
        result = agent.invoke({"messages": [{"role": "user", "content": query}]})
        print(f"A: {result['messages'][-1].content}")
```

---

## 小结

一个完整的工具箱应该包含：
- 简单工具（无参数）
- 带参数工具（类型标注）
- 复杂参数工具（Pydantic Schema）
- 带 metadata 的工具（StructuredTool）
- 工具注册表管理
