# 6.5 并行委派

主 Agent 可以同时委派多个任务给不同的子 Agent。

---

## 串行 vs 并行

### 串行

```
主 Agent → task("researcher", "搜索 A")
          → task("researcher", "搜索 B")
          → task("writer", "写报告")
```

### 并行

```
主 Agent → task("researcher", "搜索 A")  ┐
          → task("researcher", "搜索 B")  ├─ 同时执行
          → task("writer", "写报告")     ┘
```

---

## 流式查看并行

```python
for name, item in stream.interleave("messages", "subagents"):
    if name == "subagents":
        print(f"[{item.name}] 开始")
        # 多个子 Agent 的输出交错显示
```
