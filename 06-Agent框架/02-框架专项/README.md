# 框架专项

这里保留四套框架的完整学习资料。每个框架内部有自己的编号和顺序，跨框架阅读时不要把编号当作全仓库顺序。

## 推荐顺序

1. [LangGraph](LangGraph/0.0-学习大纲.md)：先学 State、Node、Edge、Checkpointer、Interrupt 和多 Agent。
2. [LangChain](LangChain/0.0-学习大纲.md)：再学 Model、Message、Tool、Middleware、LCEL 和 RAG。
3. [Deep Agents](DeepAgent/0.0-学习大纲.md)：学习 Backend、上下文、子 Agent、Skills、沙箱和生产部署。
4. [Pi Agent](Pi%20Agent/0.0-学习大纲.md)：学习 TypeScript Session、Model Runtime、Extension 和 Hooks。

框架专项的实战资料会引用同一个 Runtime 词汇表，便于比较责任边界。
