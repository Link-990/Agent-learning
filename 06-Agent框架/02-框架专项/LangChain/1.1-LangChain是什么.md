# 1.1 LangChain 是什么？

## 一句话理解

> **LangChain 是一个"最小化、可配置"的 Agent 开发框架——它提供 `create_agent()` 这个统一入口，帮你把 LLM、工具、中间件组装成一个能自主行动的 Agent。**

---

## 拆开来理解

### "最小化"

LangChain v1.0+ 的设计理念是**做减法**——它不再试图包揽一切，而是只提供最核心的能力：

- 调用 LLM（Chat Model）
- 定义工具（Tool）
- 组装 Agent（create_agent）
- 定制行为（Middleware）

其他复杂的事情（比如工作流编排、图结构、持久化），交给 LangGraph 去做。

### "可配置"

LangChain 的 Agent 可以通过 **Middleware（中间件）** 来定制行为——你可以拦截 Agent 的每一步操作，添加日志、审批、摘要等功能。

### "统一入口"

`create_agent()` 是 LangChain 的核心 API——一个函数搞定 Agent 的创建。不需要理解复杂的类继承、链式调用，一行代码就能跑起来。

---

## 一个最简单的例子

```python
from langchain.agents import create_agent

def get_weather(city: str) -> str:
    """获取天气信息"""
    return f"{city}今天晴天，25°C"

agent = create_agent(
    model="openai:gpt-5.5",
    tools=[get_weather],
    system_prompt="你是一个天气助手"
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "北京今天天气怎么样？"}]}
)
print(result["messages"][-1].content)
# 输出：北京今天晴天，25°C
```

就这么简单！三步：
1. 定义工具（`get_weather`）
2. 创建 Agent（`create_agent`）
3. 调用 Agent（`invoke`）

---

## LangChain 做了什么，没做什么？

### 做了什么 ✅

- **调用 LLM**：支持 OpenAI、Anthropic、Google、Ollama 等十几个 Provider
- **定义工具**：用 `@tool` 装饰器，一行代码把函数变成工具
- **Agent 循环**：自动处理"LLM → 工具 → LLM → ... → 结束"的循环
- **Middleware**：可插拔的中间件系统，定制 Agent 行为
- **流式输出**：支持 Token 级流式输出

### 没做什么 ❌

- **不做工作流编排**：那是 LangGraph 的事
- **不做持久化**：那也是 LangGraph 的事
- **不做多 Agent 协作**：那是 Deep Agents 的事
- **不做 RAG**：需要自己组合 LangChain 的组件

---

## LangChain 的核心定位

用一个比喻：

> LangChain 就像一个**乐高积木的基础件**——它提供基础的积木块（LLM、Tool、Message），你可以用它们搭建各种 Agent。但如果你想搭建复杂的城堡（多步骤工作流、持久化），你需要 LangGraph 这个"高级积木"。
