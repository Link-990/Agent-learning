# 3.6 自定义工具

除了内置工具，你还可以添加自定义工具。

---

## 定义自定义工具

```python
from langchain_core.tools import tool

@tool
def internet_search(query: str) -> str:
    """搜索互联网获取最新信息"""
    # 实际项目中接入真实搜索 API
    return f"搜索结果：{query}"

@tool
def send_email(to: str, subject: str, body: str) -> str:
    """发送邮件"""
    return f"邮件已发送给 {to}"

# 添加到 Agent
agent = create_deep_agent(
    model="gpt-5.5",
    tools=[internet_search, send_email],
)
```

---

## 自定义工具 + 内置工具

自定义工具和内置工具共存——Agent 可以同时使用：

```
用户: 搜索 AI 新闻，然后把摘要发邮件给我
Agent:
    1. 调用 internet_search("AI 最新新闻")
    2. 调用 write_file(path="/tmp/summary.md", content="...")
    3. 调用 send_email(to="user@example.com", subject="AI 新闻摘要", body="...")
```

## Kami Code 的工具系统

Kami Code 有几十个自定义工具（文件读写、代码执行、搜索等），通过 `ToolRegistry` 管理，转换为 `StructuredTool` 后传给 `create_deep_agent()`。
