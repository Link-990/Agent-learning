# 2.6 invoke 与 stream：调用方式

---

## invoke：同步调用

```python
result = agent.invoke(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": "123"}}
)
print(result["messages"][-1].content)
```

---

## stream：节点级流式

```python
for event in agent.stream(
    {"messages": [{"role": "user", "content": "你好"}]},
    config={"configurable": {"thread_id": "123"}}
):
    print(event)
```

---

## stream_events：事件级流式

```python
stream = agent.stream_events(
    {"messages": [{"role": "user", "content": "你好"}]},
    version="v3",
    config={"configurable": {"thread_id": "123"}}
)

for name, item in stream.interleave("messages", "subagents"):
    if name == "messages":
        print(f"[主 Agent] {item.text}")
    else:
        print(f"[子 Agent: {item.name}] {item.messages[-1].text}")
```

---

## Kami Code 的流式处理

Kami Code 使用 `stream_mode="messages"` 获取消息级流式输出：

```python
for chunk in agent.stream(payload, stream_mode="messages"):
    message, metadata = chunk
    node = metadata.get("langgraph_node")
    
    if node == "model":
        # LLM 生成的文本
        print(message.content, end="", flush=True)
    elif node == "tools":
        # 工具调用结果
        print(f"工具结果：{message.content}")
```
