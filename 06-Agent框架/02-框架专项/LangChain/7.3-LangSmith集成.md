# 7.3 LangSmith 集成

LangSmith 是 LangChain 官方的可观测性平台——追踪 Agent 的每一步执行。

---

## 配置

```bash
# .env
LANGSMITH_API_KEY=你的KEY
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=my-project
```

配置后，LangChain 的所有执行自动上报到 LangSmith，不需要改代码。

---

## 在 LangSmith 中查看

登录后可以看到：
- 每次 Agent 调用的完整追踪
- 每个节点的输入/输出
- LLM 调用的 Token 使用量
- 工具调用的参数和结果
- 错误和耗时

---

## Kami Code 中的可观测性

Kami Code 通过 `usage.py` 追踪 Token 使用量——从 `usage_metadata` 字段提取。在生产环境中，建议接入 LangSmith 获得更完整的可观测性。
