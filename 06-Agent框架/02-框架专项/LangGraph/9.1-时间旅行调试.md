# 9.1 时间旅行调试（Time Travel）

LangGraph 的 Checkpointer 不仅保存了当前状态，还保存了**所有历史状态**。这意味着你可以"回到过去"——回到 Agent 执行的任意一个时间点，查看当时的状态，甚至从那个时间点重新执行。

这就是**时间旅行调试**。

---

## 基本概念

每次执行后，Checkpointer 都会保存一个 checkpoint。所有 checkpoint 形成一个链：

```
checkpoint_1 → checkpoint_2 → checkpoint_3 → ...
```

你可以：
1. 查看任意 checkpoint 的状态
2. 从任意 checkpoint 继续执行
3. 比较不同 checkpoint 的差异

---

## 获取历史状态

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
app = graph.compile(checkpointer=checkpointer)

# 执行多次
app.invoke(input, config={"configurable": {"thread_id": "1"}})
app.invoke(input2, config={"configurable": {"thread_id": "1"}})

# 获取所有历史状态
history = list(app.get_state_history(
    config={"configurable": {"thread_id": "1"}}
))

for i, state in enumerate(history):
    print(f"Checkpoint {i}:")
    print(f"  值: {state.values}")
    print(f"  时间: {state.metadata.get('ts')}")
    print(f"  配置: {state.config}")
```

---

## 从历史状态继续执行

```python
# 获取第 2 个 checkpoint
old_state = history[1]

# 从那个状态继续执行
result = app.invoke(
    None,  # 不传新输入
    config=old_state.config
)
```

---

## 修改历史状态

```python
# 获取当前状态
state = app.get_state(config={"configurable": {"thread_id": "1"}})

# 修改状态
app.update_state(
    config={"configurable": {"thread_id": "1"}},
    values={"messages": [HumanMessage(content="修改后的消息")]},
    as_node="chat"
)

# 继续执行
result = app.invoke(None, config={"configurable": {"thread_id": "1"}})
```

---

## 实战：调试 Agent 的决策过程

```python
# Agent 执行到第 5 步出错了
# 想看看第 3 步时 LLM 说了什么

history = list(app.get_state_history(
    config={"configurable": {"thread_id": "1"}}
))

# 查看第 3 个 checkpoint
step3 = history[2]
print(f"第 3 步的消息：{step3.values['messages']}")

# 从第 3 步重新执行（换一个参数）
result = app.invoke(
    {"messages": [HumanMessage(content="换个问题")]},
    config=step3.config
)
```

---

## 小结

时间旅行调试：
- 查看所有历史 checkpoint
- 从任意 checkpoint 继续执行
- 修改历史状态
- 用于调试和"如果...会怎样"的分析
