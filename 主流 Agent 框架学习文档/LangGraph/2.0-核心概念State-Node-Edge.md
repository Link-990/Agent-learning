# 第二章：核心概念——State、Node、Edge

第一章我们搞清楚了"LangGraph 是什么""为什么要用它"。现在进入实战环节——掌握 LangGraph 的三大核心概念：**State（状态）**、**Node（节点）**、**Edge（边）**。

这三个概念是 LangGraph 的基石。理解了它们，你就掌握了 LangGraph 80% 的能力。

---

## 本章学习路线

- **2.1** State（状态）：Agent 的"记忆"，所有节点共享的数据结构
- **2.2** Node（节点）：执行具体逻辑的函数——可以是 LLM 调用，也可以是普通代码
- **2.3** Edge（边）：节点之间的连接，决定"下一步去哪"
- **2.4** 一个最简图：Hello LangGraph（完整代码 + 运行）
- **2.5** 用大白话理解：State 是黑板，Node 是干活的人，Edge 是流程箭头

---

## 学习方法建议

这一章会有不少代码示例。建议你：

1. **边看边敲**：把代码敲一遍，比光看强 10 倍
2. **改着玩**：运行成功后，试着改改参数、加个节点，看会发生什么
3. **画出来**：看到一个图的代码，先在纸上画出节点和边的结构，再对照代码

**预计学习时间：1-1.5 小时**
