# 2.2 ModelRuntime：多模型支持

ModelRuntime 管理 LLM 的发现、认证和调用。

---

## 创建 ModelRuntime

```typescript
import { ModelRuntime } from "@earendil-works/pi-coding-agent";

const modelRuntime = await ModelRuntime.create({
  authPath: "/custom/agent/auth.json",
  modelsPath: "/custom/agent/models.json",
});
```

---

## 获取模型

```typescript
import { getModel } from "@earendil-works/pi-ai";

// 获取内置模型
const opus = getModel("anthropic", "claude-opus-4-5");

// 通过 runtime 获取（包括自定义模型）
const custom = modelRuntime.getModel("my-provider", "my-model");

// 获取已认证可用的模型
const available = await modelRuntime.getAvailable();
```

---

## 动态设置 API Key

```typescript
if (process.env.ANTHROPIC_API_KEY) {
  modelRuntime.setRuntimeApiKey("anthropic", process.env.ANTHROPIC_API_KEY);
}
```

---

## 支持的 Provider

Pi 支持 15+ LLM Provider：
- Anthropic（Claude）
- OpenAI（GPT）
- Google（Gemini）
- Ollama（本地模型）
- OpenRouter
- 等等

---

## Thinking Level

控制模型的思考深度：

```typescript
const { session } = await createAgentSession({
  model: opus,
  thinkingLevel: "medium",  // off, minimal, low, medium, high, xhigh, max
});
```
