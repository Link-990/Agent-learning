# 9.2 错误恢复与容错

Agent 执行过程中难免出错——API 超时、工具调用失败、LLM 返回格式错误。这一节我们学习如何让 Agent 优雅地处理错误。

---

## 错误恢复策略

### 策略 1：重试

```python
import time

def retry_node(state, max_retries=3):
    for i in range(max_retries):
        try:
            result = call_external_api()
            return {"result": result}
        except Exception as e:
            if i == max_retries - 1:
                return {"error": str(e)}
            time.sleep(2 ** i)  # 指数退避
    return {"error": "max retries exceeded"}
```

### 策略 2：降级

```python
def smart_node(state):
    try:
        # 优先用 GPT-4
        result = gpt4_llm.invoke(state["messages"])
    except Exception:
        # GPT-4 不可用，降级到 GPT-3.5
        result = gpt35_llm.invoke(state["messages"])
    return {"messages": [result]}
```

### 策略 3：错误路由

```python
def route_after_node(state):
    if state.get("error"):
        return "error_handler"
    return "next_node"

graph.add_conditional_edges("risky_node", route_after_node, {
    "error_handler": "error_handler",
    "next_node": "next_node"
})
```

### 策略 4：Checkpoint 恢复

```python
# Agent 在第 5 步出错了
# 从第 4 步的 checkpoint 恢复，换一个策略

history = list(app.get_state_history(
    config={"configurable": {"thread_id": "1"}}
))

# 回到第 4 步
step4 = history[1]
result = app.invoke(None, config=step4.config)
```

---

## 最佳实践

1. **每个可能失败的节点都要有错误处理**
2. **使用重试机制应对临时性错误**
3. **准备降级方案**
4. **用 Checkpointer 保存关键状态，支持恢复**
5. **日志记录所有错误，方便调试**

---

## 小结

错误恢复策略：
- **重试**：指数退避重试
- **降级**：备选方案
- **错误路由**：跳到错误处理节点
- **Checkpoint 恢复**：回到之前的状态
