# 8.3 Prompt Caching

Deep Agents 对支持的模型自动应用 Prompt Caching——降低静态系统提示的成本和延迟。

---

## 原理

系统提示、AGENTS.md 等静态内容在多次调用中不变——Prompt Caching 把这些内容缓存起来，后续调用只需要发送增量。

---

## 效果

```
不缓存：
- 每次调用都发送完整的系统提示
- 系统提示 2000 tokens → 每次 2000 tokens

缓存后：
- 第一次：发送 2000 tokens
- 后续：发送 0 tokens（命中缓存）
```

---

## 自动生效

Deep Agents 自动处理缓存——不需要手动配置。只要模型支持（如 Anthropic Claude），就会自动启用。
