# 1.1 Deep Agents 是什么？

## 一句话理解

> **Deep Agents 是一个"Agent 线束"（Agent Harness）——它提供完整的执行环境，让 Agent 能读写文件、制定计划、委派子任务，处理复杂的多步骤任务。**

---

## 与普通 Agent 的区别

### 普通 Agent（LangChain `create_agent()`）

```python
from langchain.agents import create_agent

agent = create_agent(
    model="gpt-4o-mini",
    tools=[search],
    system_prompt="你是一个助手"
)
```

- 只能调用工具、返回结果
- 没有文件系统
- 没有规划能力
- 没有子 Agent 委派

### Deep Agent（Deep Agents `create_deep_agent()`）

```python
from deepagents import create_deep_agent

agent = create_deep_agent(
    model="openai:gpt-5.5",
    tools=[search],
    system_prompt="你是一个研究助手",
    subagents=[
        {"name": "writer", "description": "写作助手", "system_prompt": "你是写作专家"},
        {"name": "researcher", "description": "研究员", "system_prompt": "你是研究专家"},
    ],
)
```

- ✅ 内置文件系统（读写文件）
- ✅ 内置规划工具（write_todos）
- ✅ 子 Agent 委派（task 命令）
- ✅ 上下文自动管理
- ✅ 人工介入支持

---

## 名字的含义

"Deep" 有两层含义：

1. **深度任务**：能处理需要多步骤、长时间执行的复杂任务
2. **深度思考**：通过规划和子 Agent 委派，实现更深层次的问题解决

---

## 一个典型场景

用户说："帮我写一篇关于 AI 在教育领域应用的研究报告"

### 普通 Agent 的处理

1. 调用搜索工具，搜索一些信息
2. 直接生成一篇文章
3. 可能质量一般，没有深度

### Deep Agent 的处理

1. **规划**：用 `write_todos` 制定研究计划
   - [ ] 搜索 AI 在教育领域的最新进展
   - [ ] 搜索具体应用案例
   - [ ] 整理分析
   - [ ] 撰写报告
2. **委派**：把搜索任务委派给 researcher 子 Agent
3. **文件操作**：把收集的资料保存到文件
4. **写作**：把写作任务委派给 writer 子 Agent
5. **输出**：生成完整的研究报告
