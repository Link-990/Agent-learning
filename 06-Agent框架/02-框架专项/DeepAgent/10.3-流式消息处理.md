# 10.3 流式消息处理

Kami Code 通过解析 LangGraph 的流式消息，实现实时交互。

---

## LangGraph 的流式输出格式

```python
# stream_mode="messages" 返回的格式
(message, metadata)

# metadata 包含：
{"langgraph_node": "model"}  # 消息来自哪个节点
```

---

## 节点类型

| `langgraph_node` | 含义 |
|-------------------|------|
| `"model"` | LLM 生成的消息 |
| `"tools"` | 工具执行结果 |
| `"input"` | 用户输入回显 |

---

## 消息过滤

```python
def _stream_node(chunk):
    """提取节点名"""
    if not isinstance(chunk, tuple) or len(chunk) < 2:
        return ""
    value = chunk[1].get("langgraph_node")
    return value.strip().lower() if isinstance(value, str) else ""

def assistant_text_from_stream_chunk(chunk):
    """只提取 model 节点的 assistant 文本"""
    node = _stream_node(chunk)
    if node != "model":
        return ""
    
    message = chunk[0]
    if getattr(message, "type", None) != "ai":
        return ""
    
    return getattr(message, "content", "")
```

---

## 这就是 LangGraph 的实战用法

Kami Code 不直接构建 LangGraph 图——它消费 LangGraph 的流式输出。通过 `langgraph_node` 元数据区分消息来源，实现精确的消息路由。
