# 4.4 StoreBackend：持久化存储

StoreBackend 把文件存在 LangGraph Store 中——适合多用户、跨会话的场景。

---

## 用法

```python
from deepagents import create_deep_agent
from deepagents.backends import StoreBackend

agent = create_deep_agent(
    model="gpt-5.5",
    backend=StoreBackend(
        namespace=lambda rt: ("user", rt.context.user_id),
    ),
    context_schema=UserContext,
)
```

---

## 特点

- ✅ 持久化
- ✅ 多用户隔离（通过 namespace）
- ✅ 跨会话保留
- ❌ 需要配置 Store

---

## Namespace 设计

```python
# 按用户隔离
StoreBackend(namespace=lambda rt: ("user", rt.context.user_id))

# 按组织隔离
StoreBackend(namespace=lambda rt: ("org", rt.context.org_id))

# 按 Agent 隔离
StoreBackend(namespace=lambda rt: (rt.server_info.assistant_id,))
```
