# 4.1 什么是 Backend？

Backend 是 Deep Agents 的**文件系统抽象层**——它决定了 Agent 的文件操作实际存储在哪里。

---

## 为什么需要 Backend？

Agent 需要读写文件，但文件可以存在不同的地方：
- 内存中（开发测试）
- 本地磁盘（单机应用）
- 数据库（多用户、持久化）
- 沙箱环境（安全隔离）

Backend 让你切换存储后端，而不改变 Agent 的代码。

---

## Backend 接口

所有 Backend 实现相同的接口：

```python
class Backend:
    def read_file(self, path: str) -> str: ...
    def write_file(self, path: str, content: str) -> None: ...
    def list_dir(self, path: str) -> list[str]: ...
    def delete(self, path: str) -> None: ...
    def glob(self, pattern: str) -> list[str]: ...
    def grep(self, pattern: str, path: str) -> list[dict]: ...
```

---

## 四种 Backend

| Backend | 存储位置 | 持久化 | 适用场景 |
|---------|---------|-------|---------|
| `StateBackend` | 内存 | ❌ | 开发测试 |
| `FilesystemBackend` | 本地磁盘 | ✅ | 单机应用 |
| `StoreBackend` | LangGraph Store | ✅ | 多用户、持久化 |
| `CompositeBackend` | 混合路由 | 取决于子 Backend | 生产环境 |
