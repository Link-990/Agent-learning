## 为什么要看真实项目？

学习框架最好的方式，就是看它在真实项目中是怎么用的。Kami Code 是一个**类似 Claude Code 的本地 CLI 编程助手**，它底层使用了 LangGraph（通过 `deepagents` 框架），是学习 LangGraph 实战应用的绝佳案例。
