# 工具、协议与能力封装

这一阶段回答：模型提出的动作意图，如何经过校验、授权和协议边界，变成一次可审计的外部调用。

## 推荐顺序

1. [MCP](01-MCP/README.md)：协议角色、发现、调用和错误边界。
2. [Skills](02-Skills/README.md)：把任务知识和行为封装为可复用能力。
3. [飞书开放能力](03-飞书开放能力/README.md)：Function Calling、API、Webhook、卡片和人机协同。

Function Calling 是模型表达动作的格式，MCP 是能力连接协议，Skills 是任务能力包；它们解决的问题不同。
