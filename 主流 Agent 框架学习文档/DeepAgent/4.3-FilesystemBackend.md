# 4.3 FilesystemBackend：本地磁盘

FilesystemBackend 把文件存在本地磁盘——适合单机应用。

---

## 用法

```python
from deepagents import create_deep_agent
from deepagents.backends import FilesystemBackend

agent = create_deep_agent(
    model="gpt-5.5",
    backend=FilesystemBackend(root_dir="/Users/user/my_project"),
)
```

Agent 的文件操作直接映射到本地磁盘：

```
Agent: write_file(path="/report.md", content="...")
实际写入: /Users/user/my_project/report.md
```

---

## 特点

- ✅ 持久化
- ✅ 与真实文件系统交互
- ✅ 可以被其他程序读取
- ❌ 单机（不能跨服务器）
- ⚠️ 注意路径安全

---

## 配合 interrupt_on

```python
agent = create_deep_agent(
    model="gpt-5.5",
    backend=FilesystemBackend(root_dir="./project"),
    interrupt_on={
        "write_file": True,  # 写文件前审批
        "edit_file": True,   # 编辑文件前审批
        "delete": True,      # 删除文件前审批
    },
    checkpointer=MemorySaver(),
)
```
