# 2.5 tools 参数：工具绑定

---

## 内置工具

Deep Agents 自带一套内置工具（不需要手动添加）：

| 工具 | 功能 |
|------|------|
| `ls` | 列出目录内容 |
| `read_file` | 读取文件 |
| `write_file` | 写入文件 |
| `edit_file` | 编辑文件 |
| `delete` | 删除文件 |
| `glob` | 搜索文件名 |
| `grep` | 搜索文件内容 |
| `execute` | 执行 Shell 命令 |
| `eval` | 执行 JavaScript |
| `write_todos` | 任务规划 |
| `task` | 委派子任务 |

---

## 添加自定义工具

```python
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索互联网"""
    return f"搜索结果：{query}"

@tool
def get_weather(city: str) -> str:
    """获取天气"""
    return f"{city}晴天"

agent = create_deep_agent(
    model="gpt-5.5",
    tools=[search, get_weather],  # 自定义工具 + 内置工具
)
```

---

## 子 Agent 可以有不同工具

```python
agent = create_deep_agent(
    model="gpt-5.5",
    tools=[search],
    subagents=[
        {
            "name": "researcher",
            "description": "搜索",
            "system_prompt": "你是研究员",
            "tools": [search, get_weather],  # 子 Agent 的工具
        },
    ],
)
```
