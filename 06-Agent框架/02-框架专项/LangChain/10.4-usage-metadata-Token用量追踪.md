# 10.4 usage_metadata：Token 用量追踪

Token 用量直接关系到成本和性能。Kami Code 从 LangChain 的消息对象中提取 Token 使用量。

---

## 核心代码

```python
# kamiagent/usage.py
def usage_from_message(message, *, model):
    # 优先读 LangChain 格式的 usage_metadata
    usage_metadata = getattr(message, "usage_metadata", None)
    if usage_metadata:
        return {
            "model": model,
            "input_tokens": usage_metadata.get("input_tokens", 0),
            "output_tokens": usage_metadata.get("output_tokens", 0),
            "cache_read_tokens": usage_metadata.get(
                "input_token_details", {}
            ).get("cache_read", 0),
        }
    
    # 回退到 OpenAI 格式
    response_metadata = getattr(message, "response_metadata", {})
    token_usage = response_metadata.get("token_usage", {})
    if token_usage:
        return {
            "model": model,
            "input_tokens": token_usage.get("prompt_tokens", 0),
            "output_tokens": token_usage.get("completion_tokens", 0),
        }
    
    return None
```

---

## LangChain 的 usage_metadata 格式

```python
{
    "input_tokens": 150,
    "output_tokens": 80,
    "total_tokens": 230,
    "input_token_details": {
        "cache_read": 100
    }
}
```

---

## 多 Provider 兼容

Kami Code 的 `usage_from_message` 同时支持：
- LangChain 标准格式（`usage_metadata`）
- OpenAI 格式（`response_metadata.token_usage`）
- Anthropic 格式（`response_metadata.usage`）

---

## 小结

- Token 用量在消息对象的 `usage_metadata` 字段
- Kami Code 做了多 Provider 兼容
- 支持缓存 Token 统计
