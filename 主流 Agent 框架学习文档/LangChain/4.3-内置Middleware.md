# 4.3 内置 Middleware

LangChain 提供了几个开箱即用的 Middleware。

---

## SummarizationMiddleware

**作用**：当对话历史太长时，自动用 LLM 摘要旧消息，减少 Token 消耗。

```python
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[],
    middleware=[
        SummarizationMiddleware(
            model="openai:gpt-4o-mini",
            max_messages=20,  # 超过 20 条消息时触发摘要
        )
    ]
)
```

### 工作原理

1. 消息列表超过 `max_messages` 条
2. 用 LLM 对旧消息生成摘要
3. 用摘要替换旧消息
4. 保留最近的消息原文

---

## HumanInTheLoopMiddleware

**作用**：在工具执行前暂停，等待人工审批。

```python
from langchain.agents.middleware import HumanInTheLoopMiddleware

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[dangerous_tool],
    middleware=[
        HumanInTheLoopMiddleware(
            tool_names=["dangerous_tool"],  # 哪些工具需要审批
        )
    ]
)
```

---

## LLMToolSelectorMiddleware

**作用**：用一个小 LLM 从大量工具中选择最相关的几个，减少 Token 消耗。

```python
from langchain.agents.middleware import LLMToolSelectorMiddleware

agent = create_agent(
    model="openai:gpt-5.5",
    tools=all_tools,  # 假设有 100 个工具
    middleware=[
        LLMToolSelectorMiddleware(
            model="openai:gpt-4o-mini",  # 用小模型选择工具
            max_tools=5,                  # 最多选 5 个
        )
    ]
)
```

---

## 小结

| Middleware | 作用 |
|-----------|------|
| `SummarizationMiddleware` | 自动摘要长对话 |
| `HumanInTheLoopMiddleware` | 工具执行前人工审批 |
| `LLMToolSelectorMiddleware` | 智能选择相关工具 |
