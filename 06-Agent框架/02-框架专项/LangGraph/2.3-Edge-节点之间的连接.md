# 2.3 Edge——节点之间的连接

有了 State（数据）和 Node（逻辑），现在需要一个东西把它们"连起来"——这就是 **Edge（边）**。

边决定了"执行完节点 A，下一步去哪"。

---

## Edge 的本质：从 A 到 B 的箭头

想象一个流程图：

```
[节点 A] → [节点 B] → [节点 C]
```

这三个箭头就是"边"。

在 LangGraph 里，用代码表达就是：

```python
graph.add_edge("A", "B")  # 从 A 到 B
graph.add_edge("B", "C")  # 从 B 到 C
```

---

## 两种边：固定边 vs 条件边

### 1. 固定边（Normal Edge）

"执行完 A，**一定**去 B"。

```python
graph.add_edge("A", "B")
```

就这么简单。

### 2. 条件边（Conditional Edge）

"执行完 A，**根据情况**决定去 B 还是去 C"。

```python
def route_next(state):
    """根据 State 决定下一步"""
    if state["need_tool"]:
        return "tool_node"
    else:
        return END

graph.add_conditional_edges(
    "A",
    route_next,
    {
        "tool_node": "tool_node",
        END: END
    }
)
```

这里的逻辑是：
- 执行完节点 A
- 调用 `route_next` 函数，看它返回什么
- 如果返回 `"tool_node"`，就去 `tool_node` 节点
- 如果返回 `END`，就结束

---

## START 和 END：两个特殊节点

LangGraph 有两个内置的特殊节点：

### START：起点

表示"从这里开始"。

```python
from langgraph.graph import START

graph.add_edge(START, "first_node")
```

这表示：执行时，从 `first_node` 开始。

### END：终点

表示"到这里结束"。

```python
from langgraph.graph import END

graph.add_edge("last_node", END)
```

这表示：执行完 `last_node`，图的执行就结束了。

---

## 条件边的详细用法

条件边是 LangGraph 最强大的功能之一。让我们详细看看。

### 基本结构

```python
graph.add_conditional_edges(
    source="当前节点",
    path=路由函数,
    path_map=路径映射字典
)
```

- **source**：从哪个节点出来
- **path**：一个函数，根据 State 决定走哪条路
- **path_map**：把 path 函数的返回值映射到实际节点

### 路由函数的写法

路由函数接收 State，返回一个字符串（表示"走哪条路"）：

```python
def my_router(state):
    if state["count"] > 10:
        return "path_a"
    elif state["error"]:
        return "path_error"
    else:
        return "path_default"
```

### 路径映射字典

把路由函数的返回值，映射到实际节点：

```python
{
    "path_a": "node_a",
    "path_error": "error_handler",
    "path_default": "default_node"
}
```

完整示例：

```python
graph.add_conditional_edges(
    "decision_node",
    my_router,
    {
        "path_a": "node_a",
        "path_error": "error_handler",
        "path_default": "default_node"
    }
)
```

## 实战示例：一个简单的分支

假设我们要做一个"判断用户输入是否需要工具"的 Agent：

```python
from langgraph.graph import StateGraph, MessagesState, START, END

def llm_node(state):
    """调用 LLM"""
    # 假设 LLM 返回了一个标志
    return {"need_tool": True}

def tool_node(state):
    """调用工具"""
    return {"tool_result": "工具返回的结果"}

def route_after_llm(state):
    """路由函数：LLM 之后去哪"""
    if state.get("need_tool"):
        return "tool"
    else:
        return "end"

# 构建图
graph = StateGraph(MessagesState)
graph.add_node("llm", llm_node)
graph.add_node("tool", tool_node)

# 添加边
graph.add_edge(START, "llm")  # 开始 → LLM
graph.add_conditional_edges(
    "llm",
    route_after_llm,
    {
        "tool": "tool",
        "end": END
    }
)
graph.add_edge("tool", END)  # 工具 → 结束
```

流程图：

```
START → llm → 判断
            ├─ 需要工具 → tool → END
            └─ 不需要工具 → END
```

## 循环边：从 B 回到 A

边可以形成循环！这是 LangGraph 相比传统"链式调用"的巨大优势。

```python
graph.add_edge("A", "B")
graph.add_edge("B", "A")  # 从 B 回到 A，形成循环
```

实际应用场景：
- Agent 调用工具后，回到 LLM，让 LLM 看工具结果
- 代码执行出错后，回到"修复代码"节点

示例：

```python
def llm_node(state):
    # LLM 判断是否需要工具
    return {"need_tool": True}

def tool_node(state):
    # 调用工具
    return {"tool_result": "结果"}

def route_after_tool(state):
    """工具执行后，回到 LLM"""
    return "llm"

graph.add_node("llm", llm_node)
graph.add_node("tool", tool_node)

graph.add_edge(START, "llm")
graph.add_conditional_edges("llm", lambda s: "tool" if s["need_tool"] else END, {"tool": "tool", END: END})
graph.add_edge("tool", "llm")  # 工具 → LLM，形成循环
```

流程图：

```
START → llm ⇄ tool
         ↓
        END
```

---

## 并行边：同时执行多个节点

LangGraph 支持"从一个节点，同时走向多个节点"：

```python
graph.add_edge("A", "B")
graph.add_edge("A", "C")  # A 同时连到 B 和 C
```

这表示：执行完 A，B 和 C **并行执行**。

（这个功能在"多 Agent 协作"章节会详细讲）

---

## 常见错误：忘记连到 END

如果一个节点没有出边，也没有连到 END，LangGraph 会报错：

```python
graph.add_node("A", node_a)
graph.add_edge(START, "A")
# 忘记了：graph.add_edge("A", END)

app = graph.compile()  # 报错！
```

错误信息：`Node 'A' has no outgoing edges`

**解决**：确保每个节点都有出边，或者连到 END。

---

## Edge 的可视化

LangGraph 可以把图画出来，一眼看清楚边的连接：

```python
from IPython.display import Image, display

app = graph.compile()
display(Image(app.get_graph().draw_mermaid_png()))
```

会生成一张图，像这样：

```
START → node_a → node_b → END
              ↘ node_c ↗
```

强烈建议每次写完图，都画一下，检查是否符合预期。

---

## 小结

- **Edge 是什么**：节点之间的连接，决定执行顺序
- **两种边**：
  - 固定边：`add_edge(A, B)` —— 从 A 一定去 B
  - 条件边：`add_conditional_edges(A, router, path_map)` —— 根据情况决定
- **特殊节点**：START（起点）、END（终点）
- **循环边**：可以从 B 回到 A
- **并行边**：从 A 同时去 B 和 C
- **调试**：用 `get_graph().draw_mermaid_png()` 可视化

Edge 决定了"工作流的流动方向"——掌握了它，你就能设计出复杂的 Agent 逻辑。
