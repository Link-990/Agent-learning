# 6.6 Coordinator-Worker 模式

Coordinator-Worker 是 Deep Agents 最经典的多 Agent 模式。

---

## 架构

```
Coordinator（协调者）
    ↓ task() 委派
    ├─ Worker 1（研究员）
    ├─ Worker 2（写手）
    └─ Worker 3（审核员）
    ↓ 汇总结果
最终输出
```

---

## 完整代码

```python
agent = create_deep_agent(
    model="openai:gpt-5.5",
    system_prompt="""你是项目协调者。

规则：
1. 收到任务后，先用 write_todos 制定计划
2. 搜索任务委派给 researcher
3. 写作任务委派给 writer
4. 审核任务委派给 reviewer
5. 汇总所有结果后回复用户
""",
    subagents=[
        {
            "name": "researcher",
            "description": "搜索资料和分析数据",
            "system_prompt": "你是研究专家。搜索资料后返回摘要。大数据保存到文件。",
            "tools": [search_tool],
            "model": "openai:gpt-5.5",
        },
        {
            "name": "writer",
            "description": "撰写文章和报告",
            "system_prompt": "你是写作专家。根据资料撰写高质量文章。",
            "model": "anthropic:claude-sonnet-4-6",
        },
        {
            "name": "reviewer",
            "description": "审核内容质量",
            "system_prompt": "你是审核专家。检查内容的准确性和质量。",
            "model": "openai:gpt-4o-mini",  # 审核用小模型省钱
        },
    ],
)
```

---

## 执行流程

```
用户: "写一篇 AI 教育报告"

Coordinator:
    1. write_todos: 制定计划
    2. task("researcher", "搜索 AI 教育最新进展")
       → researcher 搜索资料，返回摘要
    3. task("writer", "根据资料撰写报告")
       → writer 撰写报告
    4. task("reviewer", "审核报告")
       → reviewer 返回修改建议
    5. 汇总结果，回复用户
```
