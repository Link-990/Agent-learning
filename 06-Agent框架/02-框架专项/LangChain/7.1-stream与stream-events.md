# 7.1 stream() 与 stream_events()

LangChain Agent 支持两种流式输出方式。

---

## stream()：节点级流式

```python
for event in agent.stream({"messages": [...]}):
    node_name = list(event.keys())[0]
    print(f"节点 {node_name} 执行完成")
```

每个节点执行完后返回一次。

---

## stream_events()：事件级流式

```python
for event in agent.stream_events({"messages": [...]}, version="v3"):
    if event["event"] == "on_chat_model_stream":
        content = event["data"]["chunk"].content
        if content:
            print(content, end="", flush=True)
```

可以获取每个 Token、每次工具调用。

---

## 对比

| 特性 | stream() | stream_events() |
|------|---------|-----------------|
| 粒度 | 节点级 | 事件级（Token、工具调用） |
| 适用场景 | 显示执行进度 | 实时显示 LLM 输出 |
