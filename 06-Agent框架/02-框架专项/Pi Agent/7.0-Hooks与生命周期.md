# 第七章：Hooks 与生命周期

Pi 的 Hooks 系统让你在 Agent 执行的各个阶段介入。

---

## 本章学习路线

- **7.1** before_agent_start
- **7.2** 其他生命周期钩子
- **7.3** 消息注入（sendMessage）
- **7.4** 工具执行模式

---

## 7.1 before_agent_start

```typescript
const hooks = new CodingAgentHooks(context);
hooks.before_agent_start = async (state) => {
  // 修改系统提示、注入消息
  return { systemPrompt: "修改后的提示" };
};
```

## 7.2 其他钩子

```typescript
hooks.before_tool_call = async (tool, args) => { ... };
hooks.after_tool_call = async (tool, result) => { ... };
hooks.after_agent_turn = async (state) => { ... };
```

## 7.3 sendMessage

```typescript
// 注入消息到会话
pi.sendMessage("紧急通知：...", { deliverAs: "steer" });
```

deliverAs 模式：
- `steer`（默认）：在当前轮次注入
- `followUp`：作为后续消息
- `nextTurn`：下一轮对话

## 7.4 工具执行模式

```typescript
executionMode: "sequential"  // 串行
executionMode: "parallel"    // 并行（默认）
```
