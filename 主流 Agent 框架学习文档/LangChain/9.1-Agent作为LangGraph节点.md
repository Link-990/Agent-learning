# 9.1 Agent 作为 LangGraph 节点

`create_agent()` 返回的 Agent 是一个编译后的 LangGraph 图——它可以作为另一个 LangGraph 图的节点使用。

---

## 用法

```python
from langgraph.graph import StateGraph, MessagesState, START, END
from langchain.agents import create_agent

# 创建一个 Agent
researcher = create_agent(
    model="openai:gpt-4o-mini",
    tools=[search_tool],
    system_prompt="你是研究员"
)

# 作为 LangGraph 图的节点
graph = StateGraph(MessagesState)
graph.add_node("researcher", lambda state: researcher.invoke(state))
graph.add_node("writer", writer_func)
graph.add_edge(START, "researcher")
graph.add_edge("researcher", "writer")
graph.add_edge("writer", END)

app = graph.compile()
```

---

## 应用场景

- 多 Agent 系统中，每个 Agent 是独立的节点
- 把 Agent 嵌入复杂的工作流
- 与其他非 Agent 节点组合
