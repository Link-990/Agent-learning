# 1.3 四大架构支柱

Deep Agents 的架构建立在四大支柱之上。理解它们，就理解了 Deep Agents 的核心设计。

---

## 四大支柱

```
┌─────────────────────────────────────────┐
│           Deep Agents 架构              │
├─────────────────────────────────────────┤
│                                         │
│  1. Execution Environment（执行环境）    │
│     虚拟文件系统 + Shell 沙箱           │
│                                         │
│  2. Context Management（上下文管理）     │
│     自动压缩 + 输出卸载到磁盘           │
│                                         │
│  3. Delegation（委派）                  │
│     write_todos 规划 + subagents 委派   │
│                                         │
│  4. Steering（引导）                    │
│     系统提示 + AGENTS.md + interrupt    │
│                                         │
└─────────────────────────────────────────┘
```

---

## 支柱 1：执行环境（Execution Environment）

Deep Agents 为 Agent 提供了一个**完整的执行环境**：

- **虚拟文件系统**：Agent 可以读写文件，就像在真实操作系统上一样
- **Shell 沙箱**：Agent 可以执行命令（在安全沙箱中）
- **JavaScript eval**：Agent 可以运行 JS 代码

```python
agent = create_deep_agent(
    model="gpt-5.5",
    backend=FilesystemBackend(root_dir="/path/to/project"),
)
```

Agent 可以调用内置工具：
- `ls`：列出文件
- `read_file`：读取文件
- `write_file`：写入文件
- `edit_file`：编辑文件
- `delete`：删除文件
- `glob`：搜索文件
- `grep`：搜索内容
- `execute`：执行 Shell 命令

---

## 支柱 2：上下文管理（Context Management）

长对话 = 高 Token 消耗。Deep Agents 自动管理上下文：

- **自动压缩**：对话太长时，用 LLM 对旧消息生成摘要
- **输出卸载**：工具返回的大数据，自动保存到文件，只在上下文中留一个引用

```
原始上下文：
- 消息列表（100 条）
- 工具结果（每条 1000 token）

压缩后：
- 摘要（500 token）
- 最近消息（20 条）
- 工具结果引用（指向文件）
```

---

## 支柱 3：委派（Delegation）

Deep Agents 支持两层委派：

### 第一层：write_todos（任务规划）

Agent 用 `write_todos` 工具制定计划：

```
任务计划：
- [ ] 搜索 AI 最新进展      (pending)
- [ ] 分析数据               (pending)
- [ ] 撰写报告               (pending)
```

Agent 可以更新任务状态：

```
任务计划：
- [x] 搜索 AI 最新进展      (completed)
- [~] 分析数据               (in_progress)
- [ ] 撰写报告               (pending)
```

### 第二层：subagents（子 Agent 委派）

主 Agent 可以把子任务委派给专门的子 Agent：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    subagents=[
        {"name": "researcher", "description": "搜索资料", "system_prompt": "..."},
        {"name": "writer", "description": "写文章", "system_prompt": "..."},
    ],
)
```

主 Agent 通过 `task()` 命令委派任务：

```
主 Agent: "我需要研究 AI 最新进展"
    → 调用 task(subagent_type="researcher", task="搜索 AI 最新进展")
    → researcher 子 Agent 执行搜索
    → 返回结果给主 Agent
```

## 支柱 4：引导（Steering）

Deep Agents 提供多种引导 Agent 行为的方式：

### 系统提示

```python
agent = create_deep_agent(
    model="gpt-5.5",
    system_prompt="你是一个编程助手，专注于 Python 开发。"
)
```

### AGENTS.md 文件

在项目根目录放一个 `AGENTS.md` 文件，Agent 启动时自动加载：

```markdown
# 项目指南

- 使用 Python 3.11+
- 遵循 PEP 8 编码规范
- 测试覆盖率 > 80%
```

### interrupt_on：人工介入

```python
agent = create_deep_agent(
    model="gpt-5.5",
    interrupt_on={
        "write_file": True,   # 写文件前需要审批
        "execute": True,      # 执行命令前需要审批
        "read_file": False,   # 读文件不需要审批
    },
    checkpointer=MemorySaver(),
)
```

---

## 四大支柱的协作

```
用户输入
    ↓
[Steering] 系统提示 + AGENTS.md 引导 Agent 行为
    ↓
[Delegation] Agent 用 write_todos 制定计划
    ↓
[Delegation] Agent 用 task() 委派任务给子 Agent
    ↓
[Execution] 子 Agent 在文件系统中读写文件
    ↓
[Context] 自动压缩长对话，卸载大数据到文件
    ↓
[Steering] interrupt_on 暂停等待人工审批
    ↓
输出结果
```

---

## 小结

Deep Agents 的四大支柱：
1. **执行环境**：虚拟文件系统 + Shell 沙箱
2. **上下文管理**：自动压缩 + 输出卸载
3. **委派**：write_todos 规划 + subagents 委派
4. **引导**：系统提示 + AGENTS.md + interrupt
