# 9.4 错误处理与容错

---

## Agent 级错误处理

```python
try:
    result = agent.invoke(input)
except Exception as e:
    print(f"Agent 执行失败：{e}")
```

## 工具级错误处理

工具内部捕获异常，返回友好错误：

```python
@tool
def risky_tool(x: int) -> str:
    try:
        return str(100 / x)
    except ZeroDivisionError:
        return "错误：除数不能为零"
```

## Checkpointer 容错

有了 Checkpointer，即使程序崩溃，也能从上次状态恢复：

```python
# 程序崩溃后重启
agent = create_deep_agent(
    model="gpt-5.5",
    checkpointer=SqliteSaver.from_conn_string("checkpoints.db"),
)

# 从上次中断的地方继续
result = agent.invoke(None, config={"configurable": {"thread_id": "123"}})
```
