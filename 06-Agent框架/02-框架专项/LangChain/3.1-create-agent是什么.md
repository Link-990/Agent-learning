# 3.1 create_agent() 是什么？

`create_agent()` 是 LangChain v1.0+ 引入的统一 Agent 创建接口。它把 LLM、工具、中间件组装成一个可执行的 Agent。

---

## 函数签名

```python
from langchain.agents import create_agent

agent = create_agent(
    model,                    # LLM 模型（字符串或对象）
    tools=[],                 # 工具列表
    system_prompt="",         # 系统提示词
    middleware=[],            # 中间件列表
    context_schema=None,      # 上下文 Schema（多租户）
)
```

---

## 它做了什么？

`create_agent()` 内部做了这些事：

1. **初始化 LLM**：根据 `model` 参数创建 Chat Model
2. **绑定工具**：调用 `llm.bind_tools(tools)`
3. **构建 LangGraph 图**：底层用 LangGraph 实现 Agent 循环
4. **应用 Middleware**：插入中间件到 Agent 循环中
5. **返回编译后的 Agent**：可以 `invoke()` 或 `stream()`

---

## 返回值

`create_agent()` 返回一个**编译后的 LangGraph 应用**（CompiledGraph），支持：

```python
# 同步调用
result = agent.invoke({"messages": [...]})

# 流式调用
for event in agent.stream({"messages": [...]}):
    print(event)

# 事件流
for event in agent.stream_events({"messages": [...]}, version="v3"):
    print(event)
```

---

## 与旧 API 的对比

| 旧 API（v0.x） | 新 API（v1.0+） |
|----------------|----------------|
| `AgentExecutor(agent=..., tools=...)` | `create_agent(model=..., tools=...)` |
| 需要先创建 Agent 对象 | 直接传 model 字符串 |
| 不支持 Middleware | 支持 Middleware |
| 不透明，不好调试 | 底层是 LangGraph，可追踪 |

---

## 小结

`create_agent()` 是 LangChain v1.0+ 的核心入口：
- 一个函数创建 Agent
- 底层用 LangGraph
- 支持 Middleware
- 返回可 invoke/stream 的对象
