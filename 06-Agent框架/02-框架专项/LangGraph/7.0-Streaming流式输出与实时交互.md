# 第七章：Streaming——流式输出与实时交互

前面的章节里，我们的 Agent 都是"一次性返回结果"——调用 `invoke()`，等待执行完成，拿到最终结果。

但在实际应用中，Agent 的执行可能需要几秒钟甚至几分钟。如果用户只能盯着一个"加载中..."的图标等待，体验会很差。

**Streaming（流式输出）** 解决这个问题——让 Agent 在执行过程中**实时输出中间结果**，用户可以看到 Agent 正在做什么。

## 为什么需要流式输出？

### 场景 1：长任务

Agent 执行一个复杂的任务，需要 30 秒：
- 没有流式：用户只能看到"加载中..."，30 秒后突然返回结果
- 有流式：用户实时看到 Agent 的每一步操作

### 场景 2：对话场景

用户问了一个问题，Agent 需要调用 LLM：
- 没有流式：等待 3-5 秒，突然返回一大段文字
- 有流式：像 ChatGPT 一样，一个字一个字地"打出来"

### 场景 3：调试

开发者想看到 Agent 的每一步执行过程：
- `invoke()` 只能看到最终结果
- `stream()` 可以看到每个节点的输入输出
