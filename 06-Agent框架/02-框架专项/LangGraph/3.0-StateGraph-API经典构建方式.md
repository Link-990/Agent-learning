# 第三章：StateGraph API——经典构建方式

前面我们已经用 StateGraph 写过一个 Hello World 了。这一章，我们深入学习 StateGraph API 的方方面面——从基础到进阶，把这个"经典构建方式"彻底掌握。

StateGraph 是 LangGraph 最原始、最灵活的 API。理解了它，你就能构建任意复杂的 Agent。

---

## 本章学习路线

- **3.1** StateGraph 类详解：如何定义和初始化一个图
- **3.2** 用 TypedDict + Annotated 定义自定义 State

- **3.7** 实战：构建一个带工具调用的 ReAct Agent

---

## 为什么要学 StateGraph？

虽然 LangGraph 后来推出了 Functional API（下一章会讲），但 StateGraph 仍然是：

1. **最灵活的方式**：能表达任何复杂的工作流
2. **最接近"图"的本质**：节点、边、状态，清晰明确
3. **社区示例最多**：大部分教程和开源项目都用它

**预计学习时间：2-3 小时**
