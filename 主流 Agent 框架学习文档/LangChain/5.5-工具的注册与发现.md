# 5.5 工具的注册与发现

当工具很多时（比如 Kami Code 有几十个工具），你需要一个工具注册表来管理它们。

---

## 简单方式：列表

```python
tools = [tool_a, tool_b, tool_c]
agent = create_agent(model="gpt-4o-mini", tools=tools)
```

适合工具少（< 10 个）的情况。

---

## 高级方式：ToolRegistry

```python
class ToolRegistry:
    def __init__(self):
        self._tools = {}
    
    def register(self, tool):
        self._tools[tool.name] = tool
    
    def get(self, name: str):
        return self._tools.get(name)
    
    def list_all(self):
        return list(self._tools.values())
    
    def filter(self, predicate):
        return [t for t in self._tools.values() if predicate(t)]

# 使用
registry = ToolRegistry()
registry.register(tool_a)
registry.register(tool_b)

# 传给 Agent
agent = create_agent(model="gpt-4o-mini", tools=registry.list_all())
```

---

## Kami Code 的 ToolRegistry

Kami Code 有一个完整的 `ToolRegistry`，支持：
- 注册/删除工具
- 按属性过滤（`is_read_only`、`defer_loading`）
- 转换为 `StructuredTool` 列表
- 附加 metadata 供 Middleware 使用

```python
# Kami Code 的工具注册表（简化版）
class ToolRegistry:
    def as_structured_tool_list(self) -> list[StructuredTool]:
        return [
            StructuredTool.from_function(
                func=spec.handler,
                name=spec.name,
                description=spec.description,
                args_schema=spec.input_schema,
                metadata={
                    "is_read_only": spec.is_read_only,
                    "defer_loading": spec.defer_loading,
                }
            )
            for spec in self.list_specs()
        ]
```

---

## 小结

工具管理：
- 简单场景：直接用列表
- 复杂场景：用 ToolRegistry 管理
- Kami Code 的 ToolRegistry 支持过滤、metadata、Schema 转换
