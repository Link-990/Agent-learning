# 3.3 system_prompt：系统提示词配置

`system_prompt` 是 Agent 的"灵魂"——它决定了 Agent 的行为、风格和能力范围。

---

## 基本用法

```python
agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[],
    system_prompt="你是一个专业的 Python 编程助手"
)
```

---

## 写好 system_prompt 的原则

### 1. 明确角色

```python
system_prompt = "你是一位有 10 年经验的高级 Python 工程师，擅长代码审查和架构设计。"
```

### 2. 明确能力范围

```python
system_prompt = """你是一个数据分析助手。你可以：
- 分析 CSV 和 Excel 文件
- 生成统计报告
- 创建数据可视化

你不能：
- 修改原始数据
- 执行系统命令
"""
```

### 3. 明确输出格式

```python
system_prompt = """回答时请遵循以下格式：
1. 先给出简短结论
2. 然后解释原因
3. 最后给出建议

用中文回答。
"""
```

### 4. 提供示例

```python
system_prompt = """你是一个翻译助手。

示例：
输入：Hello, how are you?
输出：你好，最近怎么样？

输入：The weather is nice today.
输出：今天天气不错。
"""
```

---

## 动态 system_prompt

如果需要动态生成 system_prompt，可以用函数：

```python
def get_system_prompt(user_role: str) -> str:
    prompts = {
        "admin": "你是管理员助手，有所有权限。",
        "user": "你是普通用户助手，权限有限。",
    }
    return prompts.get(user_role, "你是一个通用助手。")

# 根据用户角色选择不同的 prompt
agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[],
    system_prompt=get_system_prompt("admin")
)
```

---

## system_prompt 与工具描述的配合

system_prompt 和工具描述要互相配合：

```python
@tool
def search(query: str) -> str:
    """搜索互联网获取最新信息。当用户问到时事、新闻或不确定的事实时使用。"""
    ...

@tool
def calculate(expression: str) -> str:
    """计算数学表达式。当用户需要做数学运算时使用。"""
    ...

agent = create_agent(
    model="openai:gpt-4o-mini",
    tools=[search, calculate],
    system_prompt="""你是一个研究助手。
    
使用规则：
- 不确定的事实，用 search 工具搜索
- 数学问题，用 calculate 工具计算
- 不要编造数据
"""
)
```

---

## 小结

system_prompt 的要点：
- 明确角色、能力范围、输出格式
- 与工具描述配合
- 可以动态生成
- 好的 system_prompt = 好的 Agent
