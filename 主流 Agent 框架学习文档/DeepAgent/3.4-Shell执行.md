# 3.4 Shell 执行

---

## execute：执行 Shell 命令

```
Agent: execute(command="pip install requests")
返回: "Successfully installed requests-2.31.0"
```

## eval：执行 JavaScript

```
Agent: eval(code="JSON.stringify({a: 1, b: 2})")
返回: '{"a":1,"b":2}'
```

---

## 安全注意事项

Shell 执行有安全风险，建议配合 `interrupt_on` 使用：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    interrupt_on={"execute": True},  # 执行命令前审批
    checkpointer=MemorySaver(),
)
```
