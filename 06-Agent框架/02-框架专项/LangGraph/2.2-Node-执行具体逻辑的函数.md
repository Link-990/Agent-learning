# 2.2 Node——执行具体逻辑的函数

如果说 State 是"数据"，那么 **Node（节点）** 就是"处理数据的地方"。

一个节点，本质上就是一个 Python 函数——它接收 State，执行一些逻辑，然后返回更新。

---

## Node 的本质：一个普通的 Python 函数

最简单的节点长这样：

```python
def my_node(state):
    # 做点什么
    return {"some_field": "some_value"}
```

就这么简单。没有复杂的类、继承、装饰器——就是一个普通函数。

---

## Node 可以做什么？

节点里可以写**任何 Python 代码**：

### 1. 调用 LLM

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

def call_llm_node(state):
    messages = state["messages"]
    response = llm.invoke(messages)
    return {"messages": [response]}
```

### 2. 调用外部 API

```python
import requests

def weather_node(state):
    city = state["city"]
    response = requests.get(f"https://api.weather.com/{city}")
    weather_data = response.json()
    return {"weather": weather_data}
```

### 3. 查询数据库

```python
import sqlite3

def query_db_node(state):
    query = state["query"]
    conn = sqlite3.connect("mydatabase.db")
    cursor = conn.cursor()
    result = cursor.execute(query).fetchall()
    return {"db_result": result}
```

### 4. 做数据处理

```python
def process_data_node(state):
    raw_data = state["raw_data"]
    processed = [x * 2 for x in raw_data]
    return {"processed_data": processed}
```

### 5. 甚至什么都不做（空节点）

```python
def empty_node(state):
    return {}  # 不更新任何字段
```

---

## Node 的输入和输出

### 输入：State

节点函数的参数是当前的 State：

```python
def my_node(state):
    # state 是一个字典，包含当前所有字段
    user_input = state["input"]
    ...
```

### 输出：State 更新字典

节点返回一个字典，表示"我要更新 State 里的哪些字段"：

```python
def my_node(state):
    return {
        "output": "处理结果",
        "count": state["count"] + 1
    }
```

LangGraph 会把返回的字典合并到 State 里。

---

## Node 的命名：清晰 > 简洁

给节点起名字时，遵循一个原则：**让别人（或 3 个月后的自己）一眼看出这个节点是干什么的**。

好的命名：

```python
def call_llm_node(state): ...
def query_database_node(state): ...
def send_email_node(state): ...
```

不好的命名：

```python
def node1(state): ...
def process(state): ...
def do_stuff(state): ...
```

---

## Node 可以抛出异常

如果节点执行出错，直接 `raise` 异常：

```python
def risky_node(state):
    if state["value"] < 0:
        raise ValueError("value 不能为负数")
    return {"result": state["value"] * 2}
```

LangGraph 会捕获异常，并停止执行。

（后面学到"错误处理"章节时，会讲如何优雅地处理异常）

---

## Node 可以访问外部变量

节点函数可以访问闭包里的变量：

```python
llm = ChatOpenAI(model="gpt-4o-mini")

def call_llm_node(state):
    # 可以直接用外部的 llm 对象
    response = llm.invoke(state["messages"])
    return {"messages": [response]}
```

这样可以避免每次调用节点都重新初始化 LLM。

---

## Node 的类型标注（推荐）

给节点加上类型标注，IDE 会给你更好的提示：

```python
from typing import TypedDict

class MyState(TypedDict):
    input: str
    output: str

def my_node(state: MyState) -> dict:
    """这个节点的功能是..."""
    result = state["input"].upper()
    return {"output": result}
```

好处：
- IDE 自动补全：敲 `state["` 时会提示 `input` 和 `output`
- 类型检查：如果你写错了字段名，IDE 会警告
- 文档清晰：一眼看出这个节点接收什么、返回什么

## 实战示例：一个完整的节点

```python
from typing import TypedDict
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini")

class AgentState(TypedDict):
    messages: list
    city: str
    weather: str

def get_weather_node(state: AgentState) -> dict:
    """
    根据 LLM 的输出，调用天气 API
    """
    # 1. 从 State 里读取城市名
    city = state["city"]
    
    # 2. 调用天气 API（这里用假数据）
    if city == "北京":
        weather = "晴天，25°C"
    elif city == "上海":
        weather = "阴天，18°C"
    else:
        weather = "未知"
    
    # 3. 返回更新
    return {"weather": weather}

# 测试
test_state = {"messages": [], "city": "北京", "weather": ""}
result = get_weather_node(test_state)
print(result)  # {"weather": "晴天，25°C"}
```

---

## 小结

- **Node 是什么**：一个普通的 Python 函数，接收 State，返回更新
- **Node 可以做什么**：调用 LLM、调用 API、查数据库、做数据处理——任何 Python 代码
- **输入**：当前的 State（字典）
- **输出**：State 更新（字典）
- **命名**：清晰描述功能
- **类型标注**：推荐加上，IDE 支持更好

Node 就是"干活的地方"——你的业务逻辑都写在节点里。
