# 10.3 核心代码解读：流式消息解析

这一节我们深入解读 Kami Code 中最核心的代码——`message_stream.py` 中的流式消息解析逻辑。

---

## LangGraph 流式输出的数据格式

当使用 `stream_mode="messages"` 时，LangGraph 返回的数据格式是：

```python
(message, metadata)  # 元组
```

- **message**：LangChain 的消息对象
  - `AIMessageChunk`：LLM 生成的文本增量
  - `ToolMessage`：工具调用结果
  - `HumanMessage`：用户输入回显
- **metadata**：元数据字典
  - `langgraph_node`：消息来自哪个节点

---

## 节点类型

| `langgraph_node` | 含义 | 消息类型 |
|-------------------|------|---------|
| `"model"` | LLM 调用节点 | `AIMessageChunk` |
| `"tools"` | 工具执行节点 | `ToolMessage` |
| `"input"` | 输入节点 | `HumanMessage` |

---

## 解析代码逐行解读

### 提取节点名

```python
def _stream_node(chunk: Any) -> str:
    """
    从 chunk 中提取节点名。
    
    chunk 格式: (message, metadata)
    metadata 格式: {"langgraph_node": "model", ...}
    """
    # 1. 验证 chunk 格式
    if not isinstance(chunk, tuple):
        return ""
    if len(chunk) < 2:
        return ""
    if not isinstance(chunk[1], dict):
        return ""
    
    # 2. 提取 langgraph_node 字段
    value = chunk[1].get("langgraph_node")
    
    # 3. 规范化（转小写，去空格）
    return value.strip().lower() if isinstance(value, str) else ""
```

### 提取消息对象

```python
def _stream_message(chunk: Any) -> Any:
    """从 chunk 中提取消息对象"""
    if not isinstance(chunk, tuple) or len(chunk) < 1:
        return None
    return chunk[0]
```

### 提取消息角色

```python
def _message_role(message: Any) -> str:
    """获取消息的角色"""
    if message is None:
        return "unknown"
    
    msg_type = getattr(message, "type", None)
    
    if msg_type == "ai":
        return "assistant"
    elif msg_type == "human":
        return "user"
    elif msg_type == "tool":
        return "tool"
    else:
        return "unknown"
```

### 提取 assistant 文本

```python
def assistant_text_from_stream_chunk(chunk: Any) -> str:
    """
    从流式 chunk 中提取 assistant 的文本增量。
    
    只提取来自 model 节点的 AIMessageChunk。
    """
    # 1. 检查节点名
    node = _stream_node(chunk)
    if node != "model":
        return ""  # 不是 model 节点，跳过
    
    # 2. 提取消息
    message = _stream_message(chunk)
    if message is None:
        return ""
    
    # 3. 检查消息类型
    if getattr(message, "type", None) != "ai":
        return ""  # 不是 AI 消息，跳过
    
    # 4. 提取文本内容
    content = getattr(message, "content", "")
    if isinstance(content, str):
        return content
    
    return ""
```

## 完整流程示例

假设 LangGraph 的 ReAct Agent 执行一次，流式输出如下：

```python
# 1. 用户输入回显
(HumanMessage(content="搜索 AI 新闻"), {"langgraph_node": "input"})

# 2. LLM 决定调用工具（多个 token chunk）
(AIMessageChunk(content="我"), {"langgraph_node": "model"})
(AIMessageChunk(content="需要"), {"langgraph_node": "model"})
(AIMessageChunk(content="搜索"), {"langgraph_node": "model"})
(AIMessageChunk(content="", tool_calls=[...]), {"langgraph_node": "model"})

# 3. 工具执行结果
(ToolMessage(content="搜索结果：...", tool_call_id="call_1"), {"langgraph_node": "tools"})

# 4. LLM 生成最终回复（多个 token chunk）
(AIMessageChunk(content="根据"), {"langgraph_node": "model"})
(AIMessageChunk(content="搜索结果"), {"langgraph_node": "model"})
(AIMessageChunk(content="..."), {"langgraph_node": "model"})
```

Kami Code 的处理逻辑：

```python
for chunk in agent.stream(payload, stream_mode="messages"):
    # 1. input 节点的消息 → 跳过
    # 2. model 节点的 AI 文本 → 显示给用户
    text = assistant_text_from_stream_chunk(chunk)
    if text:
        print(text, end="", flush=True)
    
    # 3. tools 节点的消息 → 显示工具调用状态
    node = _stream_node(chunk)
    if node == "tools":
        print("\n🔧 工具执行中...")
```

---

## 为什么这样设计？

### 问题：LangGraph 的流式输出是"混合"的

LangGraph 把所有节点的消息都放在一个流里——model、tools、input 的消息交错出现。

### 解决方案：用 `langgraph_node` 过滤

通过 metadata 中的 `langgraph_node` 字段，Kami Code 可以：
- 只显示 model 节点的文本（用户看到的 AI 回复）
- 单独处理 tools 节点的消息（显示工具调用状态）
- 忽略 input 节点的消息（不需要回显用户输入）

### 优势

- ✅ 统一的流式接口
- ✅ 灵活的过滤逻辑
- ✅ 可以按需处理不同类型的消息

---

## 小结

Kami Code 的流式消息解析核心：

1. **数据格式**：`(message, metadata)` 元组
2. **节点识别**：通过 `metadata["langgraph_node"]` 区分消息来源
3. **消息过滤**：只显示 `model` 节点的 `assistant` 消息
4. **工具处理**：单独处理 `tools` 节点的消息

这种设计模式——**从混合流中按 metadata 过滤**——是消费 LangGraph 流式输出的标准做法。
