# 2.4 system_prompt：系统提示词

---

## 基本用法

```python
agent = create_deep_agent(
    model="gpt-5.5",
    system_prompt="你是一个编程助手，专注于 Python 开发。"
)
```

---

## 带文件操作指引

```python
agent = create_deep_agent(
    model="gpt-5.5",
    system_prompt="""你是一个研究助手。

工作流程：
1. 收到任务后，先用 write_todos 制定计划
2. 搜索资料，保存到 /data/ 目录
3. 分析资料，撰写报告
4. 报告保存到 /output/ 目录

注意：大数据请保存到文件，不要放在上下文中。"""
)
```

---

## 与 AGENTS.md 配合

system_prompt 是"通用指令"，AGENTS.md 是"项目特定指令"：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    system_prompt="你是一个编程助手",
    backend=FilesystemBackend(root_dir="./project"),
    memory=["./AGENTS.md"],  # 自动加载项目指南
)
```
