# 3.1 什么是 Extension？

Extension 是一个 TypeScript 模块，放在 `~/.pi/agent/extensions/` 目录下，Pi 启动时自动加载。

---

## Extension 能做什么

1. **注册自定义工具**：给 Agent 添加新能力
2. **注册自定义命令**：添加 `/command` 斜杠命令
3. **监听事件**：在 Agent 生命周期的各个阶段做操作
4. **修改系统提示**：动态修改 Agent 的行为

---

## Extension 的文件结构

```
~/.pi/agent/extensions/
├── my-extension.ts      # Extension 模块
├── another-extension.ts
└── ...
```

---

## 基本 Extension 结构

```typescript
// ~/.pi/agent/extensions/my-extension.ts
import type { PiExtension } from "@earendil-works/pi-coding-agent";

const extension: PiExtension = {
  name: "my-extension",
  
  setup(pi) {
    // 注册工具
    pi.registerTool({...});
    
    // 注册命令
    pi.registerCommand({...});
    
    // 监听事件
    pi.on("tool_call", (event) => {
      console.log(`工具调用：${event.toolName}`);
    });
  },
};

export default extension;
```
