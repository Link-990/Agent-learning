# 5.4 Tool extras：Provider-specific 功能

LangChain v1.2.0+ 引入了 `tool extras`——让工具可以携带 Provider 特有的配置。

---

## 用途

不同的 LLM Provider 有不同的工具能力：
- Anthropic 支持 **code execution**（在沙箱中执行代码）
- Anthropic 支持 **computer use**（控制鼠标键盘）
- 某些 Provider 支持 **client-side execution**（工具在客户端执行）

`tool extras` 让你声明这些特殊能力。

---

## 示例：允许代码执行

```python
@tool(extras={"allowed_callers": ["code_execution_20250825"]})
def run_python(code: str) -> str:
    """在沙箱中执行 Python 代码"""
    return exec(code)
```

`allowed_callers` 告诉 Anthropic：这个工具可以在你的沙箱中执行。

---

## 示例：标记只读工具

```python
@tool(extras={"is_read_only": True})
def search(query: str) -> str:
    """搜索信息（只读操作）"""
    ...
```

Kami Code 在 `StructuredTool` 的 metadata 中也使用了类似的概念：

```python
StructuredTool.from_function(
    func=...,
    metadata={
        "is_read_only": True,
        "source": "internal",
        "defer_loading": False,
    }
)
```

---

## 小结

Tool extras 让你：
- 声明 Provider-specific 的工具能力
- 标记工具的属性（只读、可延迟加载等）
- 让 Middleware 可以根据属性过滤工具
