# 第六章：Human-in-the-Loop——人工介入机制

AI Agent 再智能，有时候也需要"人在回路中"——在关键节点暂停，让人类审批、确认或修正。

这一章我们学习 LangGraph 的人工介入机制，让你的 Agent 具备"暂停/审批/恢复"的能力。

## 为什么需要人工介入？

### 场景 1：高风险操作

Agent 要执行的操作涉及金钱、删除数据、发送邮件等高风险操作，需要人工确认。

### 场景 2：AI 不确定

Agent 对自己的输出不确定，希望让人类帮忙判断。

### 场景 3：合规要求

某些行业（金融、医疗）有法规要求，关键决策必须有人工审批。

### 场景 4：质量控制

在发布内容之前，让人类审阅一遍。

---

## LangGraph 的人工介入机制

LangGraph 提供两种暂停方式：

### 1. 函数式：interrupt()

在代码里显式调用 `interrupt()`，暂停执行并等待人工输入。

```python
from langgraph.func import interrupt

result = interrupt({"question": "是否批准？"})
```

### 2. 节点级：interrupt_before / interrupt_after

在图的配置中指定在哪些节点之前或之后暂停。

```python
app = graph.compile(
    checkpointer=checkpointer,
    interrupt_before=["critical_node"]  # 在这个节点之前暂停
)
```

---

## 前提条件：必须配置 Checkpointer

人工介入必须配合 Checkpointer 使用，因为暂停时需要保存当前状态，恢复时需要加载状态。

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
```
