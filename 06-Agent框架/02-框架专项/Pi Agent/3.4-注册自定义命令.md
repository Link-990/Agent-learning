# 3.4 注册自定义命令

除了工具，Extension 还可以注册斜杠命令（`/command`）。

---

## 示例

```typescript
const extension: PiExtension = {
  name: "deploy",
  
  setup(pi) {
    pi.registerCommand({
      name: "deploy",
      description: "Deploy to production",
      execute: async (args) => {
        console.log("Deploying...");
        // 部署逻辑
      },
    });
  },
};
```

---

## 使用

```
> /deploy
Deploying...
```
