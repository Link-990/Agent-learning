# 4.2 @entrypoint 装饰器——工作流入口

`@entrypoint` 是 Functional API 的核心装饰器——它把一个普通的 Python 函数，变成一个"可执行的 LangGraph 工作流"。

这一节我们学习 `@entrypoint` 的各种用法。

---

## 基本用法

### 最简单的 entrypoint

```python
from langgraph.func import entrypoint

@entrypoint
def my_workflow(input: str) -> str:
    result = input.upper()
    return result

# 直接调用
output = my_workflow("hello")
print(output)  # "HELLO"
```

就这么简单！加上 `@entrypoint`，函数就变成了一个工作流。

---

## entrypoint 的参数

`@entrypoint` 可以接收一些配置参数：

```python
@entrypoint(
    checkpointer=...,       # 持久化检查点
    interrupt_before=[...], # 在哪些任务前暂停
    interrupt_after=[...],  # 在哪些任务后暂停
    store=...               # Store 系统（长期记忆）
)
def workflow(...):
    ...
```

我们逐个讲解。

---

## checkpointer：持久化

如果你想让工作流支持"暂停/恢复"，需要配置 checkpointer。

### 不带 checkpointer

```python
@entrypoint
def workflow(value: int) -> int:
    value = value + 10
    value = value * 2
    return value

result = workflow(5)
print(result)  # 30
```

这个工作流是"一次性"的——执行完就结束了，没有记忆。

### 带 checkpointer

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()

@entrypoint(checkpointer=checkpointer)
def workflow(value: int) -> int:
    value = value + 10
    value = value * 2
    return value

# 第一次执行
result = workflow(5, config={"thread_id": "thread_1"})
print(result)  # 30

# 第二次执行（同一个 thread_id，会继续之前的状态）
result = workflow(3, config={"thread_id": "thread_1"})
print(result)  # 26
```

**注意**：这个例子里，第二次执行还是从头开始的——因为函数没有"暂停"。checkpointer 的真正威力在于配合 `interrupt()` 使用（下一节会讲）。

---

## interrupt_before / interrupt_after：人工介入

你可以指定在哪些"任务"之前或之后暂停，让人工介入。

```python
from langgraph.func import entrypoint, task, interrupt
from langgraph.checkpoint.memory import MemorySaver

@task
def write_essay(topic: str) -> str:
    return f"关于 {topic} 的文章..."

@entrypoint(
    checkpointer=MemorySaver(),
    interrupt_after=["write_essay"]  # 在 write_essay 任务后暂停
)
def workflow(topic: str) -> str:
    essay = write_essay(topic)
    # 这里会暂停，等待人工决定
    return essay
```

（`@task` 的用法下一节会详细讲）

## store：长期记忆

`store` 参数用于配置 Store 系统（跨线程的长期记忆）。

```python
from langgraph.store.memory import InMemoryStore

store = InMemoryStore()

@entrypoint(store=store)
def workflow(user_id: str, message: str):
    # 可以在函数里通过 runtime.store 访问
    # （具体用法在"持久化系统"章节会讲）
    pass
```

## entrypoint 的返回值

### 同步执行

```python
@entrypoint
def workflow(input: str) -> str:
    return input.upper()

result = workflow("hello")
print(result)  # "HELLO"
```

### 流式执行

```python
@entrypoint(checkpointer=MemorySaver())
def workflow(input: str) -> str:
    return input.upper()

# 用 stream() 获取流式输出
for event in workflow.stream("hello", config={"thread_id": "1"}):
    print(event)
```

---

## entrypoint 的可注入参数

在 entrypoint 函数里，可以声明一些特殊参数，LangGraph 会自动注入：

### 1. config

获取运行时配置（如 thread_id）。

```python
from langgraph.func import entrypoint
from typing import Any

@entrypoint
def workflow(input: str, config: dict[str, Any]) -> str:
    thread_id = config.get("configurable", {}).get("thread_id")
    return f"处理 {input}，线程 ID: {thread_id}"

result = workflow("hello", config={"configurable": {"thread_id": "thread_1"}})
print(result)
```

### 2. store（需要在 @entrypoint 里配置）

```python
from langgraph.func import entrypoint
from langgraph.store.memory import InMemoryStore

store = InMemoryStore()

@entrypoint(store=store)
def workflow(user_id: str, store):
    # 从 store 里读取用户记忆
    memories = store.search(("user", user_id))
    return f"找到 {len(memories)} 条记忆"
```

### 3. writer（用于流式输出）

```python
from langgraph.func import entrypoint

@entrypoint
def workflow(input: str, writer):
    writer.write("步骤 1：开始处理")
    result = input.upper()
    writer.write("步骤 2：处理完成")
    return result
```

---

## 调用 entrypoint 的方式

### 方式 1：直接调用（同步）

```python
result = workflow(input)
```

### 方式 2：用 .invoke()（与 StateGraph 一致）

```python
result = workflow.invoke(input, config={"thread_id": "1"})
```

### 方式 3：用 .stream()（流式）

```python
for event in workflow.stream(input, config={"thread_id": "1"}):
    print(event)
```

### 方式 4：用 .ainvoke()（异步）

```python
result = await workflow.ainvoke(input)
```

---

## entrypoint 的编译行为

虽然你写的是普通函数，但 LangGraph 会在第一次调用时，把它编译成图。

```python
@entrypoint
def workflow(input: str) -> str:
    step1 = input.upper()
    step2 = step1 + "!!!"
    return step2

# 第一次调用：编译 + 执行
result1 = workflow("hello")

# 第二次调用：直接执行（已编译）
result2 = workflow("world")
```

编译后的图可以通过 `.get_graph()` 查看：

```python
graph = workflow.get_graph()
print(graph)
```

## 实战示例：一个简单的审批工作流

```python
from langgraph.func import entrypoint, interrupt
from langgraph.checkpoint.memory import MemorySaver

@entrypoint(checkpointer=MemorySaver())
def approval_workflow(proposal: str) -> str:
    # 1. 生成计划
    plan = f"计划：{proposal}"
    
    # 2. 请求人工审批（这里会暂停）
    approved = interrupt({"plan": plan, "question": "是否批准？"})
    
    # 3. 根据审批结果决定
    if approved:
        result = f"执行计划：{plan}"
    else:
        result = "计划被拒绝"
    
    return result

# 第一次调用：会在 interrupt 处暂停
try:
    result = approval_workflow("建设新大楼", config={"thread_id": "1"})
except Exception as e:
    print("工作流已暂停，等待审批")

# 人工审批后，恢复执行
from langgraph.types import Command

result = approval_workflow.invoke(
    Command(resume=True),  # 批准
    config={"thread_id": "1"}
)
print(result)  # "执行计划：计划：建设新大楼"
```

## 常见错误

### 错误 1：忘记配置 checkpointer

```python
@entrypoint  # 没有 checkpointer
def workflow():
    interrupt(...)  # 运行时报错！
```

**解决**：使用 `interrupt()` 必须配置 checkpointer。

### 错误 2：entrypoint 里不能用 async

```python
@entrypoint
async def workflow():  # ❌ 不支持
    ...
```

**解决**：用同步函数。如果需要异步，在函数内部用 `await`。

---

## 小结

`@entrypoint` 的作用：
- 把普通函数变成 LangGraph 工作流
- 自动编译成图
- 支持 checkpointer、interrupt、store

配置参数：
- `checkpointer`：持久化
- `interrupt_before` / `interrupt_after`：人工介入点
- `store`：长期记忆

可注入参数：
- `config`：运行时配置
- `store`：Store 系统
- `writer`：流式输出

调用方式：
- 直接调用：`workflow(input)`
- `.invoke()`、`.stream()`、`.ainvoke()`
