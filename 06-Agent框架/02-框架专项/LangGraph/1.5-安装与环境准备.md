# 1.5 安装与环境准备

理论讲了这么多，终于到了动手环节。这一节我们把 LangGraph 的开发环境搭起来，确保后面的代码都能跑通。

---

## 前置要求

在开始之前，确保你的电脑上已经安装了：

1. **Python 3.9 或更高版本**
   ```bash
   python --version  # 应该显示 Python 3.9.x 或更高
   ```
   
   如果版本太低，去 [python.org](https://www.python.org/) 下载最新版本。

2. **pip（Python 包管理器）**
   ```bash
   pip --version
   ```
   
   一般安装 Python 时会自动安装 pip。

3. **一个代码编辑器**
   推荐 VS Code、PyCharm 或 Cursor。

---

## 第一步：创建虚拟环境（强烈推荐）

虚拟环境可以隔离项目的依赖，避免不同项目之间的包冲突。

### 在 Windows 上：

```bash
# 创建虚拟环境
python -m venv langgraph-env

# 激活虚拟环境
langgraph-env\Scripts\activate
```

### 在 macOS/Linux 上：

```bash
# 创建虚拟环境
python3 -m venv langgraph-env

# 激活虚拟环境
source langgraph-env/bin/activate
```

激活成功后，你会看到命令行前面多了 `(langgraph-env)` 前缀。

---

## 第二步：安装 LangGraph

在激活的虚拟环境中，运行：

```bash
pip install langgraph
```

这会安装 LangGraph 以及它的依赖（包括 LangChain 核心库）。

### 验证安装

```bash
python -c "import langgraph; print(langgraph.__version__)"
```

如果能打印出版本号（比如 `1.0.8`），说明安装成功。

---

## 第三步：安装 LLM Provider 的库

LangGraph 本身不提供 LLM API，你需要安装对应的库。

### 如果你用 OpenAI（ChatGPT）

```bash
pip install langchain-openai
```

### 如果你用 Anthropic（Claude）

```bash
pip install langchain-anthropic
```

### 如果你用 Google（Gemini）

```bash
pip install langchain-google-genai
```

### 如果你想本地运行开源模型（Ollama）

```bash
pip install langchain-ollama
```

**建议**：如果不确定，先装 OpenAI 的——大部分教程都用它做示例。

---

## 第四步：配置 API Key

LLM API 需要 API Key 才能调用。

### 获取 API Key

- **OpenAI**：去 [platform.openai.com](https://platform.openai.com/) 注册账号，创建 API Key
- **Anthropic**：去 [console.anthropic.com](https://console.anthropic.com/) 注册，创建 API Key
- **Google**：去 [ai.google.dev](https://ai.google.dev/) 申请 API Key

### 配置环境变量

拿到 API Key 后，配置到环境变量里。

#### 方法 1：直接在命令行设置（临时）

**Windows (PowerShell):**
```powershell
$env:OPENAI_API_KEY="你的API_KEY"
```

**macOS/Linux:**
```bash
export OPENAI_API_KEY="你的API_KEY"
```

这种方法只在当前终端会话有效。

#### 方法 2：写到 `.env` 文件（推荐）

在项目根目录创建一个 `.env` 文件：

```bash
OPENAI_API_KEY=你的API_KEY
ANTHROPIC_API_KEY=你的另一个KEY
```

然后安装 `python-dotenv`：

```bash
pip install python-dotenv
```

在代码里加载：

```python
from dotenv import load_dotenv
load_dotenv()  # 自动加载 .env 文件里的环境变量
```

**⚠️ 重要提醒**：千万不要把 `.env` 文件提交到 Git 仓库！在 `.gitignore` 里加上：

```
.env
```

## 第五步：安装可选的辅助工具

### 1. Jupyter Notebook（方便做实验）

```bash
pip install jupyter
```

启动：

```bash
jupyter notebook
```

### 2. IPython（增强的 Python 交互式终端）

```bash
pip install ipython
```

启动：

```bash
ipython
```

### 3. LangSmith（可观测性工具，可选）

LangSmith 是 LangChain 官方的调试工具，可以追踪 Agent 的每一步执行。

去 [smith.langchain.com](https://smith.langchain.com/) 注册账号，拿到 API Key，然后：

```bash
pip install langsmith
```

配置环境变量：

```bash
# .env 文件里加上
LANGSMITH_API_KEY=你的LangSmith_API_KEY
LANGSMITH_TRACING=true
```

后面学到调试的时候，会详细讲怎么用。

## 第六步：测试一下，确保能跑

创建一个 `test.py` 文件：

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, MessagesState, START, END

# 加载环境变量
load_dotenv()

# 初始化 LLM
llm = ChatOpenAI(model="gpt-4o-mini")

# 定义一个简单的节点
def call_llm(state: MessagesState):
    response = llm.invoke(state["messages"])
    return {"messages": [response]}

# 构建图
graph = StateGraph(MessagesState)
graph.add_node("llm", call_llm)
graph.add_edge(START, "llm")
graph.add_edge("llm", END)

# 编译并运行
app = graph.compile()
result = app.invoke({"messages": [{"role": "user", "content": "你好"}]})

print(result["messages"][-1].content)
```

运行：

```bash
python test.py
```

如果能看到 LLM 的回复（比如"你好！有什么我可以帮你的吗？"），说明环境搭建成功！

## 常见问题排查

### 问题 1：`ImportError: No module named 'langgraph'`

**原因**：没有激活虚拟环境，或者在激活前安装的包。

**解决**：
1. 确保虚拟环境已激活（命令行前面有 `(langgraph-env)` 前缀）
2. 在虚拟环境里重新运行 `pip install langgraph`

### 问题 2：`AuthenticationError: Incorrect API key`

**原因**：API Key 配置错误。

**解决**：
1. 检查 `.env` 文件里的 Key 是否正确（没有多余的空格、引号）
2. 确保代码里调用了 `load_dotenv()`
3. 如果直接用环境变量，确保在同一个终端会话里运行代码

### 问题 3：`RateLimitError: Rate limit exceeded`

**原因**：API 调用频率超限（或者免费额度用完了）。

**解决**：
1. 等几分钟再试
2. 去 API 提供商的控制台检查额度
3. 用 `gpt-4o-mini` 这种便宜的模型，而不是 `gpt-4`

```text
langgraph>=1.0.0

langchain-anthropic

jupyter

```

然后运行：

```bash
pip install -r requirements.txt
```
