# 6.2 subagents 参数配置

---

## 基本配置

```python
agent = create_deep_agent(
    model="openai:gpt-5.5",
    subagents=[
        {
            "name": "researcher",
            "description": "搜索资料和分析数据",
            "system_prompt": "你是研究专家，擅长搜索资料和分析数据。",
        },
        {
            "name": "writer",
            "description": "撰写文章和报告",
            "system_prompt": "你是写作专家，擅长撰写高质量的文章。",
        },
    ],
)
```

---

## 子 Agent 的参数

| 参数 | 说明 |
|------|------|
| `name` | 子 Agent 的名字（用于 task 命令） |
| `description` | 描述（主 Agent 靠它决定委派给谁） |
| `system_prompt` | 子 Agent 的系统提示词 |
| `tools` | 子 Agent 的工具（可选） |
| `model` | 子 Agent 的模型（可选，默认继承主 Agent） |

---

## 带工具的子 Agent

```python
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索"""
    return f"结果：{query}"

agent = create_deep_agent(
    model="gpt-5.5",
    subagents=[
        {
            "name": "researcher",
            "description": "搜索资料",
            "system_prompt": "你是研究员",
            "tools": [search],  # 子 Agent 的工具
        },
    ],
)
```
