# 第四章：Middleware 系统——Agent 的定制核心

Middleware（中间件）是 LangChain v1.0+ 最重要的新特性——它让你可以**拦截和定制 Agent 的每一步行为**，而不需要修改 Agent 的核心逻辑。

这也是 Kami Code 用来实现"延迟加载工具过滤"的核心机制。
