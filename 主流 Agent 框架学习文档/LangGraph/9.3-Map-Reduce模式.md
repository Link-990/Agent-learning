# 9.3 Map/Reduce 模式

Map/Reduce 是一种并行处理模式——把任务分成多个子任务（Map），并行执行，然后汇总结果（Reduce）。

---

## 模式说明

```
输入数据
    ↓
[Map] → 子任务 1 → 结果 1
      → 子任务 2 → 结果 2
      → 子任务 3 → 结果 3
    ↓
[Reduce] → 汇总所有结果
    ↓
最终输出
```

---

## 在 LangGraph 中实现

### 方式 1：手动并行

```python
from concurrent.futures import ThreadPoolExecutor

def map_node(state):
    items = state["items"]
    
    with ThreadPoolExecutor(max_workers=3) as executor:
        results = list(executor.map(process_item, items))
    
    return {"results": results}

def reduce_node(state):
    results = state["results"]
    final = aggregate(results)
    return {"final": final}

graph.add_node("map", map_node)
graph.add_node("reduce", reduce_node)
graph.add_edge("map", "reduce")
```

### 方式 2：Send API（LangGraph 原生支持）

```python
from langgraph.types import Send

def map_node(state):
    items = state["items"]
    
    # 为每个 item 创建一个 Send
    return [Send("process", {"item": item}) for item in items]

def reduce_node(state):
    # 收集所有 process 节点的结果
    results = state["all_results"]
    final = aggregate(results)
    return {"final": final}

graph.add_node("map", map_node)
graph.add_node("process", process_node)
graph.add_node("reduce", reduce_node)

graph.add_edge("map", "process")  # 每个 Send 都会执行 process
graph.add_edge("process", "reduce")
```

## 实战：并行分析多篇文章

```python
from langgraph.graph import StateGraph, START, END
from langchain_openai import ChatOpenAI
from typing import TypedDict

llm = ChatOpenAI(model="gpt-4o-mini")

class State(TypedDict):
    articles: list[str]
    summaries: list[str]

def analyze_article(article: str) -> str:
    response = llm.invoke([
        {"role": "system", "content": "请用一句话总结这篇文章。"},
        {"role": "user", "content": article}
    ])
    return response.content

def map_node(state: State):
    from concurrent.futures import ThreadPoolExecutor
    
    articles = state["articles"]
    with ThreadPoolExecutor(max_workers=5) as executor:
        summaries = list(executor.map(analyze_article, articles))
    
    return {"summaries": summaries}

def reduce_node(state: State):
    summaries = state["summaries"]
    
    combined = "\n".join([f"- {s}" for s in summaries])
    response = llm.invoke([
        {"role": "system", "content": "根据以下摘要，生成一份综合报告。"},
        {"role": "user", "content": combined}
    ])
    
    return {"final_report": response.content}

graph = StateGraph(State)
graph.add_node("map", map_node)
graph.add_node("reduce", reduce_node)
graph.add_edge(START, "map")
graph.add_edge("map", "reduce")
graph.add_edge("reduce", END)

app = graph.compile()

# 测试
result = app.invoke({
    "articles": [
        "文章1内容...",
        "文章2内容...",
        "文章3内容..."
    ]
})
print(result["final_report"])
```

---

## 小结

Map/Reduce 模式：
- **Map**：并行处理多个子任务
- **Reduce**：汇总所有结果
- 用 `ThreadPoolExecutor` 实现并行
- 适合批量处理、数据分析
