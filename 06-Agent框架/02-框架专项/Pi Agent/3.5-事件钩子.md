# 3.5 事件钩子

Extension 可以监听 Agent 的各种事件。

---

## 可用事件

```typescript
pi.on("tool_call", (event) => {
  console.log(`工具调用：${event.toolName}`);
});

pi.on("tool_result", (event) => {
  console.log(`工具结果：${event.result}`);
});

pi.on("message", (event) => {
  console.log(`消息：${event.content}`);
});

pi.on("turn_start", () => {
  console.log("新一轮对话开始");
});

pi.on("turn_end", () => {
  console.log("一轮对话结束");
});
```

---

## 实际应用

```typescript
// 记录所有工具调用
pi.on("tool_call", (event) => {
  const log = `${new Date().toISOString()} - ${event.toolName}(${JSON.stringify(event.args)})`;
  fs.appendFileSync("tool_calls.log", log + "\n");
});
```
