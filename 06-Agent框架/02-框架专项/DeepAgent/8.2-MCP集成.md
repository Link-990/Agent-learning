# 8.2 MCP 集成

Deep Agents 支持 MCP（Model Context Protocol）——接入外部工具服务器。

---

## 什么是 MCP？

MCP 是一个标准化协议，让 Agent 可以接入各种外部工具服务器：
- 数据库查询
- API 调用
- 文件系统操作
- 自定义服务

---

## 配置

Deep Agents 可以集成任何 MCP 服务器作为工具来源。具体配置取决于 MCP 服务器的类型。

---

## 使用场景

- 接入公司内部 API
- 连接数据库
- 使用第三方服务
