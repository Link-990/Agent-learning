# 4.4 自定义 Middleware 开发

这一节我们学习如何自己写 Middleware。

---

## 基本结构

```python
from langchain.agents.middleware import AgentMiddleware, ModelRequest, ModelResponse
from typing import Callable

class MyMiddleware(AgentMiddleware):
    def wrap_model_call(
        self,
        request: ModelRequest,
        handler: Callable[[ModelRequest], ModelResponse],
    ) -> ModelResponse:
        """拦截 LLM 调用"""
        
        # 调用前：修改 request（可选）
        # request = request.override(tools=new_tools)
        
        # 调用 handler 执行 LLM
        response = handler(request)
        
        # 调用后：修改 response（可选）
        
        return response
```

## 示例 1：日志 Middleware

```python
class LoggingMiddleware(AgentMiddleware):
    def wrap_model_call(self, request, handler):
        print(f"📝 LLM 调用：{len(request.messages)} 条消息")
        response = handler(request)
        print(f"✅ LLM 返回：{len(response.message.content)} 字")
        return response
```

## 示例 2：工具过滤 Middleware

这是 Kami Code 中 `DeferredToolMiddleware` 的简化版：

```python
class ToolFilterMiddleware(AgentMiddleware):
    def __init__(self, allowed_tools: list[str]):
        self.allowed_tools = allowed_tools
    
    def wrap_model_call(self, request, handler):
        # 只保留允许的工具
        filtered = [t for t in request.tools if t.name in self.allowed_tools]
        
        # 用过滤后的工具列表替换原列表
        return handler(request.override(tools=filtered))

# 使用
agent = create_agent(
    model="gpt-4o-mini",
    tools=[tool_a, tool_b, tool_c, tool_d],
    middleware=[ToolFilterMiddleware(allowed_tools=["tool_a", "tool_b"])]
)
```

## 示例 3：成本追踪 Middleware

```python
class CostTrackerMiddleware(AgentMiddleware):
    def __init__(self):
        self.total_tokens = 0
        self.total_cost = 0.0
    
    def wrap_model_call(self, request, handler):
        response = handler(request)
        
        # 提取 Token 使用量
        usage = getattr(response.message, "usage_metadata", {})
        input_tokens = usage.get("input_tokens", 0)
        output_tokens = usage.get("output_tokens", 0)
        
        self.total_tokens += input_tokens + output_tokens
        self.total_cost += (input_tokens * 0.00001 + output_tokens * 0.00003)
        
        print(f"💰 本次消耗：{input_tokens + output_tokens} tokens")
        print(f"💰 累计消耗：{self.total_tokens} tokens, ${self.total_cost:.4f}")
        
        return response
```

## 示例 4：安全过滤 Middleware

```python
class SafetyMiddleware(AgentMiddleware):
    FORBIDDEN_WORDS = ["密码", "密钥", "信用卡"]
    
    def wrap_model_call(self, request, handler):
        # 检查用户输入是否包含敏感词
        for msg in request.messages:
            for word in self.FORBIDDEN_WORDS:
                if word in msg.content:
                    return ModelResponse(
                        message=AIMessage(content="抱歉，您的输入包含敏感信息，请修改后重试。")
                    )
        
        return handler(request)
```

---

## 小结

自定义 Middleware 的步骤：
1. 继承 `AgentMiddleware`
2. 实现 `wrap_model_call` 方法
3. 用 `request.override()` 修改请求
4. 用 `handler(request)` 执行下一步
5. 可以修改返回的 response
