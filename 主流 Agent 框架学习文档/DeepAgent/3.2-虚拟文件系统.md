# 3.2 虚拟文件系统

Deep Agents 为 Agent 提供了一个虚拟文件系统——Agent 可以像操作真实文件系统一样读写文件。

---

## 后端选择

文件系统的实际存储取决于 Backend 配置：

```python
# 内存虚拟文件系统（默认）
from deepagents.backends import StateBackend
agent = create_deep_agent(model="gpt-5.5", backend=StateBackend())

# 本地磁盘
from deepagents.backends import FilesystemBackend
agent = create_deep_agent(model="gpt-5.5", backend=FilesystemBackend(root_dir="./project"))

# 持久化存储
from deepagents.backends import StoreBackend
agent = create_deep_agent(model="gpt-5.5", backend=StoreBackend(namespace=("user", "123")))
```

---

## 文件操作

### 写入文件

```
Agent: write_file(path="/output/report.md", content="# 研究报告\n...")
```

### 读取文件

```
Agent: read_file(path="/output/report.md")
返回: "# 研究报告\n..."
```

### 编辑文件

```
Agent: edit_file(path="/output/report.md", edits=[
    {"old": "旧内容", "new": "新内容"}
])
```

### 列出目录

```
Agent: ls(path="/output")
返回: ["report.md", "data.csv"]
```

---

## 与 interrupt_on 配合

写文件前可以要求人工审批：

```python
agent = create_deep_agent(
    model="gpt-5.5",
    backend=FilesystemBackend(root_dir="./project"),
    interrupt_on={"write_file": True},  # 写文件前审批
    checkpointer=MemorySaver(),
)
```
