# 9.5 性能优化

---

## 1. Prompt Caching

Deep Agents 自动启用，无需配置。

## 2. 上下文压缩

自动压缩长对话，减少 Token 消耗。

## 3. 工具输出卸载

大数据自动保存到文件，不在上下文中占空间。

## 4. 子 Agent 模型选择

简单任务用小模型，复杂任务用大模型。

## 5. 工具延迟加载

用 Middleware 只在需要时才暴露工具。

## 6. 并行委派

同时委派多个子任务给不同的子 Agent。
