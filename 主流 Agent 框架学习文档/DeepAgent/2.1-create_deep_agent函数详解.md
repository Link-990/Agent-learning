# 2.1 create_deep_agent() 函数详解

---

## 函数签名

```python
from deepagents import create_deep_agent

agent = create_deep_agent(
    model,                    # LLM 模型（必需）
    tools=[],                 # 工具列表
    system_prompt="",         # 系统提示词
    subagents=[],             # 子 Agent 列表
    backend=None,             # 文件后端（默认 StateBackend）
    memory=[],                # 启动时加载的上下文文件
    skills=[],                # 技能模块
    interrupt_on={},          # 人工介入配置
    checkpointer=None,        # 持久化检查点
    middleware=[],            # 中间件
    context_schema=None,      # 上下文 Schema
    permissions=[],           # 文件权限
)
```

---

## 与 create_agent() 的区别

| 参数 | create_agent() | create_deep_agent() |
|------|---------------|---------------------|
| `model` | ✅ | ✅ |
| `tools` | ✅ | ✅ |
| `system_prompt` | ✅ | ✅ |
| `middleware` | ✅ | ✅ |
| `subagents` | ❌ | ✅ 子 Agent 委派 |
| `backend` | ❌ | ✅ 文件后端 |
| `memory` | ❌ | ✅ 上下文文件 |
| `skills` | ❌ | ✅ 技能模块 |
| `interrupt_on` | ❌ | ✅ 文件级介入 |
| `permissions` | ❌ | ✅ 权限控制 |

---

## 返回值

返回一个编译好的 LangGraph 应用，支持：

```python
agent.invoke(input)           # 同步调用
agent.stream(input)           # 流式调用
agent.stream_events(input)    # 事件流
```
